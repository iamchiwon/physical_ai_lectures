# 집필 및 코드 스타일 가이드

## 독자와 문체

- 컴퓨터공학 학부 수준의 자료구조, 선형대수, 운영체제, Python/C++ 경험을 전제로 한다.
- 한국어로 설명하고 첫 등장 전문용어는 `한국어(English)` 형식으로 병기한다.
- 단순 기능 나열보다 문제 상황, 원리, 구현, 검증, 실패 원인의 순서로 설명한다.
- 불확실하거나 버전에 따라 달라지는 내용은 단정하지 않는다.

## 장 구성

각 장의 `chapter.md`는 다음 순서를 따른다.

1. 장 개요
2. 학습 목표
3. 선수 지식과 준비물
4. 핵심 이론
5. 설계 및 구현
6. 단계별 실습
7. 예상 출력 예시
8. 트러블슈팅
9. 요약
10. 확인문제와 프로젝트 과제
11. 참고문헌

## 코드

- Python은 Python 3.12 문법과 타입 힌트를 우선한다.
- ROS 2 C++은 C++17과 `rclcpp`를 사용한다.
- 비 ROS 수학 코드는 가능하면 NumPy 의존성만 사용한다.
- 하드웨어 명령에는 범위 제한, 타임아웃, 예외 처리, 안전 정지 경로를 둔다.
- 코드 블록에는 대응하는 `code/` 파일의 상대 경로를 표시한다.
- 출력은 재현 결과가 아니라 `예상 출력 예시`임을 명시한다.

## 수식과 단위

- 벡터와 행렬의 좌표 프레임을 명시한다.
- 각도 내부 표현은 radian, 사용자 표시가 필요할 때 degree를 병기한다.
- SI 단위를 우선하며 숫자와 단위 사이에 공백을 둔다.
- 쿼터니언 순서는 라이브러리별 `(x, y, z, w)` 또는 `(w, x, y, z)` 차이를 반드시 표시한다.

## 출처

- 공식 문서, 표준, 원 논문을 우선한다.
- 본문 인용은 Markdown 링크와 `[저자, 연도]`를 사용한다.
- 장 말미에 링크 제목, 기관/저자, 접근일 또는 발행연도를 기록한다.
- 라이선스가 불명확한 외부 이미지는 복제하지 않고 자체 도식으로 재구성한다.

## 이미지

- 원본 도식은 SVG를 우선하고 `images/`에 저장한다.
- 모든 그림에는 번호, 제목, 본문 설명, 대체 텍스트를 둔다.
- 색상만으로 상태를 구분하지 않는다.
- 최종 PDF 흑백 출력에서도 관계가 식별되어야 한다.

## 안전

- 실물 로봇 실습에는 작업 공간 비우기, 속도/토크 제한, 비상 정지, 전원 차단 순서를 포함한다.
- 검증 전 코드를 실물 장비에 바로 적용하지 않도록 경고한다.
- 안전 기능을 일반 예외 처리나 UI 상태에만 의존하지 않는다.
