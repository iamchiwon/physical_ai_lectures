# KANT 순서 참고 재배치 적용 기록 · 2026-11-06

제안에 대한 사용자 승인과 대상 보정에 따라 실제 카탈로그·홈·목차·기본 이전/다음·추천 경로에 적용했습니다. 최종 단계와 상세 내용은 [현행 커리큘럼](../integrated_curriculum.md), 전체 소주제 배치는 [JSON](kant_sequence_2026-11-06.json)을 기준으로 합니다.

- 대상은 일반 코딩을 할 수 있는 개발자입니다. Python·C/C++ 언어/문법 입문을 추가하지 않습니다. 초기 제안의 B01~B07은 채택하지 않았습니다.
- S01은 M01 여섯 단위와 M31.01/.02로 구성합니다. AI/로봇 환경·패키지·ABI·CMake/colcon·재현·시간/데이터 계약에 집중합니다.
- 조기 실습에서 고전적 영상 연산을 경험한 뒤 좌표·센서·제어·인지 기반을 익히고, 모바일 → 조작 → ML·모방학습 → VLA → 통합으로 진행합니다. ACT·Diffusion·양팔 등은 선택 심화로 분리합니다.
- 원래 204개 소주제를 모두 보존하고 관제 M34의 3개를 준비중으로 추가했습니다. 현재 35모듈·207소주제, 공통 경로 1개와 기존 전문 경로 6개입니다.
- 공통 과정 147개는 필수 144개와 캡스톤 선택안 3개입니다. 전문화 60개는 별도 선택 과정입니다. 기본 학습 순서와 E1~E9 집필 이력은 서로 다릅니다.
- P1~P4는 단계별 프로젝트 안내입니다. 2026-11-09에 P1 기본 실행 패키지를 추가했고 P2~P4와 M34 상세 교재는 준비중입니다. 새 목차 등록을 집필 완료로 표시하지 않습니다.
- 기존 unit/topic/track/step/activity ID와 URL·저장 키는 유지합니다. 수정된 원고는 지문 검수 후 연결하고 기존 답안/완료 이력을 보존합니다.
