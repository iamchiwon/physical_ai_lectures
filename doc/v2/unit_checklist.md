## 작업 단위와 완료 규칙

한 번의 집필 작업은 소주제 ID 하나다. **분석·기준 → 작성 → 탈고 → 검수 → 완료 기록**을 순서대로 끝내고 다음 단위로 이동한다. 관련 기존 교재·선수/후속 설명도 같은 작업에서 수정·재승인한다. 묶음 W의 완료는 소속 소주제 전체 통과와 연결 검수를 요구한다. 단계 S/A의 프로젝트·연결 검수와 모듈 전체 완료는 별도다.

아래 단위는 실제 학습 순서로 배치했다. `필수 선수`는 현행 allOf, `대안 선수`는 anyOf 중 하나 이상이다. 완료된 선수가 포함되어도 작업 시작 때 현재 지문과 설명 연결을 확인한다. 옛 자산 매핑의 설명 full/partial/none은 등록 당시 자료 범위이며 현행 집필 완료 상태를 대체하지 않는다. [품질 기준](quality_gate.md).
