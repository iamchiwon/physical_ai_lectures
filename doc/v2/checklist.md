## 1. 작업 순서와 단위

1. **소주제 1개**: `work_items/<Mxx.yy>.md`에서 사전 기준 → 작성 → 탈고 → 검수 → 완료 기록을 끝낸다. 기존 교재의 잘못된 선수·후속 설명도 함께 수정한다.
2. **집필 묶음 W**: 소속 단위 전체와 단위 사이의 연결을 검수한 후 체크한다. 묶음은 일괄 집필/일괄 승인 단위가 아니다.
3. **프로젝트 작업 PKG-Pn-01~05**: 안내 페이지와 실제 실행 패키지를 구분해 환경·스타터·입력·실패 사례·해설·웹 연결까지 별도로 완성한다.
4. **구간 검수 G-Sxx/G-Axx**: 완료 원고를 재집필하지 않고 진입·선수·활동·다음 이동과 필요한 프로젝트를 연결한다. 원고 완료와 전체 경로 검수는 다른 체크다.

기본 우선순위는 **W01 → P1 실행 패키지/G-S00~03 → W02/G-S04 → W03/P2/G-S05 → G-S06~08 → P3/G-S09 → W04~06/P4/G-S10 → K01/G-S11 → 전문화**다. 완료된 단위도 해당 구간에서 연결만 재검수한다. 내용 선수의 실제 allOf/anyOf가 우선하며, 아래 선행 작업은 신규 집필끼리의 의존만 요약한다.

별도 작업자가 있다면 선수와 파일 소유가 독립적인 단위의 자료 조사·검산을 병행할 수 있다. 저자와 검수자의 작업은 분리하되 같은 원고의 동시 수정을 피하고 선수가 통과하기 전 후속 단위를 완료 처리하지 않는다. 공통147교재·P1~4·K01/G-S00~11을 마쳤으며 남은 전문화 44개를 진행한다.
