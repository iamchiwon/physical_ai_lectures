# 공개 산출물의 정보 경계

학습자에게 제공하는 화면·교재·다운로드·AI 참조에는 커리큘럼 조사에 이용한 외부 강의의 제공사, 강의명/강좌 제목, 조사 식별자, 교육 페이지 URL, 목록 및 참고·재배치 관계를 싣지 않는다. 버전명·메타데이터·브라우저 번들·corpus·숨은 링크도 같은 기준을 적용한다.

- 공개 대상: 학습 원고, 개념/실습·평가 자료, 공개 목차와 커리큘럼, 정적 웹과 AI 참조, 검수한 실행 패키지.
- 내부 전용: 조사 원본/목록·비교 제안, 출처 매핑, 승인/작업 이력과 보존 기준선. 최종 묶음에 doc 디렉터리 전체나 저장소/Git 이력을 통째로 포함하지 않는다.
- 논문·서적·공식 기술 문서와 필수 라이선스/저작권 표시는 정확성/이용 조건에 따라 유지한다. 강의 영상/교육 페이지를 기술 문서처럼 위장해 연결하지 않는다.
- 강의 안내에 기대는 설명은 본문에서 자립하게 보완한다. 학습 범위·순서·수식/코드/실습과 식별자/저장 호환은 유지하고 수정 원고는 현재 지문으로 다시 승인한다.

`npm run check:publication`은 공개 입력과 실제 정적 산출물의 알려진 노출 패턴/강의명·내부 파일 혼입을 검사한다. 전체 빌드 끝에서도 실행하며, 출판 원고 조립은 쓰기 전에 같은 기준을 검사한다. 자동 검사는 새 강의명·간접 표현·이미지/영상 안의 문구까지 판단하지 못하므로 F06에서 전수 육안/내용 검수를 함께 한다.

PDF/EPUB 제작·공개는 모든 내용 검수 후 별도 사용자 요청이 있을 때 진행한다. 기존 출판 파일은 이번 작업에서 재생성하거나 재배포하지 않는다. 향후 출판본의 본문·목차·참고 자료·링크/메타데이터도 같은 기준으로 별도 검수한다.
