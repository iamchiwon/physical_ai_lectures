## 이북 원고 연결

- 웹뿐 아니라 기존 `ebook/tools/build_book.sh`의 입력에도 승인된 E1 상세 본문을 기존 여섯 장 앞에 포함하도록 연결했다. 원본 Markdown을 같은 parser로 읽고 JSON 메타데이터를 제외하여 생성하며 E1 내부 연결은 책 앵커로 바꾼다. 원고를 이중 집필하지 않는다.

- 새 답안의 다른 탭 충돌도 실제 확인했다. 첫 탭 수정 중/미저장 입력과 다른 탭의 저장 답안을 모두 보존하고 비교 안내를 표시했다. 첫 탭의 자동 덮어쓰기는 없었다.

## M01 실제 화면·코드 대조

- 승인12단위 중간빌드의 `/textbook/` 새기초 목차12개와 기존137개 읽기링크/용어복습 보존을 확인했다. M01.04 본문3292자·코드2블록, 320px에서 페이지너비320/코드내부overflow:auto. 실제 모바일PNG를 열어 읽기와긴명령표시를 점검했다.
- 본문에 표시된 C++2예제와 CMakeLists가 실제실행한 코드파일과 완전히 일치했다. Python은 __main__guard와docstring차이만 있어 표시코드를 직접실행해 원본파일과 stdout일치까지 확인했다. 로컬 Python실행이며 Ubuntu·ROS·장비검증이 아니다.
