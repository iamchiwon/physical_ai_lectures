# M25.03 · Collision Group·Filtered Pairs·Physics Debug

- 날짜: 2026-11-09 / 상태: 분석·기준 확정.
- 선수/기존: M25.02 관절·연결과 M25.01 collider/재질. 기존 2장2.4/2.12의 충돌 근사·filtering을 재사용하고 실제 후보쌍·예외·관찰 시각의 빈 부분을 채운다.
- 범위: 네 collider의 합성 집합/관찰 기록 검토. 실제 엔진/GUI 실행이나 충돌 안전 실증이 아니다. 설치·일반 문법은 제외한다. 엔진별 기본 self-collision/그룹 반전/다중소속 규칙을 단정하지 않고 이번 명시 계약으로 한정한다.

| 목표 | 활동 | 사전 통과 기준 |
|---|---|---|
| 그룹·개별 제외와 형상/접촉을 나눈다 | 4collider 쌍·Q1 | B,F,O,G의 무순서6쌍, 명시 BF만 제외→후보5쌍. 그룹 필터와 개별 제외의 영향·우선순위·실제 적용 범위를 설명하고 허용=접촉발생으로 읽지 않음 |
| 잘못된 넓은 필터를 좁게 수정한다 | Robot-Object 오제외·실습/Q2 | 그룹이 BO/FO를 함께 막고 BF제외까지 총3쌍제외/후보3임을 계산. FO 개별제외만 지워 그룹차단을 복구했다고 하지 않음. 지지/파지에 필요한 쌍과 설계근거 보존 |
| Physics Debug와 보고서의 미확인을 진단한다 | 0접촉·시각표/Q3 | collider표시/엔진근사·실제 활성/필터·기하/물리스텝·report구독을 순서대로 검사. 접촉0은 부재/필터/미실행/미수집 구분. update시작 접촉과 update끝 렌더 시각을 같은 것으로 비교하지 않음 |

- 합성 입력: Robot={B(base),F(finger)}, Object={O(box)}, Ground={G(floor)}. 단일그룹소속·반전없음·기타엔진필터없음·모든collider활성. BF제외는 이 표에서 설계근거를 별도로 제공한 제한 가동범위의 예외이며 실제 모든 인접 링크의 포괄 제외를 권하지 않는다.
- 실패/경계: 필요한 FO/OG접촉까지 제거·존재하지않는경로·그룹멤버누락·개별필터우선·같은쌍중복집계·query필터와simulation혼동·접촉0/보고0·렌더/physics시각불일치. 충돌검사후보5개를실제contact5개로보고하면실패.
- 출처: 2026-11-09 OpenUSD CollisionGroup/FilteredPairsAPI와 NVIDIA Physics Debug 공식 문서. API의 그룹/쌍 의미와 디버그 시각 한계를 확인했다. 최신 GUI 메뉴 경로/색상은 고정 절차로 요구하지 않는다.
- 통과: 내용7항목과 실제웹1항목 각2점, 1실습/3문제·개별해설, 집합/경계·기존문단개정/지문·320px/저장/개정/완료·전후이동·선택AI·카탈로그/빌드 검사.
