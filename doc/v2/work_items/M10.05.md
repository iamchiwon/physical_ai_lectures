# M10.05 집필 기록

- 상태: 통과·완료 / 2026-11-03
- 범위: 물리/렌더/센서/제어와 벽시계, 단순 적분 오차와 solver 반복의 차이, 반복 실험의 조건/오차 지표다. 실제 simulator/API 실행과 정밀 성능 측정은 제외한다.
- 선수: M05.06 시간, M07의 이산 모델, M10.03 접촉이다.
- 목표 1은 주기/스텝/RTF로 실습 1/Q1, 목표 2는 명시한 적분 계산과 solver/비용 판정으로 실습 2/Q2, 목표 3은 반복 조건/허용 오차로 실습 3/Q3에 대응한다.
- 정상은 물리120/렌더30Hz, 경계는 비정수 비율과 동일 seed/다른 입력 순서, 실패는 렌더만 높여 물리 정밀도 개선 및 허용 오차 통과를 bit 동일성으로 읽는 경우다.
- 콘텐츠 7항목 모두 2점 필요. Isaac Sim 6.2 Fundamentals의 주기/이벤트 구분 및 PhysX5.4.1 RigidBodyDynamics의 solver/제한적 결정성을 직접 확인했다. 단순 semi-implicit 식은 교육용 모형으로 실제 solver 내부와 구별한다. PDF/EPUB는 생성하지 않는다.

## 작성·탈고·자기검수

- 물리/렌더/벽시계→단순 적분/solver→반복 조건의 세 목표가 실습과 Q1~3에 대응한다. 실제 엔진 적분과 교육용 식을 구분했다.
- 120/30 및 240/60의 네 스텝, RTF 0.5, 위치 0.02/0.015와 Q2 0.04/0.03, 정확 위치 대비 오차 0.01/0.005, 허용 오차/계산 비용의 독립 실패를 재계산했다. multiline 수식을 KaTeX로 확인한다.
- 같은 seed/같은 전체 조건·허용치 통과/비트 동일성·외부 h/solver 내부/렌더 이벤트를 구분하고 전 섹션 가독성/부분 답 피드백을 탈고했다. 콘텐츠 7항목 자기 2점. 실제 simulator 실행/출판 생성은 없다.
