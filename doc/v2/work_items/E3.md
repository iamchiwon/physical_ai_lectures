- 시작: 2026-11-03 / 상태: 집필·독립 내용 검토·웹 통합 검수 통과
- 사용자 지시: PDF/EPUB는 만들지 않는다. 모든 작업과 내용 검수가 끝난 뒤 사용자가 별도로 요청할 때 생성한다. 이번 작업은 원고·웹·내용 검수이며 PDF/EPUB 생성 명령을 실행하지 않는다.
- 범위: M10·M11·M12 각6개와 M14.01/.03/.06, 총21개 단위. M14 전체 모듈 완료로 표시하지 않는다.
- M14 분할 근거: 카메라 보정·시간 정합·오차/불확실성 기록은 E1 확률·E2 프레임/ROS와 E3 투영 기초로 이어진다. M14.02의 센서별 다중 정합, .04 Kalman/EKF, .05 다중모달3D융합은 M13 등의 선수와 함께 E6에 남긴다. 기존ID·제목·204개 계획은 보존한다.

- 절차: 한 단위 사전 기준→집필→탈고/검산→별도 콘텐츠 검토→보완·재검수→정확SHA승인 순서로21개를 완결한다. 작성·검토·웹 구현을 분담하며 root는 기존 교재 개정과 최종 통합 검수를 담당한다.
- 환경: Ubuntu24.04·ROS2 Jazzy·기존 Isaac Sim6.2 문서 기준. 실제 실행 환경과 문서 기준을 구분한다. 확인된 로컬은 Darwin·torch2.13.0/NumPy2.4.4이며 cv2/pxr는 없다. 설치 없이 가능한 작은CPU예제와 합성 입력을 사용하고, GPU/Isaac/OpenCV/YOLO 실제 실행·학습 성과를 지어내지 않는다.
- 공개: [E3 승인 registry](../inventory/e3-reviews.json)의 정확한 현재SHA와 근거가 있는 단위만 제공한다. M14의 유보3단위는 E3에서 승인할 수 없다. E1/E2 원고·기준선·URL/ID·답안/진도를 보존한다.
- 표시: 완료 항목에는 상태 배지를 붙이지 않고 미완료 항목만 준비중으로 표시한다. 방문·계산기 조작은 학습 완료/숙달을 자동 부여하지 않는다.

## 사전 통과 기준

1. 목표/선수·자립성·정확성·전이예제·실습·문제해설·자습표현의7내용 기준을 모두2점으로 충족한다. 자연스러운 한국어 띄어쓰기를 전 섹션에 적용한다.
2. M10은 시각·충돌·물리·시간·조합 계층을 분리한다. Stage/레이어/참조/인스턴싱과 물리 step/CCD·solver의 조건을 명시하며 단순 모형·문서 대조를 실제 시뮬레이터 검증이라고 부르지 않는다.
3. M11은 손실/경사/역전파·tensor shape/dtype·데이터 분리/누수·출력/지표·실험 조건을 연결한다. 작은CPU실행과 모델의 일반화·실물 성공을 구분한다.
4. M12는 영상색/좌표·투영/왜곡·라벨/검출·분할/추적·지표와 실제 작업 기준의 차이를 수치·반례로 설명한다. M14 기초는 시간원/시점·보정 프레임/잔차·불확실성 근거를 연결하고 심화3주제로 준비도를 확대하지 않는다.
5. 기존 교재의 불일치·선수/후속 설명 부족을 같이 개정하고 독립 검토·승인 지문을 갱신한다. 기존137읽기절·18요약·317alias와 저장 호환을 보존한다.
6. 웹의 실제 본문·수식/코드·실습/해설·모바일320px·키보드/저장/AI참조를 확인하고, 테스트·타입·린트·전체웹/API빌드와 정적 링크/자산을 검수한다. 별도 교재 검증 스크립트를 repo에 추가하지 않는다.
7. PDF/EPUB 산출물을 생성하지 않는다. 승인 원고를 읽는 출판 입력 코드의 확장이 필요해도 생성 명령은 실행하지 않는다. 실제 외부 배포·외부AI모델품질·실물/GPU 실행 여부는 수행한 사실만 기록한다.

## 진행

시작 기준은 E1/E2 상세48개·내부집계48/65/91이다. E3의 기존상태는 partial16/TBD5이므로 전체통과시69/49/86이 예상되며 최종 실제값을 대조한다. [독립검토](E3-review.md)와 [통합검수](E3-validation.md)에 근거를 기록한다.

### 선택 보충 모형 사전 기준

M11.05는 합성8행의 이진분류 점수와 고정 정답에서 threshold≥판정·TP/FP/FN/TN·정밀도/재현율/F1·가상오류비용을 비교한다. 분모0은 미정의로 표시한다. 이 점수를 보정확률·실제학습성과나 검출AP/mAP·작업성공으로 해석하지 않는다.

M12.02·M14.03/.06은 optical x오른쪽/y아래/z앞의 핀홀 투영과 일정깊이·같은시계·상대vx 가정에서 시점차가 픽셀/미터에 미치는 효과를 계산한다. Z>0·양수초점·유한범위를 검사하고 Z와유클리드range, 수학적으로유효한투영과영상틀밖을구분한다. 왜곡·rolling shutter·6DoF·깊이변화·시계보정·실제센서실행은 포함하지 않는다.

두 모형은 단위/revision으로 상태를 구분하고 320px·키보드·손계산·독립소스검수·자동저장/완료 미변경을 통과해야 한다. 본문의 기본 실습/네답안은 모형 없이도 수행할 수 있게 유지한다. 기존 물리·시간 개념 모형은 범위를 설명해 재사용하며 GPU실행으로 부르지 않는다.

### 기존 교재 개정 진행

기존6장과 사용법/환경의 선수·후속을 E3에 연결했다. PhysX 기본경로와 Newton 추가지원·importer작성schema의 차이를 나누고, L1 회귀식에서 곧바로 평균해를 가정하던 설명과 ApproximateTime의 전역최근접/온라인미래표본 해석을 보완했다. L1/L2의{-1,+1} 예는 로컬torch2.13 CPU에서 직접 계산해 L1최소집합과 제곱L2고유최소를 확인했다. 독립 검토 후 기존지문승인 registry를 갱신한다.

### M10 완료

M10 여섯 단위를 집필하고 독립 내용 검토와 실제 웹 전달을 확인했다. 자산 조합·단위·백엔드, 충돌·물리, 이벤트 시간·결정성, ROS·카메라 계약을 실행 조건과 함께 설명한다. M10.01의 실제 저장 흐름과 기존 보간 그림 수정도 검수했다. M11의 작은 CPU 역전파 예제는 작성자와 별도 검토자가 실행했으며 후속 단위 집필을 계속한다.

## 최종 판정 — 2026-11-03

M10~M12 각 6개와 M14.01/.03/.06, 총 21개 원고·실습 21개·확인 문제 63개와 개별 해설을 완성했다. 각 단위의 독립 내용 검토와 정확한 현재 SHA 승인을 거쳐 웹에 반영했다. E1·E2 포함 누적 상세 원고 69개·실습 69개·문제 207개다. M14 심화 3개는 미작성·미승인·준비중으로 남기며 E6에서 진행한다.
