# 공개본의 참고 강의 비노출 정리

- 날짜: 2026-11-10 / 상태: 현재 공개 입력·산출물 정리 및 회귀 검수 완료. 최종 공개 직전 F06은 별도 미완료로 유지.
- 사용자 지시: 최종 결과에 참고 강의 목록/제목/출처·참고 관계를 노출하지 않고 검토 항목에 포함한다.
- 공개 범위: 학습자 화면·목차/공개 커리큘럼·교재/다운로드 원고·AI 참조/corpus·HTML/JS/JSON/메타데이터·향후 출판 입력. 내부 조사/승인/보존 기준선은 공개하지 않는다. 논문/서적·공식 기술 문서 및 필수 라이선스 표시는 강의 조사 목록과 구별한다.
- 사전 기준: 공개 문서의 강의 조사/참고 목록/연결 삭제, 외부 강의 페이지 링크를 기술 근거/자립 설명으로 교체, 공개 카탈로그 버전명 중립화. ID/URL·순서/선수·코드/수식/입력/답안과 원본 기준선 보존. 변경 원고 SHA만 재승인하고 집필 수를 늘리지 않는다.
- 재발 방지: 공개 원고/문서·생성 HTML/JS/corpus/자산 검사와 출판 입력 검사, 알려진 제공사/강의명/URL·조사ID 누출 회귀. F06 공개 전 전수 검수와 품질 필수 조건 추가.
- 검수: 전체 기존 검사/타입/린트/shared/web/API dry-run 빌드·공개 산출물 비노출·현재174/207 준비 상태/기록 호환 대조. PDF/EPUB 생성/배포/기존 파일 재작성은 하지 않는다.

## 반영·검수 결과

- 공개 커리큘럼의 외부 강의 목록/참고 매핑과 진행 순서 출처를 제거하고 공개 카탈로그 버전명을 중립화했다. 내부 조사 원본·과거 검수 이력·보존 기준선은 유지하며 배포 경계에서 제외한다.
- 상세 교재 34개를 정리했다. 외부 강의·영상 안내는 제거하고 설명을 자립시켰으며 필요한 근거는 논문·서적·공식 기술 문서로 유지했다. 실제 통신 용어인 `FC의 30/00/05`는 조사 식별자와 혼동되지 않게 표기했다. 코드 블록/수식·실습·답안은 유지했다.
- 변경 원고의 SHA와 기존 승인 항목을 갱신했다. 집필 완료 수는 174/207로 동일하고 남은 상세 집필은 33개다. ID·학습 순서·선수·별칭·기록 저장 형식은 유지한다.
- `npm run check:publication`을 전체 빌드 끝에 추가했다. 공개 원고/소스와 실제 HTML·JS·메타데이터·확장자 없는 AI corpus, 다운로드 압축 내부까지 검사한다. 출판 입력 조립기도 쓰기 전 동일 기준을 검사한다. 조사 파일 경로·알려진 강의명/출처·인코딩된 링크 회귀 검사를 추가했다.
- 전체 테스트 **181/181**, 타입 검사·린트·shared/web/API dry-run 빌드 통과. 최종 공개 검사 **2,910개 텍스트 파일 / 압축 내부 43개 항목** 통과. 정적 산출물 **415개 HTML / 13,880개 링크 / 7,144개 자산 / corpus 207개** 대조 오류 0개.
- 런타임 원고 SHA·현재 corpus·기존 교재 다운로드 지문·준비도/별칭 대조 통과: ready174 / partial2 / tbd31, resource2073 / activity887 / alias317. 기존 교재142개와 승인된 수정16개 상태를 유지한다. 이번 작업에서는 브라우저 저장 조작이나 외부 AI 호출을 수행하지 않았다.
- F06 및 단위 집필/품질 기준에 비노출 검토를 추가했다. 자동 검사가 판단하지 못하는 간접 표현·이미지/영상과 앞으로 추가할 원고는 최종 전수 검수 대상으로 남긴다. PDF/EPUB 생성·기존 출판 파일 재작성·배포는 수행하지 않았다.
