## 1. 분석과 작성 전 기준

작성 전 범위·판정 기준을 확정하고 이후 조사·분석 문서를 작성했다.

- 범위: 현재 앱·교재·실습·평가·라우트·저장·AI 참조·정적 빌드의 구조, 보존 대상과 이행 위험.
- 제외: 앱/원고 변경, A02의 새 데이터 계약 확정, A03의 204소주제 상세 매핑, 실사용 저장소 열람, 외부 AI 요청·배포·GPU/실물 실행.
- 학습자 가정: 컴공 졸업(예정)은 출발점. 실제 자습 경로에서 본문·실습·문제·해설·AI를 찾고 수행할 수 있는지 소스상 연결과 공백을 확인한다.
- 주요 오해: 137본문 단위와 18요약 레슨을 같은 진도로 오인, 실습이 있다는 이유로 목표 충족으로 오인, API 문맥 요약이 로컬 저장 용량도 줄인다고 오인.
- 환경: 현재 v2 소스. 비밀값·실제 대화·클라우드 로그를 읽지 않는다.
- 기준 확정일: 2026-11-02. 작성 후 기준을 낮추거나 범위를 확대하지 않았다.

## 3. 탈고

학습자 순서로 홈→상세 본문→실습→답안/해설→요약 점검→AI 질문을 추적했다. 읽는 사람이 준비도를 과대평가하지 않도록 다음 사항을 구분해 기술했다.

- 원본 MD 54개와 본문 표시 원본 MD 31개의 차이를 의도적 제외·간접 활용과 구분.
- 36개 요약 점검, 99개 자동 추출 서술 문항, 27개 보고서 입력 항목의 수량 의미 구분.
- 49파일은 실행 코드만이 아니라 예제/설정 전체임을 명시.
- 본문 답안 초안은 저장되지만 피드백·실습 결과·본문 읽기 진도는 영속 저장되지 않음을 명시.
- 장비 없이 가능한 개념 실습과 실제 로봇/학습 실행을 구분.
- 현재 챕터 ID의 검색·삭제 의미와 신규 커리큘럼 모듈의 의미를 혼동하지 않도록 후속 계약 문제로 분리.

실행 확인:

- 현행 textbook/course 추출 함수를 esbuild로 메모리 번들하여 실제 메타데이터 산출. 로봇 예제 코드는 실행하지 않음.
- `npm run test:tutor`: **19개 통과, 0개 실패**. 기존 메모리 저장소/가짜 모델 응답 테스트. 외부 AI 요청 없음.
- 기준선의 전체 원본 파일 SHA-256과 파일 목록 대조, 문서 링크·식별자 유일성 확인.

미실시: 브라우저·실제 사용자 저장소 이행·정적 빌드/린트/타입검사·OpenRouter 실호출·GPU/실물. 코드 변경 없는 A01의 판정 범위 밖이며 해당 검수가 통과했다고 주장하지 않음.

탈고에서 수량 의미·직접/간접 자산·AI/실습 한계를 보완한 문서를 검수했다. 검수 미통과 항목은 없어 추가 재검수 차수는 없음. 향후 소스가 변경되어 분석이 달라지면 해당 항목을 재개방한다.
