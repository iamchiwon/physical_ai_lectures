# M23.02 · Rollout·Actor-Critic·PPO의 업데이트

- 날짜: 2026-11-10 / 상태: 분석·기준 확정. 묶음: W12.
- 작성자 자기검수. 일반 코딩 가능 대상, 언어 문법 설명 제외. 필수 선수: M23.01. 기존 ID/URL/기록과 원고를 보존한다.
- 범위: 장비 없는 합성 수치/기록 분석. 실제 GPU 학습·상용 도구 실행·실물 시험은 범위 밖이며 수행했다고 표현하지 않는다.

## 사전 목표·판정

1. rollout·actor·critic·advantage와 on-policy 자료를 구분한다. 본문 예제→실습→Q1와 개별 해설로 판단하며 값만 맞고 가정/실패 이유가 없으면 미통과다.
2. 확률비와 PPO clipped surrogate를 부호별로 계산한다. 본문 예제→실습→Q2와 개별 해설로 판단하며 값만 맞고 가정/실패 이유가 없으면 미통과다.
3. 종료/마스크·과도한 업데이트·학습안정성 기록을 진단한다. 본문 예제→실습→Q3와 개별 해설로 판단하며 값만 맞고 가정/실패 이유가 없으면 미통과다.

- 정상: 제공 입력/단위로 수치와 판단을 재현한다. 실패: 본문 반례의 거짓 성공을 반박한다. 경계: 자료 없음/조건 불일치를 성공으로 간주하지 않는다. 용어·가정·입력·분모·계산·해석을 생략하지 않는다.
- 루브릭: 내용7항목·웹1항목 모두 적용. 현재 본문/공식 자료/선수·후속을 대조하고 모바일·폼/해설·AI corpus·정적 자산을 확인한다. 별도 검수자/학습자 시험은 수행하지 않는다.

## 작성

본문·사례/반례·실습·3문제/해설·참고 자료를 작성했다. 수식/표는 합성 계산이며 실제 실행 산출물이 아니다. 기존 관련 원고는 후속 링크/역할과 모순되는지 읽고, 원래 코드/수식을 유지했다. 웹 전달 검수 전이다.
