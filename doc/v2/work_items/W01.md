# W01 · S01 작업 명세·AI 도구 검토

- 날짜: 2026-11-09 / 상태: 통과·완료.
- 사전 기준: M31.01/.02의 각5단계 완료, 같은 입력/검증/권한 용어의 일관성, S01→S02 이동·원래 ID/저장 보존, 승인 지문/공개 상태 일치. 모듈 M31 전체나 프로젝트 실행 패키지 완료를 뜻하지 않는다.
- 수행/검수: 주 에이전트 작성·자기검수. 별도 독립 검수·학습자 검수는 주장하지 않는다.

## 개별 단위와 연결

[M31.01](M31.01.md)은 작업 명세/입력·환경·허용 변경·완료 기준과 작은 변경을, [M31.02](M31.02.md)는 그 명세 안에서 모델 제안·도구 행위·사람 검토와 권한 범위를 다룬다. 두 단위는 언어 문법·설치·ROS/트랙 전체 경험 없이 합성 기록으로 활동/해설을 수행한다. 기존 M01의 환경/자료/재현 계약에서 출발한다.

기존 M31 모듈이 초반에도 ROS·트랙 경험을 요구하는 충돌을 현행 모듈 안내와 통합 커리큘럼에서 수정했다. 후반 M31.03~06은 그대로 준비중이며 초기두 단위가 그 내용을 수행한 것으로 표시하지 않는다. W01 승인 권한은 M31.01/.02로 제한한다.

## 완료 근거

- 각 단위의 분석→작성→탈고→검수→완료를 각각 커밋했다. 개별 기록에 원고 SHA·공식 자료·실습/문제 대응·웹 근거를 남겼다.
- 테스트128·타입·린트·전체빌드 및 정적 HTML414/링크13,421/자산6,989 오류0, corpus207/manifest207을 확인했다.
- 실제 320px 본문/답안/해설·무배지·저장/자기검토/완료/재로드·이전 기록 보존·현재 AI 참조를 확인했다. AI 응답은 fetch fixture로 외부 모델 성능 검증이 아니다.
- 실제 키보드 main 경로 M31.01→M31.02→M05.01 이동을 수행했다. 별도 보충인 기존 응용 장 전체를 초기 선수로 요구하지 않는다.
- 런타임으로 두 단위의 ready와 각 실습1/평가3을 대조했다. 현재 상태137/13/57, Resource1703/Activity739/alias317이며 과거204 unit ID와 alias를 보존했다.
- 원래 physical-ai local/sessionStorage는 단위별로 정확 복원·대조하고 private backup을 삭제했다. 임시 서버/브라우저 공간은 다음 구간 검수에 재사용한다.

W01의 두 소주제와 연결 범위 통과. M31 모듈 전체 체크는 미완료로 유지한다. 다음 작업은 **G-S00 · 진단/분기 구간 검수**다. PDF/EPUB·출판 exporter·외부 배포는 실행하지 않았다.
