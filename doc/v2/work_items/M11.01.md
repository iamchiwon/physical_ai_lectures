# M11.01 집필 기록

- 상태: 통과·완료 / 2026-11-03
- 범위: 지도학습의 입력/목표/모형·손실, 스칼라 MSE의 연쇄법칙과 경사 갱신, PyTorch zero_grad/backward/step 및 학습률 실패다. 실제 VLA/영상 학습과 일반화 실증은 제외한다.
- 선수: M02.03 미분/M02.05 최적화, M01.02 Python이다.
- 목표 1은 데이터/목표/손실 계약으로 실습 1/Q1, 목표 2는 gradient/update 계산으로 실습 2/Q2, 목표 3은 loop/학습률/주장 범위로 실습 3/Q3에 대응한다.
- 정상은 정규화된 두 합성 표본의 MSE 감소, 경계는 손실 감소/작업 성공의 차이, 실패는 backward만 호출한 갱신/gradient 초기화 누락/너무 큰 학습률이다.
- 콘텐츠 7항목 모두 2점 필요. PyTorch 공식 autograd/optimization/MSELoss/SGD 문서를 직접 확인했다. 현재 공식 stable 문서는 2.15로 연결되지만 로컬 실제 실행은 Darwin/PyTorch2.13.0 CPU이며 버전/결과를 구분한다. 패키지 설치와 PDF/EPUB 생성은 하지 않는다.
