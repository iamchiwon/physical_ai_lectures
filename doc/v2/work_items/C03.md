## 작성 전 기준

기존 `/learn/`, `/textbook/` URL·콘텐츠 ID·정적 생성 목록은 보존한다. 신규 단위에서 원문을 열면 원래 앵커와 추천 경로를 보존하고 신규 단위로 돌아갈 수 있어야 한다. 동일 원문을 여러 단위에서 열 경우 실제 출발 단위만 복귀 대상으로 고른다. 임의/중복 query나 무관한 단위는 복귀 대상으로 인정하지 않는다. 신규 단위의 이전/다음은 기존 B04 순서를 유지한다.

| 검수 사례 | 기대 결과 |
|---|---|
| 원문 앵커가 있는 링크 | from/track이 hash 앞에 추가되고 기존 앵커 유지 |
| 두 단위가 공유하는 원문 | 해당 원문에 매핑된 출발 단위로 복귀 |
| 잘못된 from/track·중복 query | 잘못된 문맥을 적용하지 않음 |
| query 없는 기존 URL | 기존 원문과 목차·이전/다음 정상 유지 |

적용 루브릭: 탐색 가능성·내용 보존·접근/가독성·배포 적합성. 신규 집필/실물 실행은 범위 밖.

## 산출물·검수

## 구현·탈고

- `legacy-study-context.ts`는 자료 URL의 기존 앵커를 보존하며 `from=<unitId>`·유효한 `track`을 추가한다. 외부 URL·다운로드는 변경하지 않는다.
- `legacy-study-context-server.ts`는 공개되고 유효한 Binding만 원문별로 역색인한다. 각 원문 페이지에는 작은 출발 단위 목록만 전달한다.
- `legacy-study-navigation.tsx`는 실제 원문에 매핑된 출발 단위와 단일 query만 인정한다. 교재/요약의 본문·문제·실습 위에 단위 복귀/모듈 목차를 제공한다. 기존 URL 직접 방문은 전체 목차를 제공한다.
- `lesson-view.tsx`·기존 교재 페이지의 원래 순서 이동은 유지한다. 브라우저 모형에 `virtual-lab` 앵커를 추가해 C02의 직접 연결을 지원했다. 정적 화면은 Suspense fallback으로 목차 링크를 유지한다.
- 초심자 순서: 신규 단위→관련 원문→실습/문제→단위로 돌아가기→경로의 다음 단위. 관련 원문과 신규 단위 완료를 혼동하지 않도록 안내를 덧붙였다.

## 검수 근거

- `node --test tests/learning-storage.test.mjs`: 신규 저장/URL 호환 7개 통과. 앵커 보존·비학습 URL 무변경·무관한 from/중복 query 거부·잘못된 track 제거 확인.
- `npm run check --workspace @physical-ai/web`, `npm run lint --workspace @physical-ai/web`: 통과.
- 구현자 자기검수. 전체 브라우저 검수와 정적 빌드 결과는 루트 통합 검수에서 추가한다. GPU/실물 실행은 해당 없음.

### 브라우저 결함 보완 — 기존 읽기 이동의 출발 문맥

- 루트 브라우저 검수에서 `chapter-6 → chapter-7`의 기존 다음 링크가 `from/track`을 잃는 결함을 발견했다. 두 절 모두 같은 M06.02 단위의 자료인데 복귀 안내가 사라졌다.
- `LegacyContextLink`를 교재 이전/다음·장별 요약 링크, 요약의 상세 본문·이전/다음·옆 목차, 완료된 레슨의 다음 링크에 적용했다. query가 없는 SSR fallback은 기존 canonical URL을 그대로 유지한다.
- 명시된 단일 출발 ID만 전달하며 도착 원문에서는 기존 역색인으로 실제 매핑/유효 track을 다시 검증한다. 무관한 자료로 이동한 경우 해당 단위 복귀를 표시하지 않는다.
- `tests/learning-storage.test.mjs` 7개 통과: 실제 chapter-6/7의 공유 매핑·다중 페이지 전파·query 없는 canonical·중복/잘못된 ID·무관한 도착 검증. web 타입/린트 재통과.
