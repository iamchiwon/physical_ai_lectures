## 1. 학습자와 범위

학습자는 조건/반복·함수·자료 구조·예외 등 일반 코딩이 가능하다. 일반 언어 문법 자체를 다시 가르치지 않는다. 반면 로봇·AI 실행에 필요한 셸/권한·프로세스·패키지/환경·배열 shape/dtype·바이너리 ABI·컴파일/링크·CMake/colcon·환경 overlay·시간/장치 계약을 이미 안다고 가정하지 않는다. Python/C++ 등의 예제는 필요한 계약을 드러내는 도구로 쓰며 언어 이름만으로 실시간 성능이나 안전을 보장하지 않는다.

M01 여섯 단위와 후속 M00.05의 개발환경 자기진단 개정이 승인 범위다. 루트가 M00.05를 M01 여섯 개 뒤 저자에게 추가 할당했음을 확인했다. M34 세 운영 단위는 이번에 계획 ID·순서만 등록하고 pending/준비중을 유지하며 콘텐츠 승인 대상이 아니다. 기존 ID를 유지한 콘텐츠 개정은 실제 목표/활동 대응과 이전 기록의 의미를 확인하며, 정렬 변경만으로 새 목표를 자동 완료시키지 않는다. 준비중 주제·프로젝트의 순서상 위치와 현재 수행 가능 여부를 구분한다.

## 4. 구조·보존 감사 기준

204개 기존 topic과 unit/URL·활동/답안 키를 단계별 배열 순서와 분리해 유지한다. 신규 운영 단위는 별도 신규 ID로 추가한다. 기존 완료·초안/답안·대화의 저장 의미를 새 단계 위치 때문에 초기화/자동 승격하지 않는다. 기존 원고의 개정 목표와 현재 정의를 승인 원고에 일치시킨다.

제안의 역순 선수 17건은 자동 삭제하지 않는다. 기본 활동에서 실제 필요한 개념은 이른 단위나 자립 설명으로 확보하고, 선택 분야/심화에만 필요한 선수는 해당 경로에 유지한다. allOf/anyOf의 실제 의미와 단계 내 순서까지 확인한다. pending 주제는 실제 내용 없이 준비 완료로 바꾸지 않고, 네 프로젝트 패키지가 미구현이면 수행 가능하다고 표시하지 않는다. 실제 브라우저/저장 복원은 루트 검수와 별도이며 source 감사만으로 통과를 주장하지 않는다.

고정 SHA 수신 후 전체 원고·관련 diff를 읽고 독립 계산/안전한 CPU 실행·공식 자료 대조 후 통과 기록을 남긴다. 임시 승인 큐는 같은 디렉터리 임시 파일 후 원자적 replace로만 갱신한다. 최종 source/큐/검수 기록의 SHA와 승인 범위를 전수 확인한다.

## 6. 현재 정의·선수·보존의 독립 source 감사
