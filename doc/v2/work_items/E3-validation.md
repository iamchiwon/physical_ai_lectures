독립 검토한 두 선택 모형은 관련 pure model 테스트 10개와 웹 타입·린트를 통과했다. 임계값 모형의 분모 0, 오류 비용, 정수 퍼센트 경계와 투영 모형의 부호·고정 Z·같은 clock·영상 틀 밖 수치 보존을 확인했다. 실제 UI는 해당 원고 공개 후 검수한다.

## AI 전송의 실제 교재 근거

실제 M11.05 화면에서 질문을 입력하고 Ctrl/Cmd+Enter로 보냈다. health와 답변 API만 로컬 fixture로 대체했고 `/tutor-study/unit-m11-05-a`는 실제 정적 파일을 읽었다. 전송된 문맥의 unitId·topicId·moduleId·resourceIds가 현재 단위와 맞았다. 질문 문자열 이외의 `lesson.contextSummary`에 실제 새 본문의 출처 ID와 절 제목, C=FP+4FN, t=.5의 비용 5·t=.3의 비용 1·t=.8의 비용 4 및 별도 8행 모형의 한계가 포함됐다. 현재 모형 조작값은 전달되지 않는다는 안내도 유지됐다. 이 검사는 조회·전송 경로의 검수이며 외부 AI 모델 응답 품질이나 실제 외부 호출 성공의 근거가 아니다.
