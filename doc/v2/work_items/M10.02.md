- 상태: 통과·완료 / 2026-11-03
- 범위: 원본/확장 URDF와 생성 USD·배치/실험 레이어의 관계, importer의 이름/자원/베이스/물리 근사와 수치 보존, 재가져오기 및 버전/경고/검사 증거다. 실제 import/Isaac/GPU 실행은 제외한다.
- 선수: M08의 URDF와 이식 계약, M10.01의 reference/layer다.
- 목표 1은 표현과 산출물 역할로 실습 1/Q1, 목표 2는 단위·이름·mimic/베이스 보존 검사로 실습 2/Q2, 목표 3은 재가져오기/의존성/검증 계획으로 실습 3/Q3에 대응한다.
- 정상은 명시된 프레임/단위의 기준 자세, 경계는 기본 베이스 옵션과 재가져오기 시 수동 수정 소실, 실패는 동일 파일명/표시 성공만으로 재현/물리 통과라 하는 경우다.

## 작성·탈고·자기검수

- 원본/확장 입력/생성 USD/배치·실험 레이어의 역할을 설명하고 이름·경로·단위·mimic·베이스의 정보 보존과 재가져오기 추적을 구성했다. 실습 및 Q1~3이 세 목표와 일대일 대응한다.
- q=0.5 rad 끝점 (0.175517,0.095885,0) m, 제한 ±57.2958 degree, 그리퍼 0.03 m와 Q2 길이 30 unit/그리퍼 0.03 m를 Python 산술로 재계산했다.
- Base Type=Source와 Fixed, importer가 쓰는 API와 실제 선택 백엔드를 구분했다. Newton 관련 schema를 기본 백엔드의 증거로 해석하지 않는다. 전 섹션 띄어쓰기/선수/부분 답 피드백을 탈고했고 콘텐츠 7항목 자기 2점이다. 실제 import/Isaac/GPU 및 출판 생성은 없다.
