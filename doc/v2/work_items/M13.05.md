# M13.05 · 다중 시점 기하·삼각측량·깊이 추정

- 갱신: 2026-11-09 / 상태: 분석·기준 확정.
- 작성·검수: 주 에이전트 작성/자기검수. 실제 카메라·OpenCV·보정 실행을 주장하지 않는다.
- 범위/선수: M06.01 좌표변환·M12.02 핀홀·M14.01 내부/외부 보정을 연결한다. 다중 시점 광선/대응, 보정·정렬된 스테레오의 깊이 계산, 재투영/양의깊이/저시차와 척도 한계를 다룬다. 언어·문법·설치·일반3D삼각측량 해법 유도는 제외한다.
- 기존 자산: [M13 매핑](../mapping/M13.md)에 독립 설명/활동/평가 없음. M12.02의 투영과 M14.01의 보정은 재사용할 선수로 연결하고 이를 재작성한 것으로 완료수를 더하지 않는다.
- ID보존: unit-m13-05-a, authored:M13.05:practice/q1/q2/q3.

## 사전 목표·판정

| 목표 | 설명/활동 | 통과 기준 |
|---|---|---|
| 광선·대응·보정·좌표 계약을 구분한다 | 단안광선, rectification, 동차좌표/Q1 | 한픽셀로거리불확정, 동일물리점·시각/왜곡/좌표일관성, 동차w나눗셈 설명 |
| 정렬된스테레오의Z/X/Y를계산한다 | f400px/B.2m/c320,240/u360,340/v260 실습/Q2 | d20px, Z4m/X.4m/Y.2m와재투영, half해상도의f/c/u/v동시변경 |
| 깊이품질·퇴화·척도/검증을판단한다 | d4±1 및 d0/음수/행불일치·Q3 | 큰원거리오차/부적합분리, 작은재투영오차만으로대응/미터척도확정금지 |

- 손계산계약: optical X오른쪽/Y아래/Z앞, 왼쪽원점, 오른쪽중심이+.2m X에위치, 평행축/같은f·주점·왜곡제거/rectification완료·동시정적점. d=uL−uR>0. 일반비정렬영상에그대로적용금지.
- 정상: (uL,vL)=(360,260), (uR,vR)=(340,260); d20,Z4,X.4,Y.2; 오른쪽X=.2,Z4로재투영340,260.
- 경계/변형: half크기f200,c160/120,u180/170,v130이면동일좌표. d4의Z20m, d3→80/3m,d5→16m. d0은유한깊이불확정/무효처리, 음수는이번배치의전방가정에불일치. v차4는교육용행오차≤1px기준에서제외.
- 척도/동차: (4,2,40,10)→(.4,.2,4)m; baseline을.1로잘못사용하면모든길이절반이나재투영은같을수있다.
- 근거: OpenCV 공식 [Depth Map](https://docs.opencv.org/4.x/dd/d53/tutorial_py_depthmap.html), [calib3d/triangulatePoints](https://docs.opencv.org/4.x/d9/d0c/group__calib3d.html) 본문을확인했다. 라이브러리 출력/스케일은API자료형/버전계약과별도로구분한다.
- 콘텐츠7항목과 실제웹1항목 각2점 요구. 계산·변형/오답·실습/Q1~3 대응 및320px·4답안/해설·저장/AI/이동 검수 전에는 완료 체크하지 않는다.
