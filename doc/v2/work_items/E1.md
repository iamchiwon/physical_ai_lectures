# E1 M00~M03 상세 집필

- 상태: 통과·완료 / 2026-11-03
- 범위: 24소주제 실제 본문·예제·장비 없는 실습·서술문제3개·해설, 웹 직접 읽기/답안/해설 비교/명시 완료, AI 실제 본문 참조.
- 사용자 추가 요구: 기존 6장 교재의 E1 관련 가정·용어·선수·연결 부족도 검토하고 수정한다. 기존 URL/본문 청크 ID/답안/진도는 보존하고 승인된 개정 이력을 기록한다.
- 절차: 각 소주제 분석·기준 확정→집필→탈고→자기검수, 모듈별 독립 AI 검토→보완→웹/저장/AI 통합 검수. 신규 파일 존재만으로 준비도를 올리지 않는다.
- 단위 완결 기준: 구체 목표3개·기호/가정 설명·단계적 예제·변형/실패 사례·입력/절차/관찰/판정이 있는 실습·실습 해설·목표별 문제3개와 풀이/부분답 판정/오개념 피드백. 최초 등장 지식은 설명하거나 선수 링크 제공.
- 기존내용 재사용: 완성된 원문의 유도·코드를 중복 작성하지 않고 신규 맥락·연결 설명과 예제를 보완한다. 원문 상세로 직접 연결하며 신규 단위에 필요한 기초는 자립적으로 설명한다.
- 코드실행 예시는 실제 실행/예상출력 구분. Ubuntu24.04 기본, Python/C/C++ 예제, 실물·GPU는 기본경로에서 요구하지 않는다. 외부 설치·고전력 배선 등 실제실행을 검수했다고 표시하지 않는다.
- 판정: 내용준비24/준비도24는 명시검토지문 registry와 실제 렌더/활동 확인 후만 완료. 기존 비E1단위의 readiness는 유지한다. 학습시간 임의기입 없음.

## 검수 시나리오

1. 초심자 독해: 용어/기호/선수/단위·좌표·시간·가정이 연결된다.
2. 정상·변형·오답: 계산/로그/설계 입력에 예상 관찰과 해설이 일치한다.
3. 기존원고: 새 기초→기존 상세→원래 학습 복귀, 제목/슬러그/답안 키 유지, 개정한 파일의 baseline/현행 지문 대조.
4. 웹: 24단위 실제 본문/실습/문항/해설·모바일/키보드·KaTeX/코드·AI 참조. 새 답안은 v2 activityRecords에 저장, 기존기록 비변경. 방문과 명시완료/숙달 구분.
5. 회귀: 타입/린트/기존 테스트·새 의미있는 활동/저장/콘텐츠참조 테스트·정적빌드·내부링크.

## 진행

M00 집필, 교재 제공 기반 구현, 기존원고 연결 검토를 분담했다. 내용 집필은 모듈 내 한 단위씩 기준·탈고·자기검수를 마친 뒤 다음을 진행하며, 모듈의 독립검수 보완 후 다음 모듈로 이동한다.

### 기존 교재 개정

환경/사용법/안전과 여섯 장의 선수·본문 연결을 개정했다. 1장 결정론 구분·POMDP gamma/관측모형/시간축·지연과 주기 구분을 보완하고 새 기초 링크를 삽입했다. 최신 버전 설치 대신 검증버전 고정 원칙을 적용했다. 초기 변경9파일의 baseline/현행 SHA와 이유는 [승인 개정 목록](../inventory/legacy-revisions.json)에 기록했다. 기존 ## 제목/분할수·URL/ID를 유지한다.

별도 검토자가 제5장 설치 예제의 실패 후 계속 실행 가능성을 지적하여 전체 설치를 subshell set -eu 블록으로 보완했다. bash 구문 확인 통과, 미지정 revision 실제 셸 중단/clone 미실행 확인, mock checkout 실패 뒤 venv/pip 진입0 확인. 네트워크 패키지 설치·GPU/실물은 실행하지 않았다.

### M00 원고 내용 검수 완료

M00.01~06은 단위별 순차 집필·자기검수와 별도 콘텐츠 검토를 거쳤다. 01/02/03의 목표-활동-문항 정합 보완 후 7개 내용루브릭 전부2점. [독립 검토 상세](E1-review.md). 새 본문은 각2255~2701자, 전체 각5050~5865자이며 실제 화면/저장/AI 통합을 확인 중이다. 다음 M01을 같은 순서로 집필한다.

### M01 원고 내용 검수 완료

M01.01~06의 개발 기반 원고·문제·해설을 작성하고 독립내용검토를 통과했다. 사용자권한 전제, C/C++ 자동저장기간/실행절차, 명령방식의 abs/delta·seq·TTL 의미를 보완했다. Python로그파서·C++안전예제·CMake계약예제는 macOS의 실제도구로 실행하고 Ubuntu/ROS검증과 구별했다. 다음 M02 수학브리지를 같은 단위별순서로 집필한다.

### 기존 좌표변환 설명 추가 정정

M02 검토에서 기존2장과 transforms.py 주석의 extrinsic Z-Y-X 표기와 RzRyRx 열벡터 구현이 어긋남을 발견했다. 고정축 적용X→Y→Z와 intrinsicZYX 동치를 명시하고 기존함수명·실행수식은 보존했다. docstring제외AST가원본과동일한지확인하고 실제예제실행/왕복오차1.11e-16/두축90도합성사례를검산했다. 짐벌락은정확±90도특이점과근처조건악화를구분했다. 승인 개정 목록은10파일이다.

### M02 원고 내용 검수 완료

M02.01~06의 벡터/변환·미분·확률·최적화·안정성 브리지 원고를 순차집필·독립수치검토했다. det검산/halfangle·특수회전예제·행렬형태용어 등의선수비약/혼동을보완하고7내용루브릭모두충족했다. M02의118개수식을별도KaTeX검사해문법오류0확인했으며, 실제웹에서는최종렌더를추가확인한다. 마지막 M03 구성요소 집필로진행한다.

### M03 원고 내용 검수 완료

M03.01~06의 기구·센서·액추에이터·전원·BOM 원고를 순차 집필하고 독립 검토를 통과했다. 관측/추정·정격/동작 조건·전력/논리·핀 번호/보는 방향·단위/기계적 한계를 구분하고 종이 계산으로 검산했다. 기존 3장 전원 원칙도 권장 동작 범위·극성·전류·논리핀 정격을 따로 확인하도록 보완했다.

### 산출물과 범위

- [새 상세 교재 목차](../../../ebook/curriculum/README.md): M00~M03 총 24개 원고, 실습 24개 및 해설, 확인 문제 72개 및 개별 해설. 원문 전체 약12.8만자(메타데이터·문제·해설 포함).
- [승인 지문](../inventory/e1-reviews.json)과 원고가 일치해야 준비됨으로 제공한다. 기존 교재 10파일의 승인 개정은 [별도 이력](../inventory/legacy-revisions.json)에 보존한다. 원래 제목/URL/자료·문항 ID와 기존 답안·진도를 유지했다.
- 웹에서 실제 본문·실습·문제·해설과 답안 저장/자기검토/명시 완료를 제공한다. AI에 실제 신규 본문을 전달하며, 외부 모델의 응답 품질은 검증하지 않았다.
- 이북 빌드 입력에도 같은 원고를 포함했다. 최종24개 단위의 Markdown 집계와 Pandoc AST 변환을 확인했다. 실제 PDF/EPUB 파일 재생성·외부 배포는 수행하지 않았다.
- 전체204단위 중 E1의24단위를 완료한 범위다. 다음 상세 집필 묶음은 계획의 E2(M05~M08)이며 첫 단위는 M05.01이다.
