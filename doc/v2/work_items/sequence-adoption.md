# 학습 순서 재배치 적용 · 2026-11-06

## 범위와 사전 기준

사용자 승인 순서에 맞춰 KANT 참고 제안을 실제 카탈로그·홈·단계 목차·추천 경로·기본 이전/다음·AI 문맥과 기존 교재에 반영한다. 일반 코딩 가능을 전제로 언어·문법 입문은 제외하고 AI/로봇 환경·패키지·ABI·CMake/colcon 등 필요한 도구만 설명한다.

1. 기존 204 topic/unit·기존 여섯 track/step·731 activity·317 alias의 ID, 원래 소속·필수/선택 및 저장 키를 보존한다. 새 내용은 M34 3개 목차로 추가한다.
2. 모든 207개를 17단계에 한 번씩 배치하고 필수 선수와 anyOf 진입 조건이 학습 순서에서 충족되어야 한다. 공통 경로는 필수 144+캡스톤 선택안 3으로 구성한다.
3. 기본 이동·홈·단계 목차·경로는 현행 순서를 사용한다. 원래 모듈별 참조 목차·기존 교재 URL은 유지한다.
4. M01 6개와 M00.05 진단, 앞당긴 기존 원고의 선수 안내를 실제로 수정·검산·독립 승인한다. 승인 지문과 다른 원고를 준비 완료로 노출하지 않는다.
5. 프로젝트 안내와 실행 패키지, M34 계획과 상세 집필 완료를 구분한다. 완료 항목은 무배지, 미완료 항목만 준비중으로 표시한다.
6. 테스트·타입·린트·웹/API 정적 빌드·링크/자산·브라우저 모바일/이전다음/저장/AI 문맥을 검수한다. 수정 전 학습자의 답안과 완료 이력은 삭제하지 않는다.
7. PDF/EPUB/Pandoc/출판 exporter·외부 배포를 실행하지 않는다.

## 구현

- 현행 정의는 `current-definition.ts`와 `current-sequence-data.ts`, 과거 기준선은 `catalog-data.ts`/`legacyCatalog`로 분리한다. 공개 `catalog`는 현행 정의에 승인된 상세 본문을 반영한다.
- 공통 `track-main`과 단계 S00~S11, 전문화 A01~A05를 적용한다. 문법 입문 B01~B07은 채택하지 않는다. M34는 상태·좌표/시간/버전·명령 감독의 3개 준비중 단위다.
- P1~P4 안내 페이지를 추가하며 스타터·실행 환경·입력·실행 해설 패키지는 준비중으로 표시한다.
- 현행 순서의 승인 원고만 출판 입력에서 배치하도록 exporter 소스만 고친다. 출판 명령은 실행하지 않는다.
- 기존 교재 사용법을 현행 학습 순서로 연결한다. E1~E5는 집필 이력으로 보존한다.

독립 내용 검수와 승인 지문은 [검토 기록](sequence-adoption-review.md), 실제 실행 검수는 [검증 기록](sequence-adoption-validation.md)에 기록한다.
