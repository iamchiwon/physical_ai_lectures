## 초기 기반 검수

E1/E2 승인 registry를 공용 생산 helper로 읽고 전체 카탈로그에서 원고를 탐색하도록 확장했다. E2 4모듈 fixture로 승인 전 비공개→정확 SHA 승인 후 본문/해설·AI 참조·교재 목차/내부 준비도 반영, E1 불변과 stale 차단을 확인했다. 중복·잘못된 scope·미등록 원고/검수 근거 누락을 거부한다. 초기 테스트96개·타입·린트를 통과했다. 이북 생성기도 같은 registry helper와 카탈로그를 사용해 제목·SHA·근거 파일을 대조하며, E2 링크는 실재 앵커가 있을 때만 책 내부로 변환한다. 실제 웹 전달은 승인 묶음 빌드 후 별도 검수한다.

### 기존 응용 교재·이북 중간 검수

6장 개정을 독립 검토하고 승인 registry를 현재 SHA로 갱신했다. ROS 빌드 실패 뒤 잔존 설치물을 실행할 수 있는 안내를 분리해 성공 확인 경계를 명시했고, TF 조회 발췌는 공식 Jazzy Python 타입 계약과 대조했다. 실제 ROS 실행은 하지 않았다.

29개 승인 원고 집계와 실제 이북 입력 순서(앞부분·신규 원고·기존6장/실습/문제·부록, 총48개 입력 파일)의 Pandoc AST 변환을 수행했다. 헤더985개·링크397개에서 없는 내부 앵커0·root상대 웹 링크0이었다. 별도 임시 fixture로 E2 본문/모듈 내부 앵커, 미포함 단위의 웹 fallback, 웹 전용 제어 모형 fragment 보존, inline/fenced 코드 문자열 불변을 확인했다. 실제 PDF/EPUB는 생성하지 않았다. 최종48단위 집계는 전체 승인 후 다시 확인한다.

### 기존 기구학 모형 코드 개정 승인

별도 root가 virtual-lab.tsx의 실제 수학/호출·상태 정지를 재독했다. 78/64mm 두 링크의 안쪽14mm·바깥142mm 경계, 영역 밖 해 거부, roundoff에 한정한 cosine 보정과 양의q2 분기, ±180도 최단 각도 보간을 확인했다. 구현과 수학이 같은 등록 파일 안에 있어 해당 source SHA가 함께 바뀐다. 순수 모델 회귀는 실제 등록 파일을 읽어 FK 왕복·경계/불가·각도 보간을 검산한다. 원래 앱 구현 지문은 legacyCatalog 기준선에 보존하고 현재 구현은 기존 개정 registry에 별도1행으로 승인했다. book 원본142파일 중 개정10파일과 이 앱 구현1파일을 구분한다. 실제 UI 조작은 중간 빌드 후 검수한다.
