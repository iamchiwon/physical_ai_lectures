# M21.02 집필 기록

- 상태: 통과·완료 / 2026-11-03
- 범위: 인과적 관측 이력/멀티카메라 shape, 관절/TCP·절대/고정 기준 상대/누적 증분 시퀀스, 정규화/역변환과 경계 mask다. 실제 정책/장비 실행은 하지 않는다.
- 선수: M11 shape/손실, M19 프레임/IK, M20 스키마/정합과 M21.01 BC다. 관측 시점과 미래 행동의 차이를 자립 설명한다.
- 목표 1은 이력/shape·누설과 실습 1/Q1, 목표 2는 행동 표현/복원과 실습 2/Q2, 목표 3은 정규화/역변환·mask와 실습 3/Q3에 대응한다.
- 정상은 명시된 3-step 계약과 train 통계, 경계는 같은 숫자의 고정 기준/누적 증분·끝 패딩, 실패는 미래 영상을 입력으로 넣거나 상태 통계로 행동을 복원/패딩을 실제로 평균하는 경우다.
- 콘텐츠 7항목 모두 2점 필요. 공식 LeRobot action representations/v3 시간 창 문서를 직접 조회했다. 현재 relative/delta의 기준/누적 구분은 기존 5.5.3 연결 보완으로 parent에 보고했다. 선택 계산은 표준 Python만 사용하며 학습/장비·출판/배포 실행은 없다.

## 작성·탈고·자기검수

- 관측 가용 시각/shape→행동 공간·상대/누적→정규화/배포→패딩 mask를 자립 설명했다. 실습/Q1~3은 세 목표와 대응한다. 부모가 기존 5.5.3에도 상대 기준/증분의 구분을 보완했다.
- 표준 Python 예를 원고에서 추출해 실제 Darwin/Python3.13.4에서 실행했고 action_rad=0.450; valid_mse=2.500 출력이 일치했다. 실제 정책/제어 실행이 아니다.
- 영상 96원소/96·384 byte, state6성분, 목표 시각 0.12/.17/.22와 상대 .50/.45/.38·누적 .50/.55/.53 rad를 재계산했다. z2/복원 .45·잘못된 통계 .6/clip .4·mask2.5와 Q2 .3/.15 대 .3/.25/Q3 .2 rad·loss4도 맞다.
- 공식 Action Representations의 fixed-reference/순차 차이·정규화 순서와 v3 시간 창을 대조했다. ACT 고유 loss reduction과 이번 유효 평균 규약을 동일시하지 않는다. 기존 5.5/5.3 목적지와 초심자 단위/부분 답/오개념·띄어쓰기를 탈고했다. display 수식은 없고 콘텐츠 7항목 자기 2점이며 출판/배포 실행은 없다.
