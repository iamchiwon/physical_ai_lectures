# M25.04 · 강성·감쇠·마찰·질량·접촉 보정

- 날짜: 2026-11-09 / 상태: 작성 완료·탈고 대기.
- 선수: M25.03 필터/접촉 확인. M07.01/.03·M10.04/.05의 힘/제어·질량/시간은 필요한 식과 링크로 복습한다. 기존2장2.6/2.9의 마찰/물리 보정을 현재 단위로 연결한다.
- 범위: 수평1DOF force drive의 합성 순간 측정표와 독립 마찰 실험표를 분석한다. 실제 파라미터 추정·시뮬레이터/실물 실행·정밀한 접촉 솔버 재현은 아니다. acceleration drive/각도단위는 같은 숫자를 복사하지 않도록 차이를 설명하되 새로운 API/코딩 입문은 제외한다.

| 목표 | 활동 | 사전 통과 기준 |
|---|---|---|
| 힘·가속도·드라이브/접촉 계수를 구분한다 | 식/단위·Q1 | F=k(x*−x)+c(v*−v), 수평접촉없는F=ma·N/m,Ns/m, force/acceleration·직선/회전·포화의 구분 |
| 분리된 합성 관측에서 m/k/c와 마찰을 계산한다 | 표·실습/Q2 | 독립 F2N/a1→m2kg; e0.02/v0/F2→k100; e0.02/v0.05/F1→c20. μs0.5/Fn20→정지마찰한계10N, μk0.3→미끄럼6N. 정지마찰을항상10N으로놓지않음 |
| 미사용 조건으로 보정을 평가하고 혼동 원인을 진단한다 | holdout/포화·Q3 | e0.03/v0.10→F1N/a0.5, 관측1.04N/0.52에서오차0.04/0.02·사전허용0.10/0.05통과. e0.05/v0/Fraw5N→max2N/a1, 질량/마찰/step를함께바꾸어맞췄다고승인하지않음 |

- 모든 직선 단위는m/kg/s, targetVelocity0. 드라이브 표는 마찰/다른힘없음·측정시각동일·포화안됨·instant sample이며 정적평형 자료가 아니다. 독립 질량 시험은 drive꺼짐/순힘2N 가정이다. 마찰 표는 별도 수평 접촉·법선력20N·Coulomb 근사·구름/회전없음으로 고정한다.
- 실패/경계: 틀린형상/단위/필터를물성으로가림·질량과gain동시변경·계수식별불능·정지마찰최댓값혼동·포화표를비포화식으로fit·렌더FPS/physicsstep혼동·contactoffset/재질혼동. 허용오차의경계는포함하며 값은 교육용/사전기준이지 엔진공통성능기준아님.
- 공식 근거: 2026-11-09 OpenUSD DriveAPI/USDPhysics와 Isaac Sim Physics Fundamentals에서 force/acceleration·재질 결합/접촉 offset·실행 설정 구분을 확인했다.
- 통과: 내용7항목·실제웹1항목 각2점, 실습/3문제·개별해설·수치/경계·기존교재개정/지문·320px/저장/개정/완료·이동/AI·카탈로그/빌드를 확인한다.
