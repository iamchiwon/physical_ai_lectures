## 작성 전 기준

D01의 전수 자산 대조, D02의 실제 학습·모바일·키보드 흐름, D03의 정적 빌드·배포 적합성 근거를 합쳐 필수 결함이 남지 않을 때만 1차 통합을 완료한다. 신규 본문 집필·외부 AI 정확도·실물/GPU 실행·실제 배포는 범위 밖이다.

| 기준 | 관찰 가능한 통과 조건 |
|---|---|
| 데이터 보존 | 손상/미래 형식·쓰기 실패·다른 탭 변경에서도 기존 원문을 무단 치환하지 않으며 미저장 입력을 보존·안내 |
| 삭제 범위 | 새 모듈 삭제와 기존 챕터 삭제를 구분하고 전역 요약·진행 요청을 무효화; 독립 저장 키의 삭제 확산 없음 |
| AI 근거·호환 | 단위/준비 상태·실제 자료 범위를 전달하며 구 Worker의 신규 정책 미지원 시 제한 안내; 본문 누락을 실제 근거로 오인하지 않음 |
| 탐색/상태 | 잘못된 쿼리는 안전한 전체 순서로 복귀; TBD 방문/활동을 준비·숙달로 승격하지 않음 |
| 최종 통합 | D01~D03 관련 기준 전부 통과, 발견 결함 수정 후 영향 범위 재검수 및 근거 기록 |

정상: 레슨→단위→같은 문항/대화 복원. 실패: 저장 읽기/쓰기 오류·다른 탭 수정·본문 조회 실패·구 Worker. 경계: 신규 module-Mxx/기존 chapter-N 혼합 대화·보충만 있는 TBD·없는 단위/경로.

## 코드 검토·재현 결과

검토 과정의 결함과 보완 및 최종 통합 판정은 아래에 기록한다.

### 1차 독립 코드 검수 — 보완 필요

- 저장·삭제 범위·탐색·AI 문맥 계약을 C 구현과 대조했다. 실제 학습자나 외부 모델 검수는 아니다.
- `/tmp/d04-store-repro.mjs` 합성 저장소로 빈 문자열 원본이 첫 질문에 덮어써지는 현상과 quota 실패 후 미저장 대화1건이 외부 정상 이벤트에서0건으로 소실되는 현상을 각각 재현했다.
- 추가로 저장 후 값을 다시 읽어 기준으로 삼는 구간에 외부 쓰기가 끼면, 이후 변경 감지에서 다른 탭 원문을 본인 저장값으로 오인할 수 있었다.
- 대화 삭제 기능 자체는 module-Mxx와 chapter-N을 분리하지만 확인 문구가 둘 다 일반적인 '현재 학습 범위'여서 계약상 구분 안내가 부족했다.
- 결과: 필수 데이터 보존 기준 미충족. 범위를 유지하고 보완 후 재검수한다.

### 보완·재검수

- `tutor-store.ts`: null만 미생성 저장소로 인정해 빈 문자열 손상 원본을 보호한다. 쓰기 실패/충돌 후 외부 정상 이벤트가 와도 미저장 대화는 메모리에 유지·안내하며 pending을 실패 상태로 바꾸고 epoch를 무효화한다. 명시적인 외부 null 삭제는 반영한다. 저장 기준은 다시 읽은 값 대신 실제 쓴 문자열로 확정한다.
- `progress-provider.tsx`: 저장되지 않은 진도 변경을 별도 추적한다. 다른 탭이 정상 기록을 바꿔도 현재 메모리 진도와 원본을 모두 보존하고 재확인 안내를 표시한다.
- `tutor-drawer.tsx`: '현재 모듈'/'현재 기존 챕터'와 건수를 구분하고, 신규 모듈 삭제 뒤 연결된 과거 챕터 대화는 별도 범위에 남는다고 알린다.
- `tests/storage-protection.test.mjs` 6개 + 기존 tutor19개 = 25개 통과. 빈 문자열·미래/손상·쓰기 전/후 경쟁·quota+외부 이벤트·명시 외부 삭제·요청 무효화를 확인했다. web 타입·린트도 통과했다.
- React 검수 기준으로 refs를 저장/요청 상태 추적에만 사용하고 기존 effect 정리·직렬화 경계·대화 스키마/ID를 유지했는지 확인했다.
- 루트의 브라우저 재검수와 D03 최종 빌드 재확인 대기.

### 평가 답안과 비동기 피드백 일치 보완

- 추가 독해에서 평가 요청 중 다른 탭의 새 답안이 수신되면 답안은 교체되지만 늦은 평가 응답이 새 답안 아래에 표시되는 경로를 확인했다. 답안 내용과 평가 근거가 달라지는 필수 결함으로 분류했다.
- `written-exercises.tsx`에 평가 epoch를 추가했다. 외부 답안 이벤트나 사용자 편집은 진행 중 결과를 무효화하고, 이전 요청의 응답·오류·busy 해제는 현재 요청과 epoch가 같을 때만 반영한다. 외부 갱신 시 비교 해설·피드백·평가 제출 상태도 초기화한다.
- 기존 문항 ID·답안 저장 키·AI 평가 의미를 유지했다. 실패/충돌로 저장이 차단된 현재 답안은 외부 이벤트에도 교체하지 않는다.
- web 타입·린트 통과. 변경 TSX의 hook 호출 순서·effect 정리·비동기 참조·기존 disabled/label·서버 경계를 React 검수 기준으로 재확인했다.
- 실제 deferred 평가/다른 탭 답안 갱신/late 응답 시나리오는 루트 D02 브라우저 검수에서 수행하고 최종 결과에 합친다.
