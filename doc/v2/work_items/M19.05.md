# M19.05 집필 기록

- 상태: 통과·완료 / 2026-11-03
- 범위: 비전 관측→후보 파지/좌표→검증/실행→물체 유지·배치 확인, Piece Picking/Depalletizing의 입력 차이·단계 지표다. 실제 인식/파지 성능은 주장하지 않는다.
- 선수: M12.02 투영, M14 기초 프레임/시간, M19.01~03 공구/계획/접근이다. 깊이/지정 자세와 grasp 후보를 자립 설명하며 M17/M18 미집필은 요구하지 않는다.
- 목표 1은 관측/파지 후보와 실습 1/Q1, 목표 2는 좌표/접근과 적재 변화·재관측으로 실습 2/Q2, 목표 3은 단계별 증거/분모와 실습 3/Q3에 대응한다.
- 정상은 유효 깊이/주어진 자세의 합성 후보, 경계는 높은 score지만 깊이/경로가 무효인 경우와 상자 제거 후 scene, 실패는 bbox 중심/attach 등록/명령 전송을 실제 물체 유지로 승인하는 경우다.
- 콘텐츠 7항목 모두 2점 필요. MoveIt Task Constructor 공식 단계/scene 부착과 Robotiq 공식 depalletizing 변동 자료를 직접 조회했다. 구형 ROS1 pick 예제 명령은 Jazzy 경로로 재사용하지 않으며 출판/배포·실제 실행은 없다.

## 작성·탈고·자기검수

- 검출/파지 후보→깊이/변환·접근→실행 증거→Piece Picking/Depalletizing→단계 지표를 자립 설명했다. 세 목표 모두 실습/Q1~3에서 관찰한다.

- MoveIt Task Constructor의 접근/자세/IK·부착/상승 단계와 Robotiq의 위치/높이 변동을 대조했다. 별도 방향 입력·같은 시계/깊이/변환과 실제 유지/배치 관측의 계약을 명시했다. 기존4.1/3.5 실제 heading·내용과 연결을 확인했다.
- 초심자 독해로 부분집합/재시도 없음의 분모 가정과 모든 수치의 합성 범위를 탈고했다. 부분 답/오개념 피드백을 확인했고 display 수식은 없다. 콘텐츠 7항목 자기 2점이며 실제 탐지/파지·출판/배포 실행은 없다.
