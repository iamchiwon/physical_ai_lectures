# M19.02 집필 기록

- 상태: 통과·완료 / 2026-11-03
- 범위: MoveIt 2의 상태/Planning Scene·IK·충돌/제약과 경로/시간 궤적·실행 상태를 구분한다. 실제 ROS/MoveIt 설치나 장비 실행은 요구하지 않는다.
- 선수: M06 IK/범위, M08 URDF/TF, M19.01 TCP다. M17 미집필의 상태 공간/경로·샘플 검사를 본문에서 보충한다.
- 목표 1은 상태/scene/IK 근거와 실습 1/Q1, 목표 2는 중간 경로·ACM/충돌 판정과 실습 2/Q2, 목표 3은 시간/시작 상태·실행 검증과 실습 3/Q3에 대응한다.
- 정상은 같은 scene의 유효 목표, 경계는 유효 끝점 사이의 금지 구간과 재타이밍, 실패는 IK/plan 성공을 실제 작업 성공으로 표시하거나 오래된 상태를 그대로 실행하는 경우다.
- 콘텐츠 7항목 모두 2점 필요. 공식 MoveIt 개념/Planning Scene·time parameterization과 Jazzy control_msgs FollowJointTrajectory를 직접 조회했다. Rolling 문서는 개념 근거로만 쓰고 배포판별 기본값을 단정하지 않는다. 합성 1관절 표는 실제 충돌 엔진이 아니며 출판/배포 명령은 실행하지 않는다.

## 작성·탈고·자기검수

- scene/IK→중간 경로→시간/실행을 순서대로 설명하고 M17의 상태 공간·경로/샘플 개념을 자립 보충했다. 실습과 Q1~3은 각각 세 목표에 대응한다.
- 합성 금지 구간에서 q0.5 충돌/성긴 0.4→0.6 누락과 1차원 우회 불가를 독해했다. 속도 1.2/0.8 rad/s·하한 0.6/0.4 s, 시작 차이 0.1>0.02와 Q3 1.5 rad/s/0.3 s를 계산했다. 시간 예제는 기하 실패와 독립임을 명시했다.
- 공식 MoveIt 개념과 Jazzy action의 목표/경로 허용오차 및 최종 결과를 대조했다. ACM·scene 최신성·plan/action 수락/작업 성공을 구분했다. legacy 실제 3.3/3.5 heading·URL을 대조했고 수식 display는 없는 개념/표 계산 단위다.
- 전 섹션 초심자 독해와 단위·가정/부분 답·오개념 피드백을 탈고했다. 콘텐츠 7항목 자기 2점. 실제 MoveIt/ROS/장비 또는 출판/배포 실행은 없다.

- 독립 검수: d04_review 콘텐츠 7항목 모두 2점. 승인 SHA bff5839860b516723dc6fbb1aa205e1a1f081634e15b84cd6b1cdfe8f8755252. 경로/시간·Jazzy action 결과와 기존 목적지를 재검산했다.
