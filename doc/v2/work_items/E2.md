# E2 ROS 2·기구학·제어·모델 상세 집필

- 시작: 2026-11-03 / 상태: 통과·완료
- 사용자 요청: E2 진행. 기존 교재의 불일치·이어지는 설명 부족도 함께 수정한다. 완료 항목에는 상태 배지를 붙이지 않고 미완료 항목에만 `준비중`을 표시한다.
- 범위: M05~M08의24개 소주제. 각 단위에 관찰 가능한3목표, 자립적인 본문·기호/가정·단계적 예제·변형/실패 사례, 장비 없는 실습1개와 해설, 목표별 확인 문제3개와 풀이/부분답/오개념 피드백, 공식 참고 자료와 기존 응용 교재 연결.
- 선수: E1의 개발·수학·구성요소 기반. M06기구학→M07동역학/제어→M08관성/모델 연결, M05 ROS 통신/시간→M08상태/TF연결. 앞선 단원을 배우지 않았다면 명시 링크로 보충한다.
- 환경: Ubuntu24.04·ROS2 Jazzy 기준으로 공식문서 확인. 장비 없는 가상로그·종이/CPU계산이 기본이다. 실제ROS·GUI/시뮬레이터·실물·GPU실행과 읽기/계산검증을 구분한다. 검증하지 않은 명령 성공·학습시간·실행결과를 만들지 않는다.
- 절차: 한 단위 기준확정→집필→탈고/검산→독립내용검토→보완→승인SHA 확정 순서로 진행한다. 작성자/독립검토자/통합 구현 담당을 분리하고 root가 기존교재·최종브라우저·공통체크리스트를 담당한다.
- 승인: [E2 registry](../inventory/e2-reviews.json)는 독립검토된 정확한 현재SHA와 근거가 있는 단위만 포함한다. 파일존재만으로준비도를올리지않는다. E1 registry/원고/기존답안·진도·URL·ID를 보존한다.
- 출판: 웹·AI문맥·이북빌드에서 같은 원고를 사용한다. 실제PDF/EPUB 재생성·배포는 별도이며 이번 작업에서 수행하지 않는다.

## 사전 통과 기준

1. 목표·선수/자립성/정확성/예제전이/실습/평가해설/자습표현의7내용루브릭이 모두2점이며 수치·프레임·부호·단위·시간·버전·모형한계를 명시한다.
2. ROS통신의요청/응답·QoS호환·발견·시간/실행지연, 기구학의frame/해조건·특이점, 제어의선형화/샘플링·포화, 모델의관성/축·충돌/이식계약을 혼동하지 않는다.
3. 기존응용교재 관련절과 연결하고 모순은 승인개정이력에 기록한다. 기존137읽기절/18요약/alias/답안과진도는 보존한다.
4. 신규24개 실제본문·실습/문제/해설·수식/코드·320px 화면과키보드/저장/AI참조를검수한다. 미완료만준비중, 완료는무배지이며 학습자의완료/숙달과집필완료를구분한다.
5. 의미있는회귀테스트·타입·린트·전체빌드와정적링크/자산/AI문맥을검수한다. 교재검증용스크립트를새로저장하지않고 임시검산만사용한다.

## 진행 기록

시작 기준은 E1 상세24개·내부준비도 ready24/partial85/TBD95다. E2 집필·내용검토·런타임확장을분담하고 M05.01부터단위별로진행한다. 최종검수근거는 [E2-validation](E2-validation.md), 독립콘텐츠검토는 [E2-review](E2-review.md)에 기록한다.

### 기존 응용 교재 6장 개정

각 장의 선수 절에 E2 직접 연결을 추가했다. 1장 QoS의 자동 협상 오해, KEEP_LAST/depth와 KEEP_ALL 자원 제한, deadline 이벤트와 실행 마감 보장의 구분을 보완했다. 시스템/ROS/steady 시간과 시간원·미초기화/역행을 구분하고, ROS 패키지 빌드는 새 터미널 underlay→빌드 성공 확인→새 실행 터미널 overlay 순서로 명시했다. 실패 뒤 잔존 설치물을 새 빌드로 오인하지 않도록 실행 경계를 분리했다.

3장은 RSP의 고정/동적 TF 역할과 모터 구동의 구분, namespace와 frame_id/prefix의 차이를 명시했다. 4장 TF 조회 Python 예제는 Jazzy API에 맞춰 `Time.from_msg`를 사용하고 동일 시계 전제·TF 수신 콜백 실행·비동기 대안을 설명했다. 6장은 EMA와 PID 적분 포화를 구별하고 무효 제안 검사→필터→최종 제한 및 내부 상태/재시작 조건의 일관성을 보완했다. 2·5장은 관성/충돌·제어 계층/구동 계약의 선수와 후속을 연결했다.

공식 원문: [Jazzy QoS](https://github.com/ros2/ros2_documentation/blob/jazzy/source/Concepts/Intermediate/About-Quality-of-Service-Settings.rst), [Executors](https://github.com/ros2/ros2_documentation/blob/jazzy/source/Concepts/Intermediate/About-Executors.rst), [Clock and Time](https://design.ros2.org/articles/clock_and_time.html), [robot_state_publisher](https://github.com/ros/robot_state_publisher/blob/jazzy/README.md), [tf2 Buffer](https://github.com/ros2/geometry2/blob/jazzy/tf2_ros_py/tf2_ros/buffer.py), [rclpy Time](https://github.com/ros2/rclpy/blob/jazzy/rclpy/rclpy/time.py)를 대조했다. ROS 문서 HTML이 접근 차단된 경우 공식 저장소의 Jazzy 브랜치 원문을 사용했다. 실제 ROS 실행은 수행하지 않았다.

독립 검토자가 명령 실패 경계 보완을 요청했고 수정 후 재검수했다. 기존 여섯 chapter의 `##` 제목·순서를 git 기준선과 대조하여 그대로임을 확인했다. 최신 지문은 [기존 원고 승인 이력](../inventory/legacy-revisions.json)에 기록했다. E1 때 승인된 다른4개 파일은 유지하며 총10개 개정 파일의 원래 기준선 지문을 보존한다.

### M06/M07 가상실습 사전 기준 추가

통합 커리큘럼에 기구학·제어 응답 조작 활동이 있으므로 M06은 기존2링크 가상실습을 연결하고, M07.03/.06은 별도 선택 보충 제어 개념 모형을 제공한다. 기존2링크 모형의 도달 판정이 바깥 반경만 검사하여 안쪽 빈 영역을 무시하는 결함을 발견했다. 안/바깥 반경과 수치 허용오차, 도달 불가 시 추종/진단을 보완하고 본문 기구학 조건과 일치시킨다.

제어 모형은 명시된 정규화1차 식과 이산 PID·포화/조건부 적분·샘플 간격·정수 샘플 지연을 사용한다. 식·계산 순서·단위·시간 의미·제약을 표시하고 실제 모터/ROS 결과와 구별한다. 손계산과 경계·응답 회복을 검산하며 320px·키보드 조작·결과 해설을 확인한다. 기본 종이/로그 실습과4답안·명시 완료 흐름은 위젯 없이도 수행 가능하게 유지한다. 위젯 추가만으로 단위 준비도를 올리지 않는다. M07 집필 전에 정한 범위이며 모형설계 확정 시 세부 근거를 추가한다.

### M05 콘텐츠 검수 완료

M05.01~06의 ROS 작업공간/Executor·인터페이스·DDS/QoS·Launch/Lifecycle·TF/기록도구·시간/네트워크 장애 상세 원고를 집필하고 독립 내용7기준을 통과했다. absolute/delta 의미와 clock 미초기화 표현, 전 섹션 자연스러운 띄어쓰기를 보완했다. 장비 없는 합성 기록 계산과 정상/실패 진단을 기본으로 하며 공식 Jazzy 원문과 대조했다. E1 포함30개 승인 원고의 웹 중간 빌드를 진행하고, M06 프레임/기구학 집필을 이어간다. 실제 웹 검수는 별도 기록한다.

### 앞부분 안내 동기화

기존 사용법·환경·안전 파일도 E2 경로와 기본 계산/로그 활동·선택 ROS 실행을 구분하도록 개정했다. 완료 무배지/미완료 준비중 표시를 사용법에 반영하고, 셸 주석과 root 프롬프트·인용 문자열의 차이를 교정했다. Lifecycle/Action 취소 응답과 물리 정지, 정규화 제어 모형과 실제 구동기, 시각 형상과 물리 모델 검토를 분리했다. 별도 검토자의 문구 보완 후 현재 SHA를 승인했다.

### M06 콘텐츠 검수 완료

M06.01~06의 프레임/합성·DH/FK·기하/DLS IK·특이점/해 연속성·바퀴 운동학·델타/SO-101/영점 보정 원고를 작성하고 독립 내용7기준을 통과했다. 직선 관절 변수의 평가 누락과 singular/near-singular 표현을 보완했다. 수치와 모형 가정·물리 제약을 나눠 설명하고 기존2링크 가상실습의 범위를 한정했다. E1 포함36개 승인 원고를 웹에 반영하며 M07 동역학·제어 집필로 진행한다.

### 바퀴 운동학 보충 모형 사전 기준

통합 커리큘럼 M06의 바퀴 속도 조작 활동을 위해 M06.05에 차동/4메카넘 선택 보충 계산기를 추가한다. 이미 검수한 본문·종이 실습은 그대로 유지한다. 몸체 x앞/y왼쪽/Ω반시계와 L/R·FL/FR/RL/RR 순서, 양수 기하와 SI 단위, 무미끄럼 운동학 가정을 명시한다. 요구 속도→바퀴 속도→공통 한계 축소→순계산과, 별도 가상기록 편차→동일가중 추정/재구성 잔차를 구분한다. 잔차 하나로 실제 미끄럼이나 실제 이동을 확정하지 않는다.

모드 변경 시 차동의 vy=0 제약을 지키고 유효 범위·정상/역산·한계·가상편차를 손계산과 비교한다. 320px·키보드·단위/수치 표를 확인하며 조작·초기화는 답안/진도/완료를 자동 변경하지 않는다. 3옴니 종이 활동과 기본4답안은 독립적으로 유지한다. 새 보충 모형 자체의 구현·독립 수치 검수·실제 화면 검수를 마쳐야 E2 전체 작업을 완료한다. 웹 전용 anchor는 이북에서 해당 웹 모형 URL로 연결한다.

### M07 콘텐츠 검수 완료

동역학·전달함수/상태공간·PID/포화/샘플링·주파수/근궤적·제어 계층/궤적·필터/지연의6개 원고가 독립 내용 검수를 통과했다. 자유응답 조건과2차계수 단위, PID 연속 기록의 이전 측정값, 필터의 측정 직후 값과ZOH 구간 끝값의 시간 인덱스 혼동을 보완했다. 수치·기호·정규화 보충 모형과 실물의 차이를 명시하고 실제 브라우저PID 조작을 확인했다. 마지막 M08 로봇 모델6단위로 진행한다.

### JointState 기존 설명 추가 보완

M08.05 집필 중 기존3장의 `가능한 한 가까운 시각`이라는 표현이 공식 JointState의 한 메시지 동일시각 계약보다 느슨함을 확인했다. 같은시각을 나타내는 상태로 한정하고, 비동기 값을 합치려면 공통시각 정렬·추정과 원시각/정책/오차를 별도로 기록하도록 수정했다. 대략적인stamp만 붙이는 원시값 혼합은 불충족으로 명시했다. 공식 Jazzy 메시지 정의를 직접 확인하고 실제 명세 링크를 연결한 뒤 독립 재검토·현행SHA 승인을 갱신했다.

### M08 및 최종 판정

M08.01~06은 모델 요소와 기준 프레임, Xacro·자산 경로, 관절 축·제한·mimic·트리, 관성·충돌 품질, JointState·RSP·TF, 구동 인터페이스와 시뮬레이터 이식을 다룬다. 여섯 단위 모두 독립 내용7기준을 통과했다. XML 구문·가상 문서·수치 검산과 실제 ROS 실행을 구분했다. E2 원문 전체는 약14.3만자(메타데이터·실습·문제·해설·참고 포함)이며 본문은 단위당2754~3570자다.

E2 총24개 원고·실습24개·확인문제72개와 개별 해설을 완성했다. E1과 합하면48개 원고·실습48개·확인문제144개이며 기존6장137개 읽기 절과 이어 읽는다. 이번 E2에서 기존 교재9파일과2R모형을 개정하고 바퀴·PID 선택 계산기를 보충했다. 원래 기준선·URL·ID·진도·답안을 보존하며, 완료 항목은 무배지·미완료 항목은 준비중으로 표시한다.

104개 테스트·타입·린트·전체 빌드, 48페이지 실제320px 검수, 내부 링크11,649개·자산6,647개 전수 검사를 통과했다. AI에 새 본문이 전달되고, 이북의 새 단위48개 앵커와 기존137개 연결에 누락이 없음을 확인했다. [상세 교재 목차](../../../ebook/curriculum/README.md) · [독립 내용 검수](E2-review.md) · [최종 통합 근거](E2-validation.md).

실제 학생 학습성과·ROS/실물/GPU 실행·외부 모델 응답 품질은 검증하지 않았다. PDF/EPUB 재생성과 배포도 수행하지 않았다. 다음 한 작업은 E3 / M10.01 분석·학습 목표·평가 기준 확정이다.
