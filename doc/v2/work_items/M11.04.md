# M11.04 집필 기록

- 상태: 통과·완료 / 2026-11-03
- 범위: CNN의 국소/공유 가중치와 비선형, 단일 query scaled dot attention의 수치/위치·mask, 표현/backbone/head와 전이 검증이다. 전체 모델 학습/대형 모델 비교는 제외한다.
- 선수: M11.01~03의 학습·tensor·분할, M02.01의 내적이다.
- 목표 1은 작은 cross-correlation/ReLU로 실습 1/Q1, 목표 2는 attention 가중합/변형으로 실습 2/Q2, 목표 3은 표현과 task head/전이 범위로 실습 3/Q3에 대응한다.
