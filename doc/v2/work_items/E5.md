# E5 모바일 로봇 최소 완결 경로 상세 집필

- 시작: 2026-11-04 / 상태: 집필·독립 내용 검토·웹 통합 검수 통과
- 범위: M09·M15·M17·M18 각 6개, 총 24개 단위.
- 순서: M09.01부터 단위별 사전 기준→집필→탈고·검산→독립 검토→보완·현재 SHA 승인. 내용 검토 후 모듈별 웹 통합 검수를 진행한다.
- 분담: 저자는 원고·단위 기록, 독립 검수자는 내용 승인, 통합 담당자는 런타임·회귀, 루트는 기존 교재·승인 등록·실제 화면·최종 판정을 맡는다.
- 사용자 지시: 기존 교재의 모순·부족한 연결도 수정한다. 완료 항목은 무배지, 미완료만 준비중으로 표시한다. PDF/EPUB는 별도 요청 전까지 생성하지 않는다.

## 사전 통과 기준

1. 내용 품질 7항목 모두 2점. 관찰 가능한 목표 3개와 본문·예제·실습·문제의 대응을 확인한다.
2. 각 단위에 자립 본문, 기호·단위·가정, 단계 예제와 변형/실패, 장비 없는 실습 1개 및 해설, 확인 문제 3개 및 개별 정답·부분 답·오개념 피드백을 제공한다.
3. M09는 고정 스텝·실시간 비율, 명령/측정, 프레임·시계·리셋 계약을 구분한다. ROS 2 Jazzy·Gazebo 호환 정보는 공식 자료로 확인하며 설치·시뮬레이터 실행을 했다고 주장하지 않는다.
4. M15는 지도·위치추정·SLAM, 좌표/격자·미지 셀, 상대 이동·루프 폐쇄, 융합·정합·오차 평가의 가정을 설명한다. 미집필 M13·M16 심화 없이 기본 활동을 완결한다.
5. M17은 configuration space·충돌·경로 비용·탐색/샘플링·최적화·시간 궤적을 구분하고 알고리즘의 조건부 성질을 과장하지 않는다. M18은 lifecycle·TF·costmap·행동 상태·취소·다중 로봇/주행-조작 자원 계약을 연결한다.
6. 기존 교재의 관련 설명·선수/후속 연결을 감사하고 필요한 개정을 독립 검토·현재 SHA로 승인한다. 원래 137개 읽기 절·18개 요약·142개 bookFiles·317개 alias와 사용자 저장 호환을 보존한다.
7. 승인된 현재 원고만 웹·교재 목차·AI 참조로 제공한다. 실제 320px 화면·수식·코드·키보드·답안/자기 검토·완료·AI 근거와 회귀·타입·린트·전체 웹/API 빌드·링크/자산을 검수한다. 미수행 검수는 완료로 표시하지 않는다.
8. PDF/EPUB·Pandoc·출판 exporter·실제 외부 배포를 실행하지 않는다. 출판 입력은 문법·읽기 검토만 한다. 저장소에 교재 검증용 스크립트를 새로 추가하지 않는다.
