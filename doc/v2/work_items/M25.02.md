# M25.02 · 바퀴·서랍·관절·Articulation Root

- 날짜: 2026-11-09 / 상태: 작성 완료·탈고 대기.
- 필수 선수: 완료한 M25.01. 변환/자유도는 M06.01/.02·M08.02·M10.04의 보충 링크로 연결한다. 기존 3장 3.1.3의 고정/부유 루트·단위 점검을 재사용하고 새 바퀴/서랍 경로를 연결한다.
- 범위: 세 강체·두 관절의 합성 구조/명령/관측표를 계산한다. 실제 USD/물리/모터/GPU 실행이나 API 설치·코딩 문법을 요구하지 않는다. 구름 거리 식은 무미끄럼 가정의 기하 예측이며 실제 traction 증거가 아니다.

| 목표 | 활동 | 사전 통과 기준 |
|---|---|---|
| 바퀴/서랍의 관절·프레임·목표 단위를 고른다 | 구성표·Q1 | 회전1/병진1자유도, body0/body1·두 로컬 관절 프레임·축/원점, USD degree와 URDF rad·장면 길이 단위 구분 |
| 고정/부유 루트와 연결 그래프를 해석한다 | 3강체/2관절·Q2 | 트리에서 고정 베이스2·부유8의 기구학 좌표, 부모 계층과 body 관계 구분, RootAPI 이름/존재만으로 world 고정이나 controller 성공을 생성하지 않음 |
| 한계·부호·실행 결과를 진단한다 | 실습·Q3 | r0.05m·θ90°=π/2rad→무미끄럼0.07854m; 베이스z90°이면 localX→worldY/localY→world−X; 서랍0.25m 경계 허용/0.30 거부, 목표 입력과 실제 관측을 분리 |

- 입력: m/Z-up 장면의 chassis-wheel-drawer 트리. wheel joint localY, drawer localX·0~0.25m. 루트 yaw+90°, 바퀴반경0.05m. 루트 고정/부유 두 변형은 별도 구성으로 비교하고 같은 장면에 중복 적용하지 않는다.
- 실패: 같은강체에 연결/누락body·로컬frame불일치·각도단위오인·잘못된root가동범위·목표한계초과·drive목표는있고관측없음. 소비엔진별 root선택/한계해석 차이를 보편명령으로 단정하지 않음.
- 공식 근거: 2026-11-09 OpenUSD Revolute/PrismaticJoint, USDPhysics, NVIDIA OmniPhysics/ovphysx Articulations. 대상 명세의 degree/단위와 프레임 관계를 확인했다.
- 통과: 내용7항목 각2점과 실제 웹1항목2점, 실습/3문제·개별해설, 수치·경계/실패·기존 원고 개정/지문, 320px/저장·개정·완료·전후이동·AI문맥/카탈로그/빌드를 확인한다.
