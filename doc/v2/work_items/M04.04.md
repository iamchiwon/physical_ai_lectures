# M04.04 · SPI·I2C/TWI·EEPROM

- 날짜: 2026-11-10 / 상태: 작성 완료·탈고 대기.
- W07/A01, 필수M04.03. SPI/I2C의가상센서바이트/시간·ATmega328P내부EEPROM의제공기록판정으로완결한다. 일반C/C++문법·버스/레지스터쓰기코드·실제배선/전송/EEPROM쓰기·정전/장비시험은없다.

- 기록모형은schemaS1/period1~1000ms·CRC/commit·nonwrappingseq를쓴다. 기본A/B를남기고새slot의내용/검사후commit하는개념을설명하되단일바이트원자성/저전압복구/순서·장비증명은별도다. CRC는인증/물리타당성을보장하지않고설정복구는출력자동재개와별개다.
- 공식근거2026-11-10: Microchip7810D §18SPI모드·§21TWI식/clock조건·§7.4내부EEPROM/쓰기(3.4ms는문서typical예),NXP UM10204 Rev7.0(2021-10-01) §3.1의7bit/ACK·repeatedSTART/STOP·clock늘어남을확인했다. Standard-mode의예이며10bit주소/UFm등에그대로확장하지않는다. 가상센서opcode/메모리기록은자체입력이다.
- 기존4장시간/센서출처에버스ACK·주소/바이트규약·설정버전/유효기록과획득시각차이를연결한다. 기존원래지문/URL/ID·현재SHA를보존/재승인한다.
- 통과: 내용7/웹1각2점·3목표/정상·오답/시간·실패/수명가정·표/실습/3문제/개별해설·부족근거/실제미실행범위,실제320px4답안/해설·저장/개정/완료·AI선택/전후M04.03→현재→.05준비중,카탈로그/기존자료/현재지문·전체172검사/타입/린트/shared/web/API dry-run빌드다. 승인후160ready/4partial/43tbd·상세160/미집필47을대조한다. 실제학습자/버스/EEPROM/장비안전실증을주장하지않는다.
