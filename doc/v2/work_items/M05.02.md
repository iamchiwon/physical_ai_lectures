# M05.02 집필 기록

- 상태: 통과·완료 / 2026-11-03

## 분석과 사전 기준

- 범위: Topic/Service/Action/Parameter 선택, msg/srv/action의 형식, 물리 의미와 상태 계약. 실제 ROS 실행·명령 송신·실물 조작은 제외한다.
- 선수: M05.01의 노드와 콜백, M01의 자료형, M02의 단위. 기존 1장의 노드와 인터페이스 사례로 연결한다.
- 목표 1은 요구에 따른 통신 방식 선택으로 실습 1/Q1에 대응한다. 목표 2는 자료형과 단위·Action의 단계 구분으로 실습 2/Q2에 대응한다. 목표 3은 timeout·취소·설정 수락의 한계로 실습 3/Q3에 대응한다.
- 사전 콘텐츠 7항목은 목표·선수, 설명의 자립성, 정확성, 예제·전이, 실습, 평가·해설, 자습 표현이다. 모두 2점이어야 통과한다. 웹 품질은 root가 별도로 검수한다.
- 정상 사례는 연속 관측/짧은 조회/진행과 취소/노드 설정이다. 실패 사례는 타입이 맞아도 단위가 다른 값, timeout 뒤 재시도 중복, 취소와 실제 정지 혼동이다. 경계는 재시작 뒤 설정의 지속 여부다.
- ROS 2 Jazzy의 공식 Interfaces/Topics/Services/Actions/Parameters 원문 5개를 직접 확인했다. 실제 ROS 실행은 하지 않는다.

## 작성·탈고·자기검수

- 상세 설명과 가상 Action 정의, 요구·기록 해석 실습, Q1~3 및 개별 해설과 부분 답안 피드백을 작성했다.
- 현재 10도/목표 30도/잔차 20도는 약 0.175/0.524/0.349 rad다. Q2의 목표 20도/잔차 30도는 약 0.349/0.524 rad다. Python 표준 산술로 확인했다.
- Topic과 수신 보장, Action 선언 순서와 시간 순서, 자료형과 유한값·범위·단위, timeout과 미실행, 취소와 실제 정지, 설정 수락과 영속화를 구분했다.
