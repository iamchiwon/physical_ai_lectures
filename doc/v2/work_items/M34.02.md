# M34.02 · 3D 장면과 로봇 상태의 좌표·시간·버전 동기화

- 날짜: 2026-11-09 / 상태: 탈고 완료·웹 검수 대기.
- 필수 선수: M34.01(관측/신선도), M06.01(열벡터·변환 방향), M14.03(시계/정합). 부족하면 해당 단원으로 복귀한다.
- 범위: 장비 없는 종이/기록표 기반의 단일 r1/bootA·ClockA·map-v7/model-v3 정합 판정. 실제 3D엔진/ROS/tf2·네트워크 동기화 구현/실물 검증은 제외한다. 일반 코딩/언어 문법은 설명하지 않는다. 표 분석으로 목표를 확인하므로 새 위젯/코드 실습은 불필요하다.

| 목표 | 활동/평가 | 사전 통과 기준 |
|---|---|---|
| 프레임/단위/변환 방향을 고정한다 | 90도 회전과 시각화축·Q1 | p_map=R_map_base p_base+t_map_base, (1,0,0)→(2,2,0)m. T반대/100배단위오류·렌더축변환과물리보정구분 |
| 동일시각·계약으로 장면을 판정한다 | 4자료표·Q2 | 관측1000ms와같은시각변환은허용, 최신1200ms변환혼합은거부. 시계미매핑/버전불일치/시각범위밖은미확인. 100ms표시지연과동기화오차를구분 |
| 개정/도착순서 변경을 다룬다 | 원자적스냅샷/再동기화·실습/Q3 | map-v8과v7·model-v4관절계약혼합금지, 앞세대seq와단순비교금지, 마지막정합장면과현재미확인분리. 수신/렌더시각으로stamp덮지않음 |

- 고정예: base점(1,0,0)m@1000ms, Rz(+90도), map에서base원점(2,1,0)m@1000ms→(2,2,0)m. 1200ms원점(3,1,0)을섞으면(3,2,0)m로1m차이지만같은시각위치라보고하지않는다. 평가시점1100ms·TTL200ms포함은100ms나이로표시허용. 두표본1100/1200의선형보간은명시한정속이동가정하에1150→(2.75,1,0)m; 회전/관절은동일일반선형보간으로확장하지않음. 측정이아닌추정임을표시한다.
- 실제공식자료: ROS2 Jazzy tf2 개념(시간별프레임관계/변환방향), REP103(단위/오른손·몸체/광학축). 공식문서웹은Anubis차단으로동일공식GitHub원본을2026-11-09확인. 자체map/model/교정버전계약은tf2자동보장이라하지않음.
- 기존6장평가의동일조건/로그문맥에장면정합연결을보충한다. 원문기준선보존·현재개정재승인은검수때수행한다.
- 통과: 내용7항목/웹1항목각2점자기검수. 본문/실습/3문제·개별해설, 수치/변형·버전/시계/외삽반례, 선수/후속/기존교재연결, 실제320px4답안/해설·저장/개정/완료·AI선택·이전M34.01/다음M34.03준비중이동, 카탈로그155ready/4partial/48tbd·기존자산·전체테스트/타입/린트/빌드로판정한다. 실제학습자/장비검증과구분한다.

## 작성

동일점의좌표→1000/1200ms혼합반례→신선도와정합→보간/외삽→버전원자전환→세대재동기화 순서로 본문·표/수식·장비없는실습·3문제/개별해설을작성했다. 기존6장평가와선수/후속을연결했다. 새코드/위젯은추가하지않았다.

## 탈고

내용7항목각2점자기검수. 회전/이동(2,2,0)·혼합(3,2,0)·차이1m·나이100ms·보간2.75m를별도계산해대조했다. 표의 ‘표현 가능’은해당시각좌표이며현재값판정과구분한다. 보간은정속위치의추정으로한정하고회전/관절일반화·외삽·버전/세대경계금지를명시했다. 대상/시계/개정누락·단위100배·역방향·이동만합산오답의피드백이목표와대응한다. 기존6장/선수/후속링크와본문·실습/문제·해설의계약이일치한다. 실제웹검수는다음단계이며기준변경없음.
