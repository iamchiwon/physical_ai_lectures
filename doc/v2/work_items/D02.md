## 작성 전 기준

| 기준 | 통과 조건 |
|---|---|
| 학습 흐름 | 홈→6개 경로 중 대표 경로→일부 준비 단위→실습 조작·문제 답안/해설→복귀/다음을 실제 수행 |
| 상태/경계 | TBD·보충만 있는 단위·잘못된 쿼리·없는 URL·첫/끝 이동을 정직하게 안내 |
| 기록 | 같은 문항의 입력·새로고침·다른 경로/탭 복원, 기존 완료/최고점·대화 보존. 방문≠신규 완료 |
| 평가 | 정상·오답·빈답과 API 실패/데모를 구분. 교재 해설/비교에 도달 |
| AI | 현재 단위·실제 코드 출처·선택 본문·TBD·구 Worker 제한, 모듈 대화 초기화의 범위 확인 |

- 실제 외부 AI·GPU·ROS·실물 명령은 제외. AI/평가 네트워크는 합성 fixture 또는 실패 응답으로 명시하여 UI 동작과 전송 문맥을 확인한다.
- 쓰는 origin은 임시 로컬 서버. 합성 기록만 사용하고 기존 로컬 키는 백업 후 복구한다. 결함은 기준을 유지한 채 보완·재검수한다.

## 검수·보완

아래 차수별 실제 검수·보완 기록을 참조한다.

### 1차 실제 흐름 검수

- ego-browser 공간8, 로컬 정적 서버4023에서 기존 physical-ai 키를 백업하고 합성 기록으로 진행했다.
- 신규 위치가 없을 때 기존 physical-ai-loop 이어 학습, 여섯 경로 노출 확인. 홈→로봇팔 추천 경로→M06.02→기구학 브라우저 모형을 실제 클릭으로 이동했다.
- q₁ 슬라이더를 키보드로25→26 변경하고 추종 실행, 목표(120,55)mm에 오차0.1mm까지 접근하는 개념 모형 표시 확인. 정밀 물리·실물 재현이 아님을 화면에서 확인했다.
- 빈 자가 점검의 확인 버튼 비활성, 첫 문항 오답→joint axis 해설, 둘째 문항 정답→예시 답안, 결과50점. 기존 별도 레슨90점/완료1개는 유지되고 신규 단위 completedAt=null이었다.
- 단위로 복귀→원래 보고서 textarea ID 앵커→합성 답안 입력/평가503 실패에서 답안 보존 확인. 실패 후에도 원본 해설·루브릭 비교에 도달할 수 있다.
- 처음 성공 fixture에 실제 계약과 다른 mode=demo를 넣어 검증 오류가 났다. 이는 fixture를 self-review로 고쳐 정상 UI 재검수했으며, 잘못된 서버 응답을 raw schema JSON으로 보여주는 제품 표현도 사용자용 오류로 보완했다.
- 다른 탭의 답안 갱신과 미완료 평가 응답 경쟁은 D04 검토에서 발견해 보완한 뒤 재검수한다.

### 보완 후 최종 실제 재검수 — 통과

- 보고서 평가 self-review 합성 응답의 피드백과 교재 해설·루브릭 비교를 확인했다. 실제 모델 응답이 아니다. 새로고침 후 같은 textarea ID/답안 복원, query 없는 동일 원문을 연 두 번째 탭에서 편집→첫 탭 최신 답안 갱신을 실제 확인했다.
- deferred 합성 평가 요청 중 두 번째 탭이 답안을 바꾸고 이전 응답을 해제했다. 새 답안 유지, `OLD_RESPONSE_MUST_NOT_ATTACH` 피드백 미표시, busy 해제 확인. 잘못된 응답 형식에는 schema JSON 대신 “평가 응답을 읽을 수 없습니다…” 안내를 표시하고 답안을 보존했다.
- 실제 브라우저의 legacy 진도 setItem에 quota 실패를 주입하고 레슨 완료 후 다른 탭에서 정상 원본을 저장했다. 첫 탭의 완료 표시/메모리 진도와 다른 탭 원본이 함께 유지되며 충돌 안내가 표시됐다. 실패 주입은 검수 후 복구했다.
- chapter-3/module-M06/module-M05 합성 대화3개에서 “현재 모듈의 대화만(1회)”와 옛 챕터 별도 안내를 확인하고 module-M06만 삭제했다. chapter-3·module-M05 유지, 전역 요약 null, 기존 점수90점 보존 확인.
- M06.02에서 실제 정적 JSON을 읽고 전달된 요청의 stable unit/track, partial 상태, `def dh_transform` 및 `legacy:asset:.../fk_dls_ik.py` 출처를 확인했다. 외부 생성 응답은 fixture로 대체했다.
- 보충만 있는 M21.05는 TBD·단위 완료 버튼 없음. 구 Worker health fixture에서는 본문 질문 차단/POST0회, 새 capability fixture에서는 readiness=tbd·공백·실습 상태 미전달을 실제 payload로 확인했다.
- 여섯 추천 경로를 실제 로드해 필수/선택 수(91/34,113/0,91/0,72/6,104/16,101/6)와 초기 JS 오류/미처리 거절0을 확인했다. 이는 공개된 일부 자료로 탐색할 수 있다는 검수이며 모든 경로의 신규 본문 집필 완료 판정은 아니다.
- 잘못된/중복 track query는 경고와 전체 순서로 복귀, canonical은 query 없이 유지. 전체 첫 M00.01/마지막 M33.06 경계 안내, 없는 단위 HTTP404 확인.
- 320px에서 긴 M14.03 제목 화면을 PNG로 저장·열어 확인했고 문서 너비320px이었다. 모바일 목차 summary를 키보드 Space로 접기/펼치기, 가로 넘침 없음 확인. 기존 수식18개/KaTeX 오류0, 센서 실습 코드2블록 및 320px에서 pre 내부 가로 스크롤(auto)·페이지 넘침 없음 확인.
- D01의 보완된 `/textbook/#glossary-practice`에 실제 도달해 FK 검색→설명 열기→순기구학 정의 확인.
- 마지막 코드 변경이 포함된 D03 테스트86개/타입/린트/정적 빌드 및 전수 링크 검수 통과를 받았다. 각 사전 기준 충족, 필수 결함 없음.
