# M34.03 · 운영 UI의 요청·권한·확인·취소·감사 기록

- 날짜: 2026-11-09 / 상태: 작성 완료·탈고 대기.
- 필수 선수: M34.01(관측/신선도), M22.06(감독/권한), M30.04(중단/미상). M34.02의장면계약을함께연결한다.
- 범위: 합성 요청봉투/허가표/상태·감사기록을 종이로 분석한다. 실제서버권한/인증/로봇명령/취소·정지·운영보안을구현/실증하지않는다. 코드/언어문법은제외한다. 새모형/실행코드없이기록표로판정가능하다.

- 고정계약: r1/bootA,map-v7/model-v3,ClockA. q17은교육용ID(암호학적지문아님), 요청은전진거리0.5m·속도상한0.1m/s의가상봉투다. 관측1000ms·TTL200ms포함, 요청권한/확인유효구간[1100,1200)ms. admission1110ms는나이110ms통과(정확범위/현재상태모두충족가정),1199는199ms/유효,1200은관측200ms경계허용이지만요청권한만료로거부. 실제전진/명령전송없음.
- 대표반례: viewer/다른robot·거리1.0변경/새map·동일키다른내용·응답단절·취소수락뒤실제속도미상·감사수집누락. 재확인과현재범위/관측을새로검사하며자동재개하지않는다.
- 공식근거2026-11-09: OWASP Authorization의최소권한/기본거부/매요청검사, Logging의시각·장소·주체·사건/연결ID·비밀제외; ROS2 Jazzy CancelGoal의수락=CANCELING. 이단원의자체요청봉투/기한정책은공식표준스키마아님.
- 기존6장평가/로그절에요청결정·취소와물리관측의연결을보충하고현재개정SHA를재승인한다.
