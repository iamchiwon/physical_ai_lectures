# M12.01 집필 기록

- 상태: 통과·완료 / 2026-11-03
- 범위: OpenCV 영상 배열/색/값 범위, 평균·중앙값과 차분의 작은 연산, 특징/대응의 한계와 검사다. 실제 OpenCV 실행/영상검출·추적 성과는 제외한다.
- 선수: M11.02 텐서와 M11.04 국소 연산, M11.05 출력 의미다.
- 목표 1은 HWC/색·dtype 계약으로 실습 1/Q1, 목표 2는 valid 필터/차분으로 실습 2/Q2, 목표 3은 특징/기하·오류 조건으로 실습 3/Q3에 대응한다.
- 정상은 float 합성 신호의 valid 평균/중앙값, 경계는 단일 밝은 픽셀을 잡음/마커로 해석하는 과제 차이, 실패는 RGB/BGR·uint8 랩어라운드·강한 특징=실제 물체 위치라는 오해다.
- 콘텐츠 7항목 모두 2점 필요. OpenCV4.x가 연결한4.13 공식 색변환/필터/산술/Harris 문서를 직접 확인했다. cv2는 로컬 부재, 선택 코드는 설치된 NumPy2.4.4 CPU로 개념 연산만 실제 확인한다. PDF/EPUB는 생성하지 않는다.

## 작성·탈고·자기검수

- 영상/색·dtype 계약·valid 필터/차분·특징/대응 한계의 세 목표가 실습과 Q1~3에 대응한다. OpenCV 함수의 문서상 동작과 NumPy 개념 실행을 명확히 구별했다.
- 본문 완전 코드를 직접 추출하여 Darwin/NumPy 2.4.4 CPU에서 실행했다. 평균[30,30,30]/중앙값[0,0,0]/차분[0,90,-90,0]/uint8합4/넓은합260이 일치했다. 회색 합76.245/29.07와 계단 필터·Q2평균20/중앙값0을 재계산했다.
- 전 섹션 자연어/축/값 범위·valid 경계/실행 한계와 부분 답 피드백을 탈고했다. 콘텐츠 7항목 자기 2점. 실제 OpenCV/카메라/특징 추적 성과 및 출판 생성은 없다.

- 독립 검토 보완: descriptor 첫 등장에 주변 패턴의 수치/이진 요약과 거리의 비유사도 의미를 정의했다. 작은 거리가 동일 물리점을 보증하지 않음을 연결하고 OpenCV 공식 matcher 자료를 추가했다. 계산/활동은 불변이다.
