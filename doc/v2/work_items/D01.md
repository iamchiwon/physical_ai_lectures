## 작성 전 기준

기존 A01 기준선, A03 정방향/역방향 매핑, 기준 커리큘럼, 현재 런타임 카탈로그와 실제 정적 산출물을 서로 대조한다. 새 교재 검증 스크립트는 저장소에 추가하지 않고 임시 감사 명령의 결과와 근거만 남긴다. 새 단위의 집필 품질·실물/GPU 실행·외부 모델 답변 정확성은 범위 밖이며 D02/D03의 브라우저·빌드 실행은 루트가 확인한다.

| 기준 | 통과 조건 |
|---|---|
| G1 전체 목차 | 기준 문서의 34모듈/204소주제 ID·제목·순서가 런타임/A03 매핑/정적 페이지에 일치 |
| G2 원본 보존 | 기존137 본문 청크·18레슨·142원본 파일·49예제·문항/해설/루브릭이 원래 식별자/해시/내용으로 보존 |

| G4 실제 도달 | 공개 자료 URL·문항/실습 앵커가 정적 산출물에 존재하고 홈/기존 목차에서 본문·요약·활동에 도달 |

## 독립 전수 감사·탈고

[전수 결과 JSON](../inventory/d01-audit.json)은 저장소 외부의 임시 명령으로 현재 원본·런타임·정적 산출물을 읽어 생성했다. 기존 테스트와 별도로 다음을 대조했다.

- 기준 문서와 카탈로그의 34모듈·204소주제 ID/제목/순서, A03의 안정204 unit ID 일치.
- 실제 `textbookUnits`137개를 원본31파일별로 다시 이어 붙여 **모든 원문 byte 일치**. 수식·코드·설명은 원문 전체 일치로 보존을 확인했으며 수식의 교육적 정확성을 새로 판정한 것은 아니다.
- A01의142 원본 파일을 SHA-256으로 대조하고 정적 `textbook-assets`의142 복사본도 원본과 byte 일치. 예제49개와 출판/참고·운영 문서도 원본 삭제 없이 유지한다.
- 실제 `exercisesForUnit` 결과126개의 원래 ID 및 **재계산한 reference SHA-256 전부 일치**. 99문항·27보고서의 해설/루브릭 참조 내용이 A03 기준선과 같다. 18레슨/36점검의 기존 ID도 일치.
- 333 Resource·191 Activity ID 중복0, 활동의 Resource/해설/루브릭 없는 참조0. Resource 구성은 본문137·요약18·파일104·그림38·점검해설36. Activity는 문항99·보고서27·요약점검36·실습21·브라우저모형7·용어1.
- 홈의 실제 HTML 링크 그래프에서 단위204·모듈34·추천경로6·기존본문137·요약18 = **399개 필수 경로 전부 도달**. 정확한126 답안 ID 앵커도 모두 존재한다.
- 준비 상태는 ready0/partial98/TBD106. 204개 단위 모두 슬롯별 보완할 범위가 있고 A03의 제안 준비도와 일치한다. 신규 본문을 작성한 것으로 승격하지 않는다.
- 본문 역색인은 direct93/context-only43/supplement-only1이며 후자44개에는 모두 보존 사유가 있다. 원본 파일 중 본선 탐색 제외31개도 각 사유를 JSON에 함께 기록했다. 출판/표지/참고 문서를 억지로 학습 가능 수에 더하지 않았다.

## 1차 감사 — 결함 발견·보완

- 결함: 단위에 binding되지 않은 `activity-legacy-glossary`가 published이면서 실제로 없는 `/glossary/`를 진입 URL로 가지고 있었다. 기존 용어 활동은 `/textbook/`의 `GlossaryPractice`에 있어 단위·HTML 링크 중심 검사에서는 등록 오류가 드러나지 않았다.
- 보완: `catalog-data.ts`의 진입 위치를 `/textbook/#glossary-practice`로 정정하고 기존 component section에 안정 anchor를 추가했다. 기존 glossary.md·Activity ID·저장 범위·준비 상태는 바꾸지 않았다. A03은 용어 원본 보존만 정의하고 잘못된 URL을 갖고 있지 않아 매핑 기준선 수정은 필요 없다.
- 회귀 검사: 기존 `tests/catalog.test.mjs`에 unbound를 포함한 published191 Activity의 모든 진입 경로가 보존된 실제 본문/요약/교재 인덱스인지 전수 검사 추가. `npm run test:catalog`28개 통과.
- React 스킬 및 로컬 Next.js `use-client` 문서를 확인하고 UI 변경을 section ID 한 개로 한정했다. 새 hook/상태/IO는 추가하지 않았다.
- 위 구현을 처음 감사했을 때 이전 정적 out에는 새 anchor가 없어 target541개 중1개가 미통과였다. D03 재빌드 후 동일 기준으로 재감사한다.

## 2차 재감사 — 통과

- D03이 수정 사항을 포함해 정적 산출물을 재생성한 뒤 같은 임시 감사 명령을 다시 실행했다.
- **독립 전수 검사22개 전부 통과**, 실패0/없는 target0. 등록된 Resource/Activity 진입 target541개 및 단위 자료 카드 projected link864개가 실제 정적 파일·페이지·앵커에 존재한다. glossary21 용어도 A01 수량과 일치한다.
- 새 용어 anchor가 실제 교재 인덱스 HTML에 존재하며 기존 모든399 필수 경로의 홈 도달성·126 답안 앵커·142 원본 hash·126 reference hash도 계속 통과했다.
- [d01-audit.json](../inventory/d01-audit.json)에 기준별 결과와 미본선 자료의 보존 사유를 남겼다. 검수 한계: 브라우저 실사용 흐름은 루트의 D02, 타입/린트/최종 빌드는 D03, 전체 통합 판정은 D04에서 결합한다.
