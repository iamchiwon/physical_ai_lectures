## 작성·탈고·자기검수

- 티칭 계약/보간→접근/확인/후퇴→구역/동적 여유를 자립 설명했다. 세 목표 각각 실습/Q1~3에서 관찰하며 실제 티칭 패널 설정 절차는 요구하지 않는다.
- 접근/후퇴 140/160 mm와 하한 2/2 s, 접근 변형 3 s 및 Q2 110 mm/2 s를 계산했다. 정적 여유 25/−5/5 mm, 합성 정지 거리 20/60 mm와 Q3 부족15 mm를 표준 Python 산술로 재계산했다.
- 제조사 문서의 feature/TCP·MoveJ/MoveL/블렌딩과 safety planes 검사 범위를 대조했다. 모형의 설계 여유를 σ/실제 정확도로 쓰지 않고 인증/전체 팔/실제 제동을 포함하지 않음을 명시했다. 기존3.5 heading/URL과 연결이 맞다.
