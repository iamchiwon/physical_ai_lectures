# M25.05 · Replicator·랜덤화·합성 라벨

- 날짜: 2026-11-09 / 상태: 작성 완료·탈고 대기.
- 필수 선수: M25.04. 카메라/분할은 M12.02·M20.03/.06 보충. 기존4장4.6/replicator_randomization.py를 읽어 camera고정·색/조명/target pose 랜덤화 및 RGB/radial depth만 쓰는 실제 범위를 구분한다. 문단의 camera랜덤화/라벨 범위·seed만 분리하면 된다는 공백을 함께 수정한다.
- 범위: 합성 생성 계획/manifest·채널/라벨/분할 기록 분석. 실제 Replicator/GPU/학습·이미지 생성/실물 일반화 실증이 아니다. 설치·언어/문법을 가르치지 않고 graph/trigger·annotator·writer/완료의 역할을 설명한다.

| 목표 | 활동 | 사전 통과 기준 |
|---|---|---|
| 랜덤화·캡처·라벨 저장의 계약을 설계한다 | 파이프라인·Q1 | 자산/의미→유효분포→동일capture/camera·시각/내외부파라미터→annotator/writer·완료/manifest를 구분. roughness/물리마찰·색지시/라벨과 무효배치·seed재현범위 구분 |
| 생성 계획의 완전성과 라벨/깊이를 계산·진단한다 | 12capture/3채널·실습/Q2 | 3asset×2light×2camera=12·채널payload36, B의mask1누락이면present35/완전11·수용33/남은2원본보존. classID사전/semantic vs instance, bbox반개구간·planeZ와radial거리 구분 |
| 분할 누수와 합성/실제 평가 범위를 판정한다 | asset홀드아웃·Q3 | A/B학습8계획→완전7, C평가4유지. 같은asset변형을프레임무작위분할해새asset일반화라하지않음. 생성완전11/12와인식성능분모를구분·실패/누락보존 |

- 입력: assetA/B/C 각각lightL0/L1×cameraC0/C1, 각capture에RGB/depth/semantic payload1개씩. manifest/ID사전은별도메타자료로36계산에서제외. 실제파일은없고제공명세/가상기록이다. B-L1-C1의semantic누락을실패행으로유지한다. 학습A/B·최종평가C는원자적asset단위분할로사전고정한다.
- 깊이 예: camera optical +Z앞쪽을선언한교육계약의점(1,0,2)m. planeZ2m·radial√5≈2.236m. 실제OpenUSD카메라축/ROS변환을이규약으로자동간주하지않음. bbox64×48픽셀의[xmin,xmax)×[ymin,ymax)와ID7→box 사전을제공하며다른writer관례는변환이필요하다.
- 실패/경계: 누락/중복capture·RGB와다른camera/tick라벨·배경0과미기록혼동·미등록ID·bbox범위/닫힌구간혼동·depthmode/단위누락·색언어모순·같은asset의분할누수·누락행삭제.12계획분모를11로바꾸어100%라고하지않음.
- 공식 근거: 2026-11-09 NVIDIA Replicator Getting Started/Randomization Snippets·1.13.30Annotator API·Visualizing Semantic Data. 역할과거리정의를확인하고실제실행/버전호환검증과구분했다.
