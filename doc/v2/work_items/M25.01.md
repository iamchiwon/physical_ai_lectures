# M25.01 · SimReady 자산·계층·단위·재질·물리 속성

- 날짜: 2026-11-09 / 상태: 분석·기준 확정.
- 대상: 일반 코딩 가능자. M10.05의 물리/렌더 시간, M12.02의 카메라 기하, M20.03의 데이터/메타데이터가 현행 필수 선수다. 좌표/질량 기초는 M10.02/.04로 보충한다.
- 기존 자산: M25 매핑의 2장 물리/재질과 create_physx_scene.py. 시각·충돌·질량 모델 구분은 재사용하고, 자산 계층/합성 단위·출처/검수 범위를 새로 연결한다. 기존 2장 선수 설명에 새 단원의 연결을 추가하고 지문을 재승인한다.
- 범위: 합성 자산 명세표의 종이 계산/결함 진단. 실제 USD/SimReady validator·Isaac Sim·GPU·접촉/실물 실행, 설치 명령·일반 언어/문법 설명은 제외한다. SimReady의 특정 profile/규격 인증을 이 교육용 활동으로 부여하지 않는다.

## 사전 목표·평가 기준

| 목표 | 활동 | 통과 기준 |
|---|---|---|
| 자산 계층과 시각·충돌·물리/재질 역할을 분리한다 | 경로표·Q1 | 루트/자식 변환·참조/override·동적 강체/정적 충돌·렌더/물리 재질을 설명하고, 스키마 존재와 실제 런타임 검증을 구분 |
| 합성 단위와 질량 입력을 검산한다 | 크기/밀도 실습·Q2 | 20×10×5cm→0.2×0.1×0.05m, 부피0.001m³, 500kg/m³→0.5kg. m 월드의 참조 보정 scale0.01. 메타데이터 변경만으로 수치 자동 변환 금지 |
| 검사 근거와 미확인을 기록하고 결함을 고친다 | 세 자산 비교·Q3 | 외관만 있음/잘못된 단위·바인딩/검사 기록 있는 후보를 비교. scope·profile/version·실행환경·원본/override 지문·관찰을 기록하고 정적 통과를 동적/실물 성과로 확대하지 않음 |

- 기본 입력: A(외관만), B(cm 원본20×10×5, m 소비 stage에서 보정 없음, mass=500 숫자를 kg처럼 입력, roughness만 변경), C(보정scale0.01, 물리mass0.5kg, 별도충돌/물리재질·계층·출처 기록). 모두 합성 명세이며 C도 실제 물리 실행 미확인이다.
- 경계/실패: metersPerUnit 미기입은 m로 임의 가정하지 않음; 참조 합성이 자동 단위변환을 보장하지 않음; 이중scale0.01·미해결참조·물리재질 바인딩 누락·roughness와 마찰 혼동·음수/0동적질량은 확인/중단 이유를 분리한다.
- 수치/예제는 교육용 조건이며 모든 제품/엔진/공식profile 공통 합격 기준이 아니다. 실제 API/규격은 버전과 목적을 고정해 확인한다.
- 출처: 2026-11-09 확인한 OpenUSD Linear Units·USDPhysics, NVIDIA SimReady FAQ/Foundation·재질 공식 자료. 최신 버전/설치 API를 기억으로 단정하지 않는다.
- 통과: 내용 루브릭 7항목 각2점, 원문·실습/3문제·개별해설 대응, 실제320px/저장·개정보존·명시적완료·전후이동·선택AI문맥·전체 자료 지문/카탈로그·빌드 검사 통과 후만 완료한다.
