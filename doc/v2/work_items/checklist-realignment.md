# 체크리스트 현행 순서 정합 · 2026-11-09

## 범위와 사전 기준

사용자 요청에 따라 변경된 커리큘럼의 작업 순서와 작업 단위를 체크리스트에 반영한다. 문서 관리 작업이며 신규 교재·프로젝트 구현·출판은 범위 밖이다.

- 런타임 `catalog`/`learningStages`와 승인 원고 상태를 기준으로 207개를 누락/중복 없이 배치한다.
- 기존 135개 상세 단위와 35모듈의 완료 체크를 보존하며 남은 72개만 신규 집필 큐로 옮긴다.
- 일반 코딩 가능자 전제·언어 문법 제외, 준비중 표시·PDF/EPUB 별도 요청 원칙을 유지한다.
- 소주제 1개, 집필 묶음, 프로젝트 실행 패키지, 구간 검수, 최종 경로 검수의 완료 조건을 분리한다.
- 신규 집필의 선수 조건을 거스르지 않는 순서와 다음 한 작업을 명시한다. 기존 기록은 삭제하거나 현재 완료로 소급하지 않는다.

## 검토에서 발견한 문제

1. 현행 순서 적용 설명을 추가했지만 문서 머리의 다음 작업은 여전히 E6 / M13.01이었다. S01에서 먼저 필요한 M31.01/.02가 후반 E9에 남아 있었다.
2. E6는 공통 S04의 인지 기초와 후반 트윈·전문화 SLAM을 한 묶음으로 관리했다. M31도 초반·모바일·후반 역할을 나누지 않았다.
3. 소주제 목록은 모듈 번호순이어서 실제 S/A 순서와 달랐고, 프로젝트 안내 공개와 실행 패키지 완료를 별도 작업으로 관리하지 않았다.
4. M34는 단위 체크에 추가됐지만 전체 집필 묶음에는 없었다. 계획/품질 문서에도 예전 수량·학습자 표현이 남아 있었다.

## 변경

- [전체 체크리스트](../checklist.md): W01~W15, PKG-P1~P4의 하위 작업, G-S00~11/G-A01~05, K01, F01~05로 분리했다. A01~D04와 E1~E5 완료 체크 및 당시 수량/다음 작업은 이력으로 보존했다. 미실행 E6~E9는 현행 작업으로 이관하여 이중 실행 큐를 없앴다.
- [단위 체크리스트](../unit_checklist.md): 207개를 S00~S11 → A01~A05 순서로 실제 재배치했다. 남은 72개에 W 묶음과 현행 allOf/anyOf 선수를 기재하고, 모듈 전체 완료는 마지막 별도 목록으로 보존했다.
- [실행 계획](../plan.md): 공통 공백 → 단계 프로젝트/연결 검수 → 전문화 → 최종 전수 검수로 우선순위를 갱신했다.
- [품질 기준](../quality_gate.md): 일반 코딩 가능을 전제로 언어·문법 입문을 제외하고 도구 선수를 보충한다는 사용자 조건을 명시했다.

다음 한 작업은 **W01 / M31.01 분석·학습 목표·평가 기준 확정**이다. 이 문서가 M31.01의 사전 기준 확정이나 집필 완료를 뜻하지 않는다.

## 검증과 판정

작성자 자기검수다. 별도 검수자나 신규 교재의 실제 학습자 검수를 수행했다고 주장하지 않는다.

- 실제 공유 TypeScript 정의를 임시 esbuild 번들로 읽고 승인/준비 상태와 단계 순서를 대조했다. 앱 소스나 승인 registry는 변경하지 않았다.
- 17단계의 207개 소주제 순서·제목이 현행 정의와 일치한다. 15개 W 묶음은 미완료 72개를 정확히 한 번씩 포함하며 공통 21개·전문화 51개로 나뉜다.
- 소주제별 기존 5단계 체크 **1,035개**와 모듈 상태 35개(기존 완료 22개)를 전후 대조하여 모두 보존했다. 상세 완료는 135개 그대로다.
- 묶음 사이·묶음 안의 미완료 allOf 선수 순서를 대조했다. anyOf는 이미 완료했거나 먼저 배치된 선택지가 존재하는지 확인했다. 새로운 실제 선수 계약을 임의로 추가하지 않았다.
- 프로젝트 하위 작업 20개, 구간 검수 17개, 캡스톤 하위 작업 4개, 최종 작업 5개의 작업 ID와 미체크 상태를 확인했다. 안내 페이지 완료만 별도로 보존했다.
- 세 실행 문서의 다음 작업이 W01 / M31.01로 일치한다. 역사 E5의 ‘다음 E6’는 과거 시점의 기록으로만 남겼다.
- 문서 내부 파일 링크·체크리스트 누락/중복·차이 공백을 검토했다. 문서 변경이므로 앱 테스트·브라우저·전체 빌드를 다시 수행하지 않았다. 2026-11-06의 테스트127 등은 당시 검증 근거로만 참조한다.

판정: 문서 정합 범위 통과. 신규 72개 소주제·프로젝트 실행 패키지·구간 검수는 준비중으로 유지한다. PDF/EPUB·출판 exporter·배포는 실행하지 않았다. 임시 전수 대조 결과: `/tmp/checklist-realignment-validation.json`.
