# M13.02 · 정합·ICP·대응점·잔차

- 갱신: 2026-11-09 / 상태: 분석·기준 확정.
- 작성/검수: 주 에이전트 작성·자기검수. 실제 PCL/Open3D/SLAM 실행이나 독립 검수로 주장하지 않는다.
- 범위: W02의 두 번째 단위. source→target 변환, 대응점과 잔차, 대응/변환의 교대 반복, 거리 문턱·초기값·반복 무늬·퇴화와 판정 기록.
- 선수: M13.01의 점군 계약/전처리와 그 선수 수학. 일반 코딩 가능을 전제로 문법·라이브러리 설치를 제외한다. 회전 기호는 본문에서 풀이하고 최적 회전/SVD 유도는 요구하지 않는다.
- 자산: [M13 매핑](../mapping/M13.md)의 독립 설명/실습/평가 없음. M15.04의 간단한 대응/SLAM 설명과 충돌하지 않게 이 단위에서 정합만 자립적으로 다룬다.
- 보존: unit-m13-02-a, authored:M13.02:practice/q1/q2/q3; 기존 URL/ID/답안 키 유지.

## 사전 목표·판정 기준

| 목표 | 설명·활동 | 통과 기준 |
|---|---|---|
| 변환 방향과 대응 가정을 구분하고 잔차를 계산한다 | source→target, Rp+t, 역변환, Q1 | 좌표 이름 변경과 변환 구분, 예측−목표 부호/단위와 회전 포함 역변환 설명 |
| 작은 ICP 한 회차와 거리 문턱의 영향을 계산한다 | source0/2/5/9, target1/3/6, t0=0, 거리≤1.2, 실습/Q2 | 3대응/1제외, t=1, 잔차0; 문턱.5의0대응은 성공/오차0으로 처리하지 않음 |
| 수렴·작은 오차와 올바른 정합을 구분한다 | 반복무늬 t1/t3, point-to-plane 벽의 접선 이동, Q3 | 대응 개수/비율·RMSE의 대상·중첩/기하/초기값을 함께 검토, 실제장소/물체정답 보장 금지 |

- 손계산: 길이m, y=z=0인1D 이동만 추정, source 원본 대비 누적t. 동일거리 시 target의 작은번호 선택. tau와 이상치 규칙/고정점 집합을 명시한다.
- 정상: t=1에서 source 첫3점이1/3/6에 일치하고9는10으로 변환되어제외. 원본분모4에대한대응비율3/4.
- 변형: target1/3.2/6의 고정대응에서 t=16/15m, 잔차1/15,-2/15,1/15m, SSE2/75m²·MSE2/225m²·RMSE약.09428m.
- 실패/경계: 문턱.5에서대응0개, 반복target1/3/5/7에서source0/2/4는t1과t3모두오차0; 실제모호성. 벽법선x와접선y이동.4의법선잔차0.
- 출처: [PCL ICP](https://pointclouds.org/documentation/tutorials/iterative_closest_point.html), [Open3D ICP](https://www.open3d.org/docs/release/tutorial/pipelines/icp_registration.html)의 공식본문을 확인했다. 특정API의fitness분모/정지기본값을 교재계약과 동일시하지 않는다.
- 콘텐츠7항목과실제웹1항목모두2점필요. 실제320px/수식/4답안·해설/저장·AI·이동을확인하기전검수체크하지않는다. 사전기준을결과에맞춰완화하지않는다.
