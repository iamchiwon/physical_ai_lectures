# M05.01 집필 기록

- 상태: 통과·완료 / 2026-11-03
- 소유: ebook/curriculum/M05/M05.01.md 및 본 기록. 기존 원고·runtime·registry는 수정 대상에서 제외한다.

## 분석과 사전 기준

- 범위: 워크스페이스·패키지·빌드·설치 환경·노드·프로세스·Executor의 관계와 합성 실행 기록 진단.
- 선수: M01의 경로·빌드·프로세스, M03의 센서와 구동기 역할. 기존 1.6의 상세 패키지 예제에 연결한다.
- 목표 1은 개발과 실행의 층위 구별이며 실습 1/Q1에 대응한다. 목표 2는 노드·프로세스·Executor 관계와 시간 계산이며 실습 2/Q2에 대응한다. 목표 3은 환경 실패와 콜백 지연의 증거 선택이며 실습 3/Q3에 대응한다.
- 정상은 성공한 빌드와 올바른 환경 및 콜백 기록의 연결, 실패는 옛 overlay와 긴 콜백, 경계는 한 프로세스의 여러 노드와 준비 뒤 대기다.
- 사전 콘텐츠 7항목은 목표·선수, 자립성, 정확성, 예제·전이, 실습, 평가·해설, 자습 표현이며 모두 2점이어야 통과한다. 웹 전달 품질은 root가 별도로 검수한다.
- 공식 ROS 2 Jazzy 원문을 기준으로 한다. Ubuntu 24.04/Jazzy 실제 설치나 실행은 수행하지 않는다.

## 작성·탈고·자기검수

- 용어와 개발·실행 경로, 가상 로그 실습, Q1~3 및 정답·부분 답안·오답 피드백을 작성했다.
- B의 대기/처리/전체 시간은 25/4/29ms, Q2는 8/5/13ms다. Python 표준 산술로 확인했으며 ROS 실행 결과가 아니다.
- 노드 수와 프로세스·스레드 수, 메시지 도착과 콜백 실행, 빌드와 현재 환경, 가상 순서와 일반 FIFO 보장을 구분했다.
- docs.ros.org 접근 차단으로 공식 ros2_documentation의 jazzy 브랜치 Workspace/Nodes/Executors 원문을 직접 확인했다.
