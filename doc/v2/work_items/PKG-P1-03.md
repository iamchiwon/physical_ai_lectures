## 실행과 판정

Python3.12.11/Darwin에서 다음 기능4종을 실제 확인했다.

1. 재생11행과 원래 frame ID/행수·상실/오래됨/모호함/형식오류·2회복귀·±.25 제한, 원본 입력 불변 및 source/input SHA 일치.
2. TTL100ms 허용/101ms 만료, 중복ID/역순/중복시각·잘못된 HWC축/width/RGB범위/bool/비유한 픽셀·미래/음수시각·누락영상의0명령/이유/복귀리셋. 비표준JSON 숫자는 전체입력오류로 처리하고 함수내 자료형오류와 구분한다.
3. 입력/기존보고서 덮어쓰기 거부와 원본보존, 잘못된JSON/설정·폐루프에재생입력/잘못된스텝수의 명시적CLI실패.
4. 기본 폐루프20스텝은 오차2/3→0과 offset변화를 확인했고 gain0대조군은 command/offset0·오차2/3에머물렀다. 실제 피드백과 단순 프레임출력을 구분한다.

기능4/4와 기존 전체회귀132/132 통과. `PHYSICAL_AI_PYTHON`으로 실제 검수 interpreter를 지정했으며 경로를 공통 시스템 환경변수로 재사용하지 않았다. 로그 `/tmp/pkg-p1-functional.log`, `/tmp/pkg-p1-03-test.log`. 새 앱 코드는 아직없어 전체 웹빌드를 반복하지 않았으며 다음 웹연결검수에서 수행한다.

해설은 정상/상실/최신성/축·복귀·명령한계·재생대비폐루프·이득0 비교와 제출근거/미확인을 설명한다. reference 두 모드의 실제수치와 일치하고, 코드·원본설정·입력을 해설에맞추려고 바꾸지 않았다. 검수는 자기검수다. 실제 ROS통신·영상장치·물리/안전·학습자의 수행/숙달을 입증하지 않는다.
