- 날짜: 2026-11-09 / 상태: 통과·완료.
- 사전 기준: 01의 기본 계약부터 04의 정확 지문과 사용자 기록 보존까지 다시 확인한다. 앞 실행 디렉터리/생성 보고서에 의존하지 않는 압축파일 재현, 7사례 결과와 원본 보존, 최종 문서 상태 일치를 요구한다.
- 방식: 동일 작성자의 별도 자기검수다. 독립 검수자·실제 학습자·실물 검수로 표시하지 않는다.

## 별도 실행

검수한 P3 ZIP을 새 임시 디렉터리에 풀고 Python 3.12.11에서 README 명령으로 7사례를 새 출력에 실행했다. CRC·13파일 목록/각 SHA·번들 SHA를 확인했으며, 각 보고서 전체가 reference와 일치했다. nominal은 18사건 READINESS_CONFIRMED, lease-expiry/cancel/no-stow는 각각 5/9/8사건 INCOMPLETE_READINESS, stale/wrong-identity/old-request는 1/1/2사건 INVALID_STOP이다. 입력/설정/소스/해설/reference 전체 지문이 실행 전후 같고 기존 출력 덮어쓰기는 종료 2로 거부했다. `/tmp/p3-isolated-review.json`.

별도 기능 6검사와 포장/웹 계약 3검사, 전체 153검사·타입·린트·전체 빌드 결과를 현재 변경 없는 실행 소스와 대조했다. 실제 웹 ZIP 다운로드 SHA도 동일하다. 최종 번들 지문은 `cd4057518da35d0f1f92b27ff4a5bc4a478cfd7240ba8e9f0a2ba6bf1cde9d5b`다. P1/P2 지문과 근거 ID는 유지했다. 승인 근거를 이 최종 기록으로 갱신한 뒤 포장/카탈로그 검사를 다시 수행한다.

웹의 별도 수행 근거는 단원 완료나 Activity 771개에 자동 합산하지 않는다. 준비중 상태는 P4 실행 패키지에 남기며 P1~3은 완료 배지 없이 제공한다. 상세 교재 145개·미집필 62개는 변하지 않는다. 원래 브라우저 저장은 04 종료 때 복원했다.

예약 만료와 점유 관측, Action 결과와 정지/물체/수납, 과거 허가와 현재 준비 상태를 해설·출력·웹에서 일관되게 구분했다. 실제 ROS/fleet·출발/도착·물체·충돌 안전은 미확인이다. 사전 기본 패키지 기준 충족이며 다음은 G-S09 연결 검수다. PDF/EPUB·외부 배포 없음.
