## 작성·탈고·자기검수

- 명령/상태/변환의 역할과 단위/축/영점, 표시/기구학/물리/제어/재현성 증거의 범위를 자립 설명했다. 세 목표가 실습/Q1~3과 정확히 대응한다.
- 길이 0.2 m→20 unit, 잘못된 0.2 unit→0.002 m와 오차 0.198 m, rad 제한 ±1→degree ±57.2958, Q2 0.3 m→30 unit 및 ±π/2→±90 degree를 재계산했다. 작은 양의 자세는 제한 안 q=0.5 rad로 두어 끝점 (0.175517,0.095885,0) m를 확인했다. multiline math 1개 KaTeX 통과.
- 모든 scale=1인 최종 길이 전제와 파일 속성/제어 API 단위 차이, 합성 보고서/실제 실행의 구분을 점검하고 전 섹션 자연스러운 띄어쓰기와 오답 피드백을 탈고했다. 콘텐츠 7항목 자기 2점이며 실제 importer/ROS/물리 실행은 없다.
