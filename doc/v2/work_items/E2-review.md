# E2 독립 콘텐츠 검수 기록

- 시작일: 2026-11-03 / 상태: M05~M08 24개 콘텐츠 검수 통과, 실제 웹/runtime 최종 확인은 루트 별도
- 범위: M05~M08의 24개 단위. 현재 M05~M08의 24개 콘텐츠 통과. 실제 웹/runtime 최종 판정은 루트의 별도 검수 기록을 따른다.
- 검수자/방식: 집필자와 별도 Codex agent의 독해·독립 계산·안전한 CPU 예제·공식 문서 대조. 실제 학습자·ROS/GPU/실물 실행을 수행하지 않았다면 수행했다고 기록하지 않는다.
- 기준: [품질 기준](../quality_gate.md), [통합 커리큘럼](../../integrated_curriculum.md), [E1 검수 기록](E1-review.md). 원고 수정은 작성자, 기존 원고 수정·runtime/registry·실제 브라우저 검수는 루트 소유다.

## 1. 선수와 학습 경계

M05는 M01의 셸/프로세스/실행환경·M03의 장치/인터페이스 계약을 사용한다. M06은 M02의 열벡터/프레임/미분/최적화와 M03의 기구를 사용한다. M07은 M06 기구학과 M02 안정성/오차 기초 위에 힘·시간응답을 추가한다. M08은 M05의 노드/패키지/tf, M06의 프레임/관절, M07.01의 관성 기초를 종합한다. 뒤 단위가 앞 단위의 미정의 개념을 사용하는 경우 보충 링크나 설명이 필요하다. E1 전체를 학습했다는 가정만으로 제어·ROS 용어를 생략하지 않는다.

기존 매핑 M05~08은 보존 자산/부분 설명의 연결 근거다. 기존 본문·요약·브라우저 근사·코드 파일을 신규 완결 단위나 실제 ROS 실행의 증거로 자동 인정하지 않는다. Ubuntu24.04/ROS2 Jazzy를 기본선으로 삼고, 실제 검산 환경이 macOS/Python 등일 때 구별한다. 장비 없는 합성 로그·행렬/종이 계산·모델 독해의 기본 활동은 필수이며 실제 설치/실행은 선택 경로로 구분한다.

## 2. 공통 판정 기준

내용7항목(목표·선수/자립설명/정확성/예제·전이/실습/평가·해설/자습흐름)을 각각 0·1·2점으로 판정하며 모든 항목2점일 때만 콘텐츠 통과다. 실제 웹 전달이라는 여덟째 항목은 루트의 별도 검수다. 세 행동목표·입력과 단계가 있는 실습/해설·Q1~3/개별해설은 직접 대응해야 한다. 숫자만 맞춘 부분답과 근거/조건 누락, 대표 오개념을 구별할 수 있어야 한다.

정의한 기호/축/시간·단위·부호로 모든 예제를 독립 계산한다. 긴 수식은 KaTeX 자체 검사와 remark-math의 inline/block 판정을 구분하고, 실제 화면 폭/접힘/코드 전달은 루트에 연결한다. 기술 불확실성은 저자/ROS 공식/제조사 등 primary source로 대조한다. 출처 접근 실패와 확인된 범위를 구별한다. 저장소에 새 교재 검증 스크립트를 만들지 않고 필요하면 일회성 계산을 쓴다.

## 4. 원고별 검수 기록

작성자 고정 알림 뒤 원고를 검토한다. 최초 결함·점수·수정 요청·재검수 근거와 통과 SHA256을 누적하고 루트에 정확한 SHA를 전달한다. 실제 연결/준비도 승격은 별도 registry의 루트 승인이다.

### M05.01 1차 독립 검수 — 콘텐츠 통과

- workspace/package/build/install/셸환경↔실습1/Q1, node/process/Executor/callback↔실습2/Q2, 환경탐색과실행지연 증거↔실습3/Q3가 대응한다. 단어와 산수만 맞춘 부분답과 환경/한계설명 누락의 차이를 해설에서 판정한다.
- 독립 계산: B대기30−5=25ms/처리34−30=4ms/전체29ms, Q2대기22−14=8ms/처리27−22=5ms/전체13ms다. 노드2/프로세스1/Executor사용스레드1을 구별하고 실제프로세스 전체스레드수를 단정하지 않는다. 관측획득age와준비부터처리시간도 분리했다.
- [Jazzy workspace 원문](https://raw.githubusercontent.com/ros2/ros2_documentation/jazzy/source/Tutorials/Beginner-Client-Libraries/Creating-A-Workspace/Creating-A-Workspace.rst), [nodes](https://raw.githubusercontent.com/ros2/ros2_documentation/jazzy/source/Concepts/Basic/About-Nodes.rst), [executors](https://raw.githubusercontent.com/ros2/ros2_documentation/jazzy/source/Concepts/Intermediate/About-Executors.rst)를 직접 대조했다. underlay/overlay·터미널별source·빌드터미널주의와rclcpp spin의단일스레드·callbackgroup/비FIFO한계가 맞다. 합성기록을 실제ROS결과로 주장하지 않고 제시셸명령도 준비환경을 갖춘 별도환경의 읽기예다.

### M05.02 1차 검수 — 문장 의미/가독성 보완 요청
