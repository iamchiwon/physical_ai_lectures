- 연결: [계획](../plan.md), [체크리스트](../checklist.md), [품질 기준](../quality_gate.md)

## 1. 분석과 작성 전 기준

- 범위: 191개 기존 활동을 원래 답안 ID와 평가 화면에서 재사용한다. 문항·보고서·자가점검·브라우저 모형·실습 원고와 해설/루브릭을 구분한다. 신규 집필은 제외한다.
- 학습자: 신규 목차에서 기존 콘텐츠로 진입하는 자습자. 단위의 선수 링크를 확인하고 관련 범위만 학습한다.
- 오개념: 일부 준비 자료를 전체 목표 충족으로 오인하거나 AI 평가를 실제 실습 실행으로 혼동할 수 있다.
- 목표·판정 기준: 문항 답안 직접 이동, 활동 종류/피드백 준비 상태 표시, 해설 원본 연결, 브라우저 근사 한계 표시. 기존 준비도 partial98/TBD106을 유지하며 동일 원본을 복제하지 않는다.
- 정상: 연결 자료를 열면 카탈로그에 지정한 원본이 열린다.
- 실패: 누락/무효 참조는 동작 링크 없이 사유를 표시한다.
- 경계: 보충 자료만 있는 TBD는 상태를 올리지 않고, 해설이 없는 활동은 그 부족분을 표시한다.
- 적용 루브릭: 내용 보존·상태 정직성·탐색 가능성·웹 전달 품질. 신규 콘텐츠의 학습 설명/예제 집필 평가는 이번 통합 범위 밖이다.
- 환경: Next 정적 export, 기존 URL·저장 키 유지. GPU/실물 실행 검수 아님.
- 기준 확정일: 2026-11-03. 기준 변경 없음.

## 2. 작성 산출물

- [자료 연결 helper](../../../apps/web/src/lib/study-resources.ts): 원본 URL·ID를 재사용하고 본문/요약/파일/활동 종류와 준비 한계를 구분.
- [학습 단위 화면](../../../apps/web/src/app/study/[unitId]/page.tsx): 연결 자료에 현재 단위·유효 트랙 복귀 문맥을 전달하고 피드백 상태를 표시. C05 담당의 AI 문맥 연결 적용.
- [연결 회귀 테스트](../../../tests/study.test.mjs): 모든 단위의 자산 URL, 모든 서술/보고서 활동의 답안 앵커와 원본 해설/루브릭, 브라우저 모형 앵커와 한계를 전수 대조.
- 기존 본문·수식·코드·활동·답안 키는 변경/복제하지 않음. 기존 partial98/TBD106 준비도 유지.

## 3. 탈고

- 신규 단위 → 자료 종류/목표 충족 한계 → 원본 절/활동 → 기존 입력/해설 → 단위 복귀 순으로 자기검수.
- 보완: 기존 자료의 일반적인 “자료 열기”를 상세 절/요약/원본 파일로 구별했고, 긴 활동 목록에서 같은 문제 페이지 처음으로 반복 진입하던 링크를 정확한 기존 답안 앵커로 변경.
- 보완: context-only 평가에는 개별 모범답안 미작성을 표시하고 브라우저 계산 모형은 실제 실행과 구분.
