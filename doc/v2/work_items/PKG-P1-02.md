## 산출물과 실행

[examples/P1](../../../examples/P1/)의 runner.py, config.json, frames.json, SPEC.md, README.md, reference2개를 구성했다. 입력은 작은 RGB8 HWC11프레임이고 감지·관측 검증·상태/명령을 분리한다. 고정 재생과 명령이 다음 영상을 바꾸는 합성 폐루프20스텝을 별도 모드로 실행한다. 실제 ROS adapter는 포함하지 않고 학습한 노드/Topic 책임과 메시지 계약을 대응한다.

호스트의 `/Users/iamchiwon/.pyenv/versions/3.12.11/bin/python`(3.12.11/Darwin)을 사용했다. 외부 패키지·네트워크·GPU/실물 설치·실행 없음. CLI의 입력/설정/소스 보호와 기존 결과 보존을 구현했다. 설정 조작의 허용 수치 범위를 SPEC에 명시해 모호한 임의 설정을 숨기지 않았다. 정상 계약의 기대값/복귀 조건을 낮추지 않았다.

실제 reference 재생11행의 상태는 ACQUIRING3/TRACKING3/LOST1/STALE1/AMBIGUOUS1/INVALID2다. 오른쪽/왼쪽 명령±.25, 폐루프 초기 정규화 오차2/3→마지막0, 마지막offset약1.7을 확인했다. source/config/input SHA와 실행 Python/플랫폼을 각 reference 보고서에 남겼다.
