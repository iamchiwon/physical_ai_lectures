# PKG-P1-01 · 실행 범위·입출력·환경·판정 기준

- 날짜: 2026-11-09 / 상태: 통과·완료(명세 작업만).
- 선행: W01·G-S00·G-S01 완료. M05.01/.02·M12.01은 기존 승인 원고다.
- 산출물: [P1 실행 계약](../../../examples/P1/SPEC.md).

## 사전 기준과 결정

첫 프로젝트가 후반 팔 기구학·ML·PID 전체를 새 필수로 요구하지 않아야 한다. RGB/시간/단위·관측 상실·오래된 관측·명령 제한·복귀의 판정이 입력/산출물에서 관찰 가능해야 한다. 환경·정상/실패 기대값·허용 오차·비목표를 구현 전에 정한다.

기본 실행은 Python3.12.11 표준 라이브러리와 작은 합성 RGB 장면으로 고정한다. 로컬 감지/명령 구성요소를 분리하고 ROS Topic/상태의 계약과 대응시킨다. 실제 ROS 미들웨어/카메라/모터와 물리 시뮬레이션은 별도이며 실행하지 않은 성과를 프로젝트 완료로 주장하지 않는다. GPU/설치가 기본 완료를 막지 않게 한다. 호스트에는3.12.11이 설치되어 있음을 확인했으나 실제 스타터 실행은 다음 작업이다.

고정 프레임 재생과 명령이 다음 관측을 바꾸는 합성 폐루프를 별도 모드로 정했다. 단위는 실물 속도가 아닌 가상 픽셀/스텝이다. TTL100ms·연속유효2회 복귀·빨강 단일 성분·잘못된 축/미래시각/중복시각/다중 성분의 판정을 명시했다. 명령 한계·형식 오류와 결과 이유·입력 보존을 요구한다.

## 명세 자기검수

11개 재생 행의 상태 집계를 TRACKING3/ACQUIRING3/LOST1/STALE1/AMBIGUOUS1/INVALID2로 대조했다. 정상 오른쪽/왼쪽 오차±2/3에 gain0.6을 곱하면±0.4, 제한 후±0.25가 된다. TTL경계=100과 만료110을 구분했다. 관측 상실/오래됨/모호함/형식 오류 뒤 유효1회는0명령이며2회 이후 재개한다. 입력과 출력은 별도 경로로 고정한다.

부족한 코드·고정 입력·실행 로그·해설·다운로드/웹 연결은 다음 작업으로 남겼다. 구현/실제 실행·웹 공개·P1 전체 완료를 주장하지 않는다. 기존4프로젝트 안내의 목표/관련 소주제와 충돌하지 않음을 읽기 검토했다. 일반 코딩 가능자이므로 언어/문법 설명을 추가하지 않는다.
