## 1. 선수 범위·기존 자산 분석

M00는 로봇·제어·ML 선수를 요구하지 않는 진입 모듈이다. 컴공 졸업 배경이 있어도 Python 문법·벡터·조건부확률·제어·ML 지식을 자동 가정하지 않는다. M00.01부터 최소 용어를 정의하고, 깊은 구현/수학은 M01~M03 브리지로 분기한다. 심화 도구 설치·GPU·실물 장비는 기본 활동의 선수가 될 수 없다.

기존 상세1.1은 상태·관측·정책·안전 계층과 POMDP 개요를 제공하고, `/learn/physical-ai-loop/`는 두 절의 짧은 요약·자가 점검이다. 두 자산을 신규 완결 단위로 자동 간주하지 않는다. 기존 지연 실습은 로컬 코드 계측 활동으로서 신규 초심자용 표 해석 활동과 구분한다. 기존 환경/안전 원고는 참조 자료이며, 특정 GPU·로봇 구성을 M00 필수 장비로 승격하지 않는다.

## 2. 단위별 통과 기준

평가 점수는 0=미충족/1=보완필요/2=충족이며, 합계와 관계없이 아래8항목이 모두2점이고 필수 결함이 없어야 해당 단위 콘텐츠를 통과한다. 브라우저 전달/저장/AI 실제 기능은 루트의 별도 통합 확인 근거를 연결해야 최종 공개 승격 가능하다.

1. **목표·선수**: 설명/계산/분류/실패 진단처럼 관찰 가능한 목표, 필요한 용어·선행 링크, 선수 미충족시 보충 안내.
2. **설명 자립성**: 첫 등장 기호·단위·가정·영어 용어를 설명하고 왜→어떻게→한 사례의 논리가 이어짐. 관련 기존 본문을 열지 않아도 기본 활동 수행 가능.
3. **정확성·일관성**: 수식의 시간 인덱스·차원·부호·코드 결과가 일치하고 모델 가정·실제 미검증을 표시. 비유의 한계와 출처 범위 명시.
4. **예제·전이**: 풀이가 있는 대표 예시와 입력/조건을 바꾼 응용 또는 반례. 예시 수치를 실측값으로 오인하지 않음.
5. **활동 구성**: 장비 없는 입력·절차·예측/관찰·해석·실패 안내. 단순 원문 읽기나 답 보기만으로 수행 완료를 주장하지 않음.
6. **평가·해설**: 목표별 문항과 판정기준, 정답뿐 아니라 이유·대표 오답·부분답안 보완. 단답 키워드 일치를 이해/숙달과 동일시하지 않음.
7. **자습 흐름·표현**: 한 단위의 범위를 유지하고 제목·목표·활동·평가 순서가 일관됨. 미작성 브리지와 실제 가능한 연결을 구분.
8. **웹 전달·근거**: Markdown/수식/표/코드가 현재 렌더러로 표현 가능, 내부 링크·안정 unit ID·활동 ID·원본참조 일치, AI가 읽는 본문과 화면 원문 일치. 실제 화면 최종 검수는 루트 증거로 확인.

**필수 중단 결함**: 중대한 사실·수식·정답 오류, 설명 없는 선수 도약, 수행 불가한 기본 활동, 목표와 모순되는 해설, 실제 장비를 무감독 구동하게 하는 절차, 안전 인증/실행 결과의 허위 주장, 기존 원문/답안 소실, TBD의 잘못된 완성표시.

## 3. 출처 검토

- POMDP 개요는 Cassandra·Kaelbling·Littman의 [AAAI1994 원문](https://cdn.aaai.org/AAAI/1994/AAAI94-157.pdf) §POMDP·Figure1의 정의와 대조했다. 환경 상태와 내부 belief를 구별하고, 관측모형은 행동 이후 상태에 대한 분포로 정의될 수 있으므로 단순화 표기는 가정과 시간축을 밝혀야 한다. 물리 세계뿐 아니라 가상 환경도 부분관측을 가질 수 있다.
- 기존1.1의 tuple에 등장하는 gamma 설명 누락과 행동독립 관측모형 가정 미표시는 루트에 기존원고 개선사항으로 전달했다. 새 원고에서 불완전한 표기를 설명 없이 복제하지 않도록 저자에게도 알렸다.
- 로봇 안전 관련 본문은 일반 교육상 한계·작업중단 원칙을 검수한다. 법적 인증이나 실제 장비 안전성을 판정하지 않으며 제조사 절차를 임의로 대체하는 수치를 추가하지 않는다.

## 11. M03 및 E1 콘텐츠 검수 결론

M03.01~06 여섯 단위의 정의·수치·관측/추정과 모형조건, 활동/문항/해설 대응을 독립 검토했다. 기본활동은 합성문서/종이계산으로 가능하며 부품구매·실배선/인가·실물실행을 요구하지 않는다. 여섯 단위 모두 내용7항목2점이다.
