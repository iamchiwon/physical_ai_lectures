# M12.06 집필 기록

- 상태: 통과·완료 / 2026-11-03
- 범위: 검출의 일대일 score 순서 매칭과 TP/FP/FN·P/R, score/IoU threshold와 AP 집계 차이, 작업 성공·오류 비용 및 선택 얼굴 비교다. 실제 검출/얼굴 인식/작업 실증은 제외한다.
- 선수: M11.05의 지표와 M11.03의 시험 잠금, M12.02~05의 공간/추적 한계다.
- 목표 1은 중복/미매칭과 P/R로 실습 1/Q1, 목표 2는 두 threshold/평가 조건으로 실습 2/Q2, 목표 3은 작업 성공/추가 증거로 실습 3/Q3에 대응한다.
- 정상은 두 정답/세 예측의 TP2/FP1, 경계는 score와 IoU·개체 중복·분모0, 실패는 검출 정답을 파지 성공/얼굴 검출을 identity 검증으로 읽는 경우다.
- 콘텐츠 7항목 모두 2점 필요. COCO 공식 evaluator의 score/IoU/매칭/집계, scikit 지표와 NIST FRTE1:1 공식 검색 자료의 FMR/FNMR 구분을 확인했다. 얼굴은 개념 선택 비교이며 수집/식별은 하지 않는다. PDF/EPUB는 생성하지 않는다.

## 작성·탈고·자기검수

- 단순 일대일 매칭/지표·threshold/집계·작업 판정의 세 목표가 실습과 Q1~3에 대응한다. ignore/crowd 없는 자체 규칙과 실제 COCO 전체 구현을 구분했다.
- IoU9/11, 세 조건의 count2/1/0 및1/0/1 및1/2/1과 P/R, Q1 중복1/1/0·P0.5/R1, 작업 성공6/10 및12/20을 별도 Python 매칭 산술로 확인했다.
- 작업 기준에 bin 안 중심/1 s 유지·취득부터2 s 기한·충돌 조건을 명시하고, 선택 얼굴 비교와 필수 컵 활동을 분리했다. 전 섹션 가독성/부분 답 피드백을 탈고했고 콘텐츠 7항목 자기 2점이다. 실제 성과와 출판 생성은 없다.
