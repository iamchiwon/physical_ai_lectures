# UX01 · 답안 확인·평가·해설 공개

- 2026-11-11 / 구현·검수 통과. 작성자 자기검수.
- 사용자 요청: 각 학습단위의 답안 저장 버튼을 확인하기로 변경하고, 해설/판정 기준에 따른 평가 결과와 저장을 제공한다. 한 번 확인하거나 저장 답안이 있을 때만 해설을 자유롭게 열고 수정/재확인할 수 있어야 한다.

## 기준

- 빈 답안/최초 방문은 확인 불가·해설 본문과 열기 컨트롤 비노출. 유효한 짧은 숫자 답안도 허용한다.
- 확인 시 답안을 먼저 기존 저장소에 저장하고 해당 문제/실습과 실제 해설을 기존 평가 API에 전달한다. 현재 답안의 피드백을 표시·저장한다. 새로고침 후 답안/피드백/해설 열람을 복구한다.
- 확인 후 또는 기존 저장 답안이 있으면 해설을 자유롭게 여닫는다. 수정 중에는 옛 평가를 새 답안의 결과로 표시하지 않고 다시 확인할 수 있다.
- 실패/연결 미설정은 평가했다고 꾸미지 않으며 저장된 답안/해설 권한을 유지한다. 저장 실패는 성공이라 표시하지 않는다. 다른탭/늦은응답·내용개정과 기존 답안/완료/대화를 보존한다.
- 확인/AI 피드백과 명시적 자기검토·단위 완료를 구분한다. 기존 학습완료/저장 형식·현재207원고 지문은 유지한다. 같은 컴포넌트를 사용하는 프로젝트 수행근거도 문제/기준을 정확히 연결한다.

## 구현

서버 페이지에서 실습/문제와 해설 원문을 직렬화 가능한 평가 입력으로 전달한다. 클라이언트는 유효한 확인 시도/저장 답안으로 해설을 공개하며 초깃값은 닫힌 잠금 안내다. 기존 저장 스키마의 feedback 필드를 사용한다. 평가 응답은 동일 활동/개정/답안에만 기록하고 수정/이동 시 요청을 취소한다. 평가 실패에도 먼저 저장한 답안은 남는다. 실제 모델 연결이 없는 self-review 응답은 연결 안내로 표시하고 자동 판정을 꾸미지 않는다.

- 추가 사용자 요청: 확인 중 버튼은 말줄임표 없이 `확인 중` 문구 오른쪽에 회전 스피너를 표시한다. disabled/aria-busy와 보조기술 상태 안내를 유지한다.

## 검수

전체 테스트188/188, 타입·린트·shared/web/API dry-run 빌드와 공개본 비노출 검사(텍스트2942개·압축43항목)를 통과했다. 신규 검사는 최초 해설 비노출, 평가 저장/복구, 동일 답안 재확인 시 이전 평가 제거, 늦은 응답/개정/다른 탭 보존, 숫자 답안, 본문 전달 및 구형 API 응답 차단을 포함한다.

실제 브라우저에서 새 답안/저장 답안/이전 개정 답안, 확인 전 잠금·확인 중 해설 열람, 수정/재확인/새로고침, 자기검토, 통신 실패·지연 응답·저장 용량 실패 후 재시도, 프로젝트 입력/문맥을 확인했다. 320px 화면에서 버튼 오른쪽 스피너·말줄임표 없음·키보드 조작을 확인했다. 검수 데이터는 원래 브라우저 저장 상태를 백업 후 격리하고 종료 시 정확히 복구했다. 브라우저 평가는 고정 응답으로 UI/전달/저장을 검증했으며 실제 모델의 정답률 실험을 수행한 것은 아니다. PDF/EPUB·배포·실물 실증은 수행하지 않았다.

## 평가 문맥·모범답안 위험 검토

기존 신규 단위의 평가는 문제/학생답안/해설만 전달하고 본문을 전달하지 않았다. 기존 프롬프트는 긴 문제해설/보완예시와 근거가 부족한 추론을 허용해, 본문의 가정·좌표/시간/단위·가상/실물 범위를 벗어날 위험이 있었다. 원래 응용교재 평가에서는 관련 본문/요약 일부를 reference에 묶지만 신규 단위에는 이 연결이 없었다.

현재 신규단위에는 본문 전체·목표/선수범위·공통실습입력을 context로, 현재문제와 그 해설을 별도로 전달한다. 전체207개 원고의 본문+실습 최대8340자로 context한도32000 안이며 자르지 않는다. 프로젝트는 목표/수행범위/환경·산출물/기준을 전달한다. 선행단원 전체나 외부링크 본문을 자동조회한 것으로 표현하지 않는다. 기존 3필드 호출은 호환하되 문맥이 없을 때 제한된 근거만으로 판단하도록 한다.

평가는 판정·잘한점2개/보완점3개 이내·필요시 질문1개로 제한하고, 본문 절/문제/해설의 짧은 근거를 요구한다. 긴 모범답안/새 조건 생성은 금지하고 타당한 대안풀이를 인정한다. 누락/상충 근거는 판정유보로 처리한다. 출력예산은4096→1536토큰으로 줄였다. 이는 근거누락/과도한확장을 줄이는 조치이며 모델의 모든 사실/산술 오류를 검증/제거했다는 뜻은 아니다.

본문 context를 보냈는데 서버가 모델 전달을 확인하지 않는 구형 응답이면 그 평가를 표시/저장하지 않는다. 재확인 시에는 동일한 답안이라도 옛 피드백을 지우고 새 평가를 기다린다. 이 확인은 서버의 문맥 전달 여부이며 모델이 실제로 모든 문장을 올바르게 추론했다는 보장은 아니다.
응용교재의 개별해설 없음 안내에서도 추론 모범답안을 유도하던 문구를 판정 유보로 바꾸고 파생 참조 지문을 재생성한다. 원래 교재 파일/문제 ID/저장 키는 보존한다.
