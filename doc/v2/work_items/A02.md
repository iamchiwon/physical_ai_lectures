## 1. 작성 전 분석·통과 기준

- 범위: 영역·경로·모듈·소주제·학습 단위·자산 참조, 안정 ID·기존 URL, 준비도·통계, 선수 조건·다음 이동, 저장/AI 호환 계약.
- 제외: 앱/공유 스키마 구현, 데이터베이스 도입, 전체 204개 상세 매핑(A03), 실제 데이터 이행·브라우저 검증·배포.
- 학습자 관점: 어디서 무엇을 배울 수 있는지, 기존 학습을 잃지 않는지, 미작성·일부 준비를 정확히 구분하는지 평가한다.
- 기준 확정일: 2026-11-02. 아래 G1~G7을 문서 작성 전에 정했으며 작성 후 기준을 낮추지 않았다.

## 3. 탈고

기존 FK 자료를 보고 일부 학습 가능한 경우, 제목만 있는 신규 단원, 공유 트랙·답안·삭제 범위를 따라 검토했다. 실습의 해당 없음/선택 심화와 실제 미작성 항목을 구분했다. 원문을 열 수 있다는 사실만으로 신규 목표가 모두 충족된다고 오인하지 않도록 예시를 partial로 유지했다.

## 4. 검수·보완 기록

### 1차 자기검수 — 보완 필요

- 일시/방식: 2026-11-02 / 계약 문구와 JSON·판정 사례 대조.
- G1/G2/G4~G6의 설계 방향은 충족하나 G3/G7에서 판정 세부 규칙 보완 필요.
- 발견: supplement 링크만으로 partial 산정할 여지, 여러 부분 설명의 자동 full 합산 모호성, passed 근거/revision 필드 부족, 선수 정의 미확정 상태의 ready 가능성, 필수 단위가 없는 집계의 ready 위험.
- 보완: primary/supplement·유효 학습 자산 정의, 목표 충족 집합 통합 검수·evidenceRef/revision 필수, 선수 없음 명시, 빈 필수 집계 오류 규칙 추가. ID alias 예시는 기존 ID→Resource ID 연결만 남겼다. 보완 사항을 S17~S20에 추가했다.
- 사전 G1~G7 기준은 변경하지 않았다.

### 2차 자기검수 — 통과

- 일시/방식: 2026-11-02 / 보완본 문서 규칙과 사례의 정적 대입·실제 기준선 대조.
- 판정 기준: 0=미충족 / 1=수정 필요 / 2=충족. 적용 G1~G7 전부 2점, 필수 결함 없음.

| 항목 | 판정 | 확인 근거 |
|---|---|---|
| G1 | 2 | 계약 §2~§3: 7영역·6트랙·34모듈·204소주제, unit/resource/activity 참조와 분할·공유 규칙 |
| G2 | 2 | 계약 §3·§7: 원래 ID·URL·문제 키 보존. 예시 FK ID/source/URL/SHA-256을 A01 기준선과 대조 일치 |
| G3 | 2 | 계약 §4·§6: 필수 슬롯·목표 coverage·검수 revision·선수 정의·primary/선택 항목 구분, S01~S20 기대 판정 대입 |
| G4 | 2 | 계약 §5~§6 및 C01~C04/C08~C09/C20: 경로·TBD·이어 학습·중복 제거·완료율과 과거 기록 구분 |
| G5 | 2 | 계약 §7 및 C05~C11/C17: 기존 키 보존·idempotent 어댑터·실패·새/옛 대화 삭제 범위 정의 |
| G6 | 2 | 계약 §8 및 C12~C16: 새 위치·활동 상태·Resource 자료 조회·TBD·배포 조합 호환과 제한 동작 |
| G7 | 2 | 계약 §9: A03/B/C/D 책임 분리. JSON 예시의 실제 참조/목표·공유 unit 유일성·링크/사례 수 확인 |

확인 결과:

- 기준 커리큘럼 소주제 204개에 예시의 M06.02/M23.04가 존재.
- 실제 FK 원본의 ID·URL·source·기준 파일 지문과 현재 SHA-256 일치.
- 두 track fragment는 같은 unit 하나를 공유. 목표 참조·Resource 참조에 누락 없음.
- 준비도 S01~S20, 호환 C01~C20의 40사례를 명시하고 계약과 모순 없는지 자기검토. 이는 실제 앱에서 40개 테스트를 실행해 통과했다는 뜻이 아님.
- 문서 상대 링크 깨짐 0, JSON 파싱/예시 참조 대조 오류 0, `git diff --check` 오류 없음.

미실시: 앱 타입/Zod 구현·전체 매핑·localStorage 이행·브라우저·외부 AI 호출·빌드·배포. 문서/설계만 변경하여 런타임 테스트는 새로 실행하지 않았다. A01의 19개 기존 테스트 통과와 이번 문서 검수는 별개의 근거이다.

최종 자기검수에서 미통과 항목은 없으며 범위를 넘는 구현 검수는 A03/B/C/D의 사례로 유지한다.
