# M14.03 집필 기록

- 범위: 시계 offset/드리프트와 취득/수신, 멀티레이트·보간의 온라인 가능성, Jazzy ApproximateTime의 큐/선택·허용시차와 공간 오차다. 센서별 정합/필터 추정·실제 ROS 실행은 제외한다.

- 목표 1은 clock 변환/구간으로 실습 1/Q1, 목표 2는 보간/지연·각도 경계로 실습 2/Q2, 목표 3은 큐 매칭/시간 예산으로 실습 3/Q3에 대응한다.

- 콘텐츠 7항목 모두 2점 필요. Jazzy message_filters Python 공식 구현과 tf2/time 자료를 직접 확인했다. 큐 실행은 합성 도착 순서의 독해이며 실제 ROS 호출로 표시하지 않는다. 위젯은 별도 단순 투영 보충이고 PDF/EPUB는 생성하지 않는다.
