# M28.01 · IVN·물리 계층·토폴로지·중재·프레임

- 날짜: 2026-11-10 / 상태: 분석·기준 확정.
- W09/A01. 필수 선수 M01.03·M03.04·M04.04. 일반 코딩 가능자를 대상으로 언어 문법 없이 차량 내 통신(IVN)의 계층·고속 Classical CAN 기초를 독립 집필한다. 기존 독립 교재/실습/평가는 없다. 기본 경로는 자체 가상 버스 그림·비트열·수치표의 종이 분석이며 실제 차량/장비 연결·송수신/수리·규격 적합성 검증을 수행하지 않는다.

| 목표 | 활동/평가 | 사전 통과 기준 |
|---|---|---|
| 계층·물리 구성과 수신/동작 근거 구분 | 계층/종단 그림·Q1 | 응용 신호 계약/제어기/트랜시버·TXD/RXD와CANH/L 구분. 11bit ID는 메시지/중재 용도이며 목적지/발신자 인증 아님. 고속 선형 간선 양끝120Ω의 이상 병렬값 두개60/세개40/한개120Ω 계산. 수치만으로 실제 배선/반사·전원/통신 정상 판정 금지. ACK는 수신 노드의 링크 확인으로 응용 처리/물리 동작/인증 보장 아님 |
| 비파괴 중재 추적과 범위 제한 | 동시 ID 비교/동일ID 반례·Q2 | 같은11bit Classical 데이터 프레임이 같은SOF부터 경쟁,dominant0/recessive1·MSB우선. A0x120=00100100000/B0x100=00100000000의첫차이는ID bit5(여섯째),B승리/A후퇴. 버스 사용 중인 프레임 선점 아님. 같은ID/다른payload는 안전한 동순위 공유 아님. 다른 형식의 정수ID만 단순 비교하지 않음 |

- 정확성 자료 확인: Microchip CAN Protocol Fundamentals(2026-03-26 갱신)의 계층/메시지/0우세 중재, dsPIC30F Section23 DS70070D §23.5.1.1/23.5.1.5·Figure23-3의11bit/dataRTR0·CRC15+1/ACK2/EOF7/intermission3, TI SLOA101B p6의 고속 간선/양끝120Ω를 2026-11-10 확인했다. 제조사 문서의 특정 장치 레지스터를 일반 설정값으로 옮기지 않는다. TI 본문의 RTR/IFS/CRC 관련 혼동 표현은 근거로 사용하지 않는다. 자체 가상 수치/계산과 실제 측정은 구별한다.
- 기존 교재4.4의 시간 계약 설명을 유지하면서 CAN ACK/수신시각이 표본 생성/실제 동작 증거가 아니라는 연결 문단과 M28.01 링크를 추가한다. 기존 코드/수식·ID/URL/원본 지문 기준선을 보존하고 현재SHA를 재승인한다. W08→현재→M28.02 연결을 확인한다.

## 탈고
