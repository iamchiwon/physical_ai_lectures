# 조사 방법과 확인 범위

## 1. 범위와 기준일

- 조사일: 2026-11-02 (KST).
- 대상: 패스트캠퍼스가 공개한 로봇공학·Physical AI·모바일 로봇·로봇팔·휴머노이드·로봇 비전·SLAM·시뮬레이션·로봇 임베디드·차량 센서/통신 과정. 인접 FPV·블록 코딩, 이전 CAMP, 세미나는 별도 분류.
- 일반적인 AI·LLM·디자인·3D 영상 제작 과정은 로봇 시스템과의 직접 연결이 확인되지 않으면 제외.
- 로그인 후 콘텐츠, 결제 후 영상·강의자료, 비공개/폐쇄된 모든 과거 과정까지 조사했다는 의미는 아님. 공개 검색으로 발견하고 확인한 목록이며, 이후 신규 개설·수정될 수 있음.

## 2. 발견 경로

공식 [로봇·Physical AI 로드맵](https://fastcampus.co.kr/event_online_robozone), [강의 검색](https://fastcampus.co.kr/search?keyword=%EB%A1%9C%EB%B4%87), 공식 도메인 검색을 함께 사용했습니다. 검색어는 로봇, 피지컬 AI, Physical AI, 로보틱스, 자율주행, 로봇팔, 휴머노이드, 디지털 트윈, 강화학습, 드론입니다. 페이지에서 연결된 관련 강의와 공식 교육과정소개서를 추가 확인했습니다. fastcampus.co.kr / next.fastcampus.co.kr의 같은 과정, 이벤트·할인 묶음과 개별 과정을 중복 등록하지 않았습니다.

## 3. 목차 확인 방식

1. 공식 상세 페이지에 공개된 커리큘럼 데이터를 PART → CHAPTER → CLIP 순서로 정리했습니다. 페이지에 포함된 공개 데이터이며 유료 학습 내용을 열람한 것이 아닙니다.
2. 공개 목차가 부족한 과정은 공식 PDF의 커리큘럼 표와 웹의 주차별 항목을 대조했습니다. 오프라인 FC27은 PDF 5~7쪽, 이전 FC30은 PDF 6~7쪽, 입문 FC28은 PDF 5~11쪽을 사용했습니다.
3. PDF 표는 텍스트 추출 후 대표 페이지를 렌더링하여 열·행 배치를 확인했습니다. 원문 번호가 건너뛰거나 웹과 다르면 그 사실을 남겼습니다.
4. 소제목의 앞 번호·공백을 정리하고 로컬 추적 ID를 부여했습니다. 원래 강의의 영상 ID가 아니며, 주제 설명·강의 본문·해설을 복제한 자료가 아닙니다.
5. 각 과정 문서 맨 위에 공식 페이지와 확인 가능한 공식 PDF를 연결했습니다. 부분 확인 과정은 그 범위를 명시했습니다.

## 4. 수량과 중복 해석

31개 문서 중 26개는 공개 온라인 목차 트리의 최하위 CLIP까지 확인했습니다. 이 26개에 총 **1,924개 CLIP 항목**이 있습니다. 이는 상품별 표시 항목의 합이며 고유 수업 수나 사이트에 새로 만들 단원 수가 아닙니다. 나머지 5개는 부분 확인·오프라인·비전공 입문 PDF·이전 CAMP·세미나 자료입니다.

특히 Dev Academy 8개의 230개 목차 제목은 아래 세 종합 과정 안에서 모두 대응됩니다. 정규화한 제목을 대조한 결과이며, 영상 파일·영상 ID·편집·설명·과제까지 같다고 단정하지 않습니다.

## 5. 불확실성 및 충돌

- FC01: 홍보 영역의 클립 수와 공개 목차 트리의 177개 항목이 다릅니다. 조사 문서는 실제 확인한 목차 수를 사용합니다.
- FC25: 미래 공개 일정과 목차 확인을 분리합니다.
- FC26: 두 공식 상세 주소가 404입니다. 검색 색인의 주제는 현재 완전한 목차나 신청 가능 상태를 보증하지 않습니다. 미확인 파트/차시를 복원하지 않았습니다.
- FC27: 웹 1주차 과제의 온톨로지·Competency Question 문구는 로봇 핵심 주차 내용 및 PDF와 연결이 불명확합니다. 편집 혼입 가능성을 기록하고 필수 단원으로 채택하지 않았습니다.
- FC28: 웹의 상위 구성과 PDF의 상세 구성 간 차이, 일부 반복/누락 번호를 남겼습니다.
- FC30·31: 과거 과정/행사로 구분합니다. 검색에 노출된다는 이유로 현재 수강 가능이라고 표시하지 않습니다.

## 6. 원자료와 우리 설계의 경계

`fastcampus/`는 확인한 공개 학습 주제와 각 과정의 활용 메모입니다. `integrated_curriculum.md`와 `merge_and_migration.md`의 모듈 순서·선수 조건·자습 인터랙션·평가·확장 우선순위는 **우리 사이트를 위한 신규 설계 제안**입니다. 패스트캠퍼스가 제공한다고 확인한 기능이나 강의의 원래 순서를 의미하지 않습니다.

우리 구현에서는 타사 강의의 본문·영상·코드·그림을 가져오지 않고 자체 설명·예제·해설·시뮬레이션을 작성합니다. 도구 버전은 원자료와 분리하여 기존 Ubuntu 24.04 / ROS 2 Jazzy 기준 호환성을 확인합니다. 이번 조사는 현업 버전 점유율을 새로 조사한 결과가 아닙니다.
