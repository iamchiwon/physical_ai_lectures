## 과정의 활용 방향

SimReady·충돌 필터·복합 관절·물리 조정·텔레옵 데이터를 기존 Isaac Sim 파트의 확장 목표로 검토한다. 공개 색인에 나온 항목만 반영하며 세부 차시 번호는 추정하지 않는다.

공식 URL 두 곳(fastcampus/next.fastcampus)은 조사 시 HTTP 404였습니다. 아래는 공식 페이지의 공개 검색 색인에서 확인된 항목이며, 현재 페이지의 전체 차시 목록을 직접 확인한 결과가 아닙니다. 5파트·약 15시간이라는 안내는 확인되지만 세부 차시 번호·클립 수는 미확인입니다. 확인 불가 부분은 채우지 않았습니다.

### 공개 색인에서 확인된 학습 주제

- Physical AI와 행동 데이터의 관계
- USD 기반 SimReady 자산 구성
- 강체·충돌체와 충돌 누락/간섭 점검
- Collision Group·Filter Pairs와 Physics Debug View
- 바디·바퀴·서랍의 링크 계층
- Revolute/Prismatic Joint와 축·가동 범위
- Articulation Root로 복합 물리 시스템 통합
- 기본 도형으로 2~3자유도 팔 구성
- Stiffness·Damping 조절과 동작 확인
- SO-ARM 자산과 키보드 텔레오퍼레이션
- 카메라·로봇 상태·행동·작업 지시 데이터
- 타코야키 도구·작업판을 이용한 접촉 조작 사례

검색 색인과 실제 신청 가능 상태가 다를 수 있습니다. 통합안의 디지털 트윈 상세 실습은 위 확인 내용과 기존 우리 교재를 바탕으로 별도 설계한 제안이며, 해당 강의의 미확인 차시를 복원한 것이 아닙니다.
