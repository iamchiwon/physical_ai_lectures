## 제안의 핵심

기존 **Physical AI 로봇 제어 실무**를 로봇팔·모방학습·Sim2Real 트랙의 중심으로 유지하고, 공통 기반과 인지·모바일·휴머노이드·임베디드 트랙을 확장합니다. 모든 학습자가 전체 과정을 순서대로 수강하도록 만들지 않고, 진단을 거쳐 공통 기반 → 분야별 경로 → 통합 프로젝트로 진행합니다.

17개 종합·전문 온라인 과정과 8개 분할 과정 등을 포함해 총 31개 항목을 구분했습니다. 디지털 트윈 과정은 현재 상세 URL이 404여서 공개 색인의 일부 주제만 확인했습니다. **31개 모두의 전체 목차가 확보되었다는 뜻은 아닙니다.** 정확한 확인 수준은 각 문서와 조사 방법에 표시했습니다.
