- FC27: 6주 오프라인 과정입니다. 안내 일정은 2026-12-13~2027-01-17이며 온라인 CLIP 수로 환산하지 않았습니다.
- FC28: 웹의 5파트 설명과 PDF의 9파트 구성이 달라 PDF의 상세 항목을 별도 표시했습니다.
