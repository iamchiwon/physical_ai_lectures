# 본문 시각자료 검토

2026-11-11 시작. 기준 브랜치 main(caab3d5), 작업 브랜치 textbook/visual-review.

현재 커리큘럼 207단위와 기존 교재의 본문·시각자료 연결을 검토한다. 사진/장면, 공간·기구 구조, 좌표·시간·데이터 흐름 중 글만으로 대상을 특정하거나 관계를 읽기 어려운 부분을 보충한다. 표/계산/명세만으로 독립적으로 이해되는 부분은 장식 이미지를 추가하지 않고 그 이유를 기록한다. 각 단위의 변경/검수는 별도 커밋한다.

사진·장면은 gpt-image-2.5-sunburst를 우선 사용하며 해당 모델 사용 불가 시 gpt-image-2를 사용한다. 정확한 수치/축/연결 도식은 원고에 맞춰 직접 제작한 SVG를 사용한다. 생성 사진은 실험 증거로 사용하지 않는다. 외부 이미지는 원문 URL·저작자·라이선스·수정/표시 조건을 확인한 경우에만 사용한다. 참고 강의의 제목/출처는 공개 결과에 노출하지 않는다.

원고에는 대체 텍스트·그림을 읽는 설명·적용 범위를 함께 제공한다. 본문 문제의 해설을 앞당겨 노출하지 않는다. 이미지 생성 프롬프트는 prompts/, 단위별 판단/근거는 units/, 진행 상태/파일 지문은 inventory.json에 기록한다. 기존 집필 승인 지문도 해당 단위의 새 내용에 맞춰 갱신한다. PDF/EPUB·배포는 수행하지 않는다.

기구 비교 후보 생성에서 M06.06의 gpt-image-2.5-sunburst 결과는 구동축/상부 링크의 실제 운동 관계가 명확하지 않아 채택하지 않았다. 최종본에는 연결 위상만 명시한 직접 제작 도식을 사용한다. 미채택 프롬프트도 기록으로 보존한다. 채택된 생성 장면은 M00.01·M00.03이며 원본 크기/의미·비실험 자료 표시를 검토했다.

## 완료 결과

현재207단위 모두 단위별 판단/커밋을 완료했다. 141단위에152개 시각자료를 제공하고, 추가하지 않은66단위도 본문 절과 판단을 기록했다. M00.01의 컵 예시, 로봇 형태, 벡터/좌표·팔/바퀴 기구·시간파형·투영/분할·점군/그래프·경로·실행 경계를 보강했다.

- 최종 자산: `apps/web/public/textbook-visuals/`의 생성 장면2개와 직접 제작SVG150개. 모든 그림에 대체 텍스트·본문 설명·범위 표시가 있다. 그림 링크에서 원본 크기로 열 수 있으며 웹에 안내를 표시한다.
- 생성: 요청 모델의 공식 ID `gpt-image-2.5-sunburst`, 번들 imagegen CLI/Images API 사용. [모델 문서](https://developers.openai.com/api/docs/models/gpt-image-2.5-sunburst). 채택 프롬프트는 [컵](prompts/M00.01-cup.txt)·[로봇 형태](prompts/M00.03-robot-forms.txt), 채택 자산은 각각 `M00.01-cup.webp`·`M00.03-robot-forms.webp`다. 외부 이미지는 새로 사용하지 않았다.
- 기존 교재137읽기 단위의 시각 참조/파일 연결 점검: 6장에 연결된24개 이미지 모두 존재. 장별 `legacy-*.json`에 단위/참조/지문을 기록했으며 기존 원본은 변경하지 않았다. 이는 기존 장 전체를 새 교육과정으로 재집필했다는 뜻은 아니다.
- 현재207단위의 목표/실습/문제/해설은 main 기준과 동일하다. 본문·이미지에 맞춰 집필 승인 지문을 갱신했으며 ready207을 유지한다. 답안/활동 ID와 저장 스키마는 변경하지 않았다.
- 검증: 188/188 회귀 테스트, 타입·린트·shared/web/API dry-run 빌드, 공개본 비노출 검사, 전수 자산/검토 지문 검사 통과. SVG150개의 실제 브라우저 글자 경계/겹침 검사에서 오류0. 정적415HTML·14296링크·7466자산 오류0.
- 브라우저: M00.01 사진/원본 열기, 320px의 컵·PRM 및 대표9단위의 이미지 로드/가로 넘침·대체 텍스트를 확인했다. 원래 브라우저 저장 상태는 정확히 복구했다. 공통 원본 링크 안내는 최종 정적HTML에서도 확인한다. [검증 수치](verification.json).
