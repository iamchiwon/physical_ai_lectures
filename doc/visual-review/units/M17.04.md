# M17.04 본문 시각자료 검토

- 검토: 2026-11-11, 작성자 자기검수
- 판단: RRT의 트리 확장는 공간/파형 관계를 직접 보아야 식의 기준과 적용 범위를 혼동하지 않으므로 도식을 추가한다. 제공된 식·본문 조건과 대조했다.
- 조치: 그림 2개 제공.
- 원고 지문: `b35691541c108850d55def0c51645c612ded3cb24e9aec9c511996a86e001e4d`

- [M17.04-concept.svg](../../../apps/web/public/textbook-visuals/M17.04-concept.svg): 각 칸은 서로 다른 역할/근거다. 아래 방향은 자료/처리의 연결이며 실제 성공을 자동으로 보장하지 않는다. 직접 제작한 개념도이며 본문의 조건과 함께 읽는다. 제작: original-svg.
- [M17.04-spatial.svg](../../../apps/web/public/textbook-visuals/M17.04-spatial.svg): 시작점에서 이미 연결된 트리를 확장하는 별도 점 모델 개념도다. 주황 확장 후보도 연결 구간 검사를 거쳐야 한다. 일반 차량의 조향/동역학을 직선 연결로 대체한 모델은 아니다. 직접 제작. 제작: original-svg.
