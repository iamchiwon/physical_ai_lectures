# M08.01 본문 시각자료 검토

- 검토: 2026-11-11, 작성자 자기검수
- 판단: 한 링크의 세 기준는 공간/파형 관계를 직접 보아야 식의 기준과 적용 범위를 혼동하지 않으므로 도식을 추가한다. 제공된 식·본문 조건과 대조했다.
- 조치: 그림 2개 제공.
- 원고 지문: `84a28bc6c8ad09aaaab50831ee0c1337c8fe4cb499f87e43c6290a99d4b1c9f8`

- [M08.01-concept.svg](../../../apps/web/public/textbook-visuals/M08.01-concept.svg): 각 칸은 서로 다른 역할/근거다. 나란히 비교할 항목이며 위아래가 시간 순서를 뜻하지 않는다. 직접 제작한 개념도이며 본문의 조건과 함께 읽는다. 제작: original-svg.
- [M08.01-spatial.svg](../../../apps/web/public/textbook-visuals/M08.01-spatial.svg): 회색 표시 형상과 파란 충돌 근사 상자, 주황 질량중심은 역할이 다르다. link 원점을 형상의 중앙/COM과 자동으로 같다고 놓지 않는다. 축척이나 실제 관성값이 없는 개념도다. 직접 제작. 제작: original-svg.

그림과 본문의 용어/방향/가정·대체 텍스트·파일 연결을 대조했다. 생성 장면은 실물/측정 결과가 아니다. 기존 목표·실습·해설의 계산/학습 범위는 유지한다.
