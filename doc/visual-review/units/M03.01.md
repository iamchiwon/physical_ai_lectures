# M03.01 본문 시각자료 검토

- 검토: 2026-11-11, 작성자 자기검수
- 판단: 백래시의 국소 접촉 개념는 공간/파형 관계를 직접 보아야 식의 기준과 적용 범위를 혼동하지 않으므로 도식을 추가한다. 제공된 식·본문 조건과 대조했다.
- 조치: 그림 2개 제공.
- 원고 지문: `150053c273e9c0722c5765da878073a7768b6c0a4dfa50374ce31c7ca4b92c9e`

- [M03.01-concept.svg](../../../apps/web/public/textbook-visuals/M03.01-concept.svg): 각 칸은 서로 다른 역할/근거다. 아래 방향은 자료/처리의 연결이며 실제 성공을 자동으로 보장하지 않는다. 직접 제작한 개념도이며 본문의 조건과 함께 읽는다. 제작: original-svg.
- [M03.01-spatial.svg](../../../apps/web/public/textbook-visuals/M03.01-spatial.svg): 맞물린 치면 사이를 펼쳐 그린 개념도다. 방향 반전 때 접촉이 바뀌기 전의 틈은 모터 축 회전과 실제 출력 변화를 다르게 만든다. 기어의 실제 형상/간격이나 모든 백래시 원인을 그린 도면은 아니다. 직접 제작. 제작: original-svg.

그림과 본문의 용어/방향/가정·대체 텍스트·파일 연결을 대조했다. 생성 장면은 실물/측정 결과가 아니다. 기존 목표·실습·해설의 계산/학습 범위는 유지한다.
