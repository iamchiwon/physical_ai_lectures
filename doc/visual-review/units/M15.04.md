# M15.04 본문 시각자료 검토

- 검토: 2026-11-11, 작성자 자기검수
- 판단: 포즈 그래프의 루프 연결는 공간/파형 관계를 직접 보아야 식의 기준과 적용 범위를 혼동하지 않으므로 도식을 추가한다. 제공된 식·본문 조건과 대조했다.
- 조치: 그림 2개 제공.
- 원고 지문: `c0c98c1e70b2908f92f4a100d7db3e7d7a0f5339dbfa830d0aa732457e62f7c8`

- [M15.04-concept.svg](../../../apps/web/public/textbook-visuals/M15.04-concept.svg): 각 칸은 서로 다른 역할/근거다. 아래 방향은 자료/처리의 연결이며 실제 성공을 자동으로 보장하지 않는다. 직접 제작한 개념도이며 본문의 조건과 함께 읽는다. 제작: original-svg.
- [M15.04-spatial.svg](../../../apps/web/public/textbook-visuals/M15.04-spatial.svg): 숫자는 시간 순서의 pose 노드다. 주황 점선은 마지막 관측과 과거 장소 사이에서 검증한 추가 제약을 뜻한다. 그림은 참 궤적/최적화 결과가 아니며 잘못된 루프도 생길 수 있다. 직접 제작. 제작: original-svg.

그림과 본문의 용어/방향/가정·대체 텍스트·파일 연결을 대조했다. 생성 장면은 실물/측정 결과가 아니다. 기존 목표·실습·해설의 계산/학습 범위는 유지한다.
