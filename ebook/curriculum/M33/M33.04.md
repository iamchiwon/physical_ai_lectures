## 본문

### 익숙한 언어보다 해결할 작업을 먼저 정한다

C# OpenJigWare, MATLAB/Simulink, 장치 전용 GUI는 같은 범주의 대체품이 아니다. OpenJigWare는 로봇/지그 소프트웨어를 위한 라이브러리의 예, Simulink는 블록선도로 시스템을 모델링/시뮬레이션하는 도구의 예, 전용 GUI는 특정 장치의 설정/관측/명령 경로의 예로 비교한다. C#이나 MATLAB 문법을 다시 배우는 과정은 아니며 제품 구매/설치를 필수로 요구하지 않는다.

도구가 제공하는 기능과 실제 선택한 버전/모듈에서 사용할 수 있는 기능을 구분한다. 코드 생성·장치 연결·데이터 내보내기·실시간 실행 등은 지원범위/추가 구성·라이선스에 따라 달라질 수 있다. 공식 문서와 실제 필요한 인터페이스를 확인하고, 이름에 '로봇'이나 '시뮬레이션'이 있다는 이유로 ROS 2 또는 실물 제어와 자동으로 호환된다고 보지 않는다.

### 공통 계약으로 비교표를 만든다

비교할 과제는 기록된 관절 목표와 측정 상태를 읽고 오차를 계산해 보고하는 읽기 전용 작업으로 정한다. 필요한 항목은 입력 형식/단위·시간/clock·관절 이름/순서·오차 정의·출력 기록이다. 도구마다 다른 화면을 비교하기보다 같은 입력에 같은 수치/판정이 나오는지 확인한다. 원본을 별도 보존하고 변환 스크립트/설정과 버전을 남긴다.

자체 교환파일은 jointA의 목표90deg·측정80deg·동일시각을 준다. 내부 계약이rad라면 목표π/2≈1.5708rad·측정4π/9≈1.3963rad, 목표−측정오차π/18≈.1745rad다. 숫자90을90rad로복사하면형식은읽혀도물리의미는틀리다. GUI에서단위표시가자동변환되는지저장파일의실제단위는무엇인지확인한다.

오차의부호도고정한다. 측정−목표를사용하는도구와목표−측정을사용하는도구의그래프는부호가다를수있다. 제곱오차가같다고전체출력계약이동일한것은아니다. 관절이름없이배열만내보내면순서변경을검출하기어려우므로스키마를명시한다.

### 모델링과 실제 실행의 시간을 나눈다

Simulink 같은모델링환경의블록선도에서계산이돌아가는것과실제장치의주기/지연을지키는것은다르다. solver/샘플시간·고정/가변step·단위와출력소비시점을정한다. GUI의그래프갱신률이100Hz라고실제명령적용이100Hz라는뜻은아니다. 화면표시/자료취득/제어계산/구동기적용의시간을분리한다.

자체기록에서계산주기10ms는100Hz이고화면갱신100ms는10Hz다. 화면에새점이하나보인동안제어계산10회가있을수있다. 실제로모든값이저장됐는지, 화면이중간점을생략/평균했는지는로그계약으로확인한다. 화면스크린샷만으로원시신호의기한/누락을평가하지않는다.

### GUI 조작을 재현 가능한 변경으로 남긴다

GUI에서값을바꿔화면에보였다는사실과장치에적용/지속저장됐다는사실은다르다. 설정파일/프로젝트·변경전후diff·대상형상/버전·readback/실제관측을남긴다. 버튼을누른순서를기억에의존하지말고내보내기형식이나명세표로보존한다. 장비연결/쓰기·리셋은이읽기전용기본활동의범위밖이다.

비교기준에는현재기본환경Ubuntu24.04/ROS2Jazzy와의직접실행또는분리호스트가능성·파일/네트워크인터페이스·의존성/ABI·헤드리스/자동화·테스트/로그·라이선스/배포조건을넣는다. 특정도구가현재어느OS를지원하는지는공식버전문서에서확인하고추정해필수경로를만들지않는다. 별도OS가필요하면선택경로로격리하고공통핵심학습을막지않는다.

### 선택 이유를 기능 목록보다 구체적으로 쓴다

세도구를1~5점으로아무근거없이점수화하기보다필수요구의충족/미확인/불충족과확인자료를적는다. 예를들어원본시각보존이필수인데GUI가평균화된화면만제공하면읽기전용비교의근거가부족하다. 추가모듈이있으면가능하다는말만으로현재구성의충족으로표시하지않는다.

같은입력의정상/단위오류/관절누락/시간역순을각도구경로에서어떻게검출할지설계한다. 실제실행하지않았다면지원문서검토와가상판정만수행했다고쓴다. 기본산출물은계약표·단위/주기계산·재현/미확인목록이다. M33.05는모바일UI·기구설계·MCU개발도구로같은경계분석을확장한다.

인수 기준을 정할 때 실제 사용할 대표 파일을 하나 고르고 누락/단위/시간 역순의 변형도 함께 정의한다. 제품 설명에 있는 기능이 이번 설치 구성에서 켜져 있는지, 추가 장치나 유료 모듈이 필요한지 확인한다. 확인하지 못한 기능은 미확인으로 남기고 다른 도구의 실제 수행 결과와 동등한 근거로 점수화하지 않는다.

## 실습

1. 목표90deg/측정80deg를rad로변환하고목표−측정오차를구한다.
2. 계산10ms/화면100ms의주파수/비율을구한다.
3. 동일관절기록분석을위한세도구비교표와정상/단위오류검사를작성한다. 막히면도구이름대신입출력/시간/형상/재현열을쓴다.

## 실습 해설

1. π/2·4π/9·π/18rad, 약1.5708/1.3963/.1745다.
2. 100/10Hz·계산10회/화면갱신1회다. 실제원시저장/제어적용은별도확인이다.
3. 라이브러리/모델링/장치UI역할을나누고지원/의존/기록/내보내기·버전/라이선스와미확인을명시한다. 설치/장비명령을실행했다고표시하지않는다.
