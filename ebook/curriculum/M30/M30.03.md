## 본문

### 부드러움과 유효한 실행은 다른 검사다

정책 출력의 흔들림/불연속을 줄이는 필터는 현재/과거의 수치를 합성한다. 유한값·단위/frame·관측 나이/버전·기본 범위를 확인하지 않고 무효 제안을 평균하면 무효 입력이 유효해지지 않는다. 먼저 입력/계약을 검사하고 유효 후보만 합성한다. 합성 뒤에도 현재 상태·시간/동역학과 경로/물리 제약을 다시 검사한다. 이 단위의 수치 한계는 교육용 입력이며 특정 로봇의 허용 정격이나 안전 기준이 아니다.

관절 목표를 정규화 공간에서 만들었다면 어느 단계에서 물리 단위로 복원하는지 적는다. 여러 관절을 같은 숫자 범위로 clip해도 rad·m·그리퍼 범위와 속도/토크 의미는 다를 수 있다. 현재 측정 q와 이전에 적용한 명령 q_prev도 구별한다. 명령 변화 제한이 실제 축 속도 제한을 보장하려면 구동 추종/상태·실행 주기 등 추가 근거가 필요하다.

### EMA는 새 입력과 저장된 상태를 섞는다

EMA(지수이동평균)는 시간 순서의 입력 u_k를 이전 필터 상태 y_(k−1)와 합성한다. k는 업데이트 번호, α는 이번 식에서 새 입력의 비중이며 0<α≤1이다. 같은 단위의 절대 목표를 일정 주기 T초로 처리하는 교육용 규약을 쓴다.

[![평균화 뒤에도 제약을 검사: EMA → Temporal ensembling → 물리 계약 복원 → 제약 재검사.](/textbook-visuals/M30.03-concept.svg)](/textbook-visuals/M30.03-concept.svg)

*그림 M30.03-1. 각 칸은 서로 다른 역할/근거다. 아래 방향은 자료/처리의 연결이며 실제 성공을 자동으로 보장하지 않는다. 직접 제작한 개념도이며 본문의 조건과 함께 읽는다.*


$$
y_k=\alpha u_k+(1-\alpha)y_{k-1}.
$$

y_0=0 rad/α=0.25에서 다음 입력이 계속 1 rad면 y_1=0.25 rad, y_2=0.4375 rad다. α가 작을수록 이전 상태의 영향이 오래 남고 갑작스러운 변화에 늦게 반응한다. α=1이면 입력을 그대로 낸다. 초기 상태를 0으로 둘지 현재 측정/첫 유효 목표로 둘지는 다른 계약이다. 기존 교육용 EMA leaf는 첫 입력으로 초기화하므로 이 y_0=0 계산과 구별한다.

필터 계수를 고정한 채 업데이트 주기를 바꾸면 실제 초 단위의 응답이 달라진다. reset/모델 교체·정지 뒤 오래된 상태가 남으면 새로운 시작에 맞지 않을 수 있다. 초기화 값·대기/램프와 실제 상태 확인을 설계한다. EMA의 지연을 무조건 줄이려고 α를 크게 하면 원래 줄이려던 흔들림이 다시 커질 수 있어 과제 응답/기한·추종을 함께 평가한다.

### Temporal ensemble은 같은 실행 시각의 후보를 모은다

action chunk는 한 번의 추론이 여러 미래 실행 시각의 값을 예측한 것이다. ensemble에서는 서로 다른 생성 시각의 chunk에서 지금 실행할 같은 시각/같은 성분의 후보를 골라 합친다. 단순히 각 chunk의 첫 행을 평균하거나 현재 목표와 다음 시각 목표를 섞지 않는다. absolute/delta·단위/frame·기준과 모델/정규화 버전이 달라지면 먼저 공통 의미가 되는지 검증한다.

후보를 생성 시각이 오래된 순서로 a_0=0.2, a_1=0.4, a_2=0.8 rad라고 하자. 가중치 w_i를 합으로 정규화해 y=Σ(w_i a_i)/Σw_i로 합성한다. [현재 LeRobot ACT 공식 구현](https://github.com/huggingface/lerobot/blob/main/src/lerobot/policies/act/modeling_act.py)은 oldest 인덱스 0에 w_i=exp(−κi)를 쓰며 양수 κ는 오래된 후보를 우선한다. 원 ACT의 해당 집계 코드도 오래된 생성 순서에 같은 방향을 사용한다. 공식 기본 계수와 아래 계산용 계수를 동일시하지 않는다.

교육용 κ=ln 2이면 오래된 순서의 비정규화 가중치는 1/0.5/0.25다. 합성값은 (0.2+0.2+0.2)/1.75≈0.342857 rad다. 반면 기존 교재 leaf들은 후보 age/상대 생성 시차에 exp(−양수×age)를 사용해 새로운 후보를 우선한다. 같은 후보에서 가중치가 0.25/0.5/1이면 (0.05+0.2+0.8)/1.75=0.6 rad다. 두 계약을 '양수면 최신 우선' 하나로 설명하면 틀리다.

균등 가중치는 1.4/3≈0.466667 rad다. 어느 값이 과제에서 더 적절한지는 후보 품질/지연·학습/실행과 관련되어 단순히 최신/오래된 쪽이 항상 맞지는 않는다. 자료가 없는 시각/만료·동일 버전 여부와 reset 때 후보 이력을 어떻게 처리할지도 명시한다. zero 값을 유효한 행동으로 쓸 수 있으므로 0이라는 값만으로 미기입 여부를 판정하지 않는 명시적 유효 mask/ID가 필요하다.

### 속도/위치·토크를 물리 계약으로 제한한다

가상 절대 관절 명령의 이전 적용값 q_prev=0.4 rad, 주기 T=0.02 s, 명령 변화율 한계 v_max=0.5 rad/s라면 허용 변화는 v_max T=0.01 rad다. 후보 0.6 rad를 속도 단계에서 0.41 rad로 줄인다. 위치 상한이 0.405 rad라면 최종 0.405 rad는 위치를 만족하고 이전 명령에서 0.005 rad 변해 속도 단계도 만족한다. 이 예는 단순 한 축·유효한 이전 상태와 고정 주기 가정이다.

별도 토크 명령 후보 0.8 N·m에 절대 한계 0.5 N·m를 주면 숫자 제한 결과는 0.5 N·m다. 위치 명령을 clip한 것만으로 실제 토크가 이 범위라는 증거는 아니다. 전류/토크 환산·드라이브 모드·부하/접촉과 실제 상태/정격이 필요하다. 실제 장치에 이 숫자를 설정하라는 뜻이 아니다.

제한을 순서대로 걸었다고 모든 제약이 함께 성립하는 것도 아니다. q_prev=0.42 rad인데 같은 변화 한계 0.01 rad라면 다음 명령 허용 구간은 [0.41,0.43]이다. 위치 상한 0.405와 교집합이 없다. 마지막에 0.405로 잘라도 변화가 0.015 rad라 앞의 변화율 조건을 깨뜨린다. 이런 상태는 조용히 정상 명령으로 처리하지 않고 충돌 제약/현재 상태를 기록해 해당 감독/복구 정책으로 넘긴다. 즉석 큰 점프를 복구라고 승인하지 않는다.

### 평균이나 끝점 검사로 전체 경로를 승인하지 않는다

기하 작업공간도 볼록하지 않을 수 있다. 평면의 원점 반경 0.5 m 안이 금지 구역이라면 점 (−1,0)/(1,0)은 각각 밖에 있지만 평균 (0,0)은 금지 구역이다. 두 유효 후보의 평균이 항상 유효하지 않다는 반례다. 관절 평균은 FK가 비선형이므로 TCP의 Cartesian 평균과 같다고 가정하지 않는다. 끝점이 유효해도 그 사이 링크/물체·접근 경로가 금지 공간을 지날 수 있다.

센서/현재 상태가 미상이거나 관측이 만료되면 필터가 숫자를 내도 실행 전제는 미상이다. raw/ensemble/EMA·각 제한 뒤/최종 명령과 실제 관측, 시각/버전·거부 원인/필터 상태를 나눠 기록한다. 정지/포화·재개 시 내부 상태와 물리 현재 상태를 맞추고 새 관측·제약/감독으로 재검증한다. [기존 6.3 출력 안정화](/textbook/06_sim2real_deployment--chapter-7/)와 [6.4 감독기](/textbook/06_sim2real_deployment--chapter-8/)의 교육 예제는 이 검사 경로를 이해하는 보충이며 인증된 안전 제어기나 실제 제동 보장을 뜻하지 않는다.

## 실습

입력은 본문의 EMA 초기값/계수·입력, 동일 실행 시각 후보/두 가중 순서, 속도/위치·별도 토크 한계와 교집합 실패/원형 금지 구역이다. 모두 합성값이다.

1. EMA 시간 상태와 ensemble 후보의 생성/실행 시각을 구분하고 공식 oldest-index와 교재 age 가중 방향을 설명한다.
2. EMA 두 단계·세 ensemble 값과 속도/위치·토크 제한 결과를 계산한다.
3. 교집합 실패/기하 평균 반례·현재 상태 미상에서 실행을 판정하고 reset/기록·복구 후 재검증을 설계한다.

관찰은 의미/시간, 숫자, 복합 제약/근거로 나눈다. 막히면 후보를 오래된 순서로 표에 적고 가중치 열을 따로 둔다. 실제 로봇/모델은 필요하지 않다.

## 실습 해설

EMA는 직전 필터 상태/새 시간 입력, ensemble은 같은 실행 시각의 다른 생성 후보다. oldest 인덱스 양수 계수는 오래된 우선, age 양수 감쇠는 새 후보 우선임을 설명하면 목표 1 통과다.

EMA 0.25/0.4375 rad, ensemble 약 0.342857/0.6/0.466667 rad다. 명령 변화 0.01 rad·속도 단계 0.41/최종 0.405 rad, 토크 숫자 0.5 N·m다. 단위/별도 예제 경계를 포함하면 목표 2 통과다.

이전 0.42 rad의 교집합은 없고 평균점은 금지 구역이다. 미상/만료를 보류하고 실제 상태/경로·필터/후보 이력/시각과 감독 복구·재검증을 제안하면 목표 3 통과다. 세 목표 모두 필요하며 부드럽게 보이면 안전하다는 답은 부족하다.

## 확인 문제

### Q1
같은 실행 시각의 후보 0.2/0.8 rad를 오래된 순서로 두었다. 가중치 1/0.5와 0.5/1의 결과/우선 방향은 무엇인가? 다른 미래 시각의 목표를 그냥 섞을 수 있는가?

### Q2
이전 EMA 상태 0.2 rad/입력 0.6 rad/α=0.5다. 별도 이전 적용 명령 0.2 rad·T=0.1 s/변화율 한계 0.3 rad/s·위치 상한 0.225 rad에서 이 EMA 후보를 제한하라. 토크 후보 0.9 N·m/한계 0.4 N·m도 계산하라.

### Q3
이전 명령이 이미 위치 한계를 벗어나 있고 금지 공간이 비볼록이다. 최종 clip/유효 끝점·오래된 필터 상태만으로 재개할 수 있는가? 필요한 검사/미상 처리를 적어라.

## 해설

### Q1
각각 0.4/0.6 rad로 오래된/새로운 우선이다. 같은 실행 시각·동일 행동 의미의 후보를 골라야 한다. 인덱스/age 정의 없이 양수 계수만으로 방향을 말하거나 다른 미래 시각을 섞으면 틀리다.

### Q2
EMA는 0.4 rad, 변화 한계는 0.03 rad라 속도 단계 0.23/위치 단계 0.225 rad다. 최종 변화 0.025 rad도 확인한다. 토크 숫자 제한은 0.4 N·m이며 실제 토크/안전을 보장한 것은 아니다.

### Q3
그럴 수 없다. 변화/위치 제약의 교집합·전체 링크/물체 경로와 현재 관측/시각·실행 상태를 확인한다. 상태/후보 초기화와 제한 충돌·미상을 기록하고 정의된 감독/복구 뒤 재검증한다. 마지막 clip이 모든 앞 제약을 보존한다고 하면 틀리다.
