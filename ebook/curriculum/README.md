# 통합 상세 교재

E1(M00~M03)·E2(M05~M08)·E3(M10~M12와 M14 기초)·E4·E5의 검수된 상세 원고 135개입니다. 각 단위에 목표 3개, 본문과 단계별 예제, 장비 없는 실습 1개와 해설, 확인 문제 3개와 개별 해설, 참고 자료를 제공합니다. 누적 실습 135개·확인 문제 405개이며, E5에서 현재 원고 24개·실습 24개·문제 72개를 추가했습니다.

W01/W02를 반영한 현재 승인 상세 원고139개·실습139개·문제/개별해설417쌍입니다. 집필 이력의 E1~E5 수량과 구분합니다.

웹의 `교재 본문` 목차와 각 단위 페이지에서 읽고 답안을 저장할 수 있습니다. 기존 여섯 장 응용 교재의 137개 읽기 절과 이어 읽으며, 읽기 절 수를 소주제 완료 수와 합산하지 않습니다. 전체 207개 소주제 집필이 끝난 것은 아닙니다. 완료 항목에는 상태 배지를 붙이지 않고 미완료 항목만 준비중으로 표시합니다.

학습은 [현행 단계 순서](../../doc/integrated_curriculum.md)를 따릅니다. 아래 E1~E5 묶음은 집필 이력입니다. 일반 코딩·문법 설명은 제외하고 AI/로봇 실행 도구를 보충합니다. M34 관제 3개와 P2~P4 실행 패키지는 준비중입니다. P1은 [장비 없는 실행 자료](../../examples/P1/README.md)를 제공합니다.

## 기본 활동과 선택 실행

기본 활동은 합성 기록 해석·종이/CPU 계산·문서 읽기입니다. ROS 2 명령·시뮬레이터·실물/GPU 실행에는 별도 환경이 필요하며, 수록한 예시나 계산 결과가 그 환경의 실제 성공을 뜻하지 않습니다. 실행 여부와 검증 범위는 원고와 작업 기록에 구분했습니다.

M06의 기존 2링크 팔과 바퀴 계산기, M07의 PID 응답 모형은 웹 단위 페이지에서 선택 보충으로 제공합니다. 모형의 배치·단위·시간·포화 가정을 확인하며 실제 장비 동작·안전이나 자동 채점/숙달로 해석하지 않습니다. 기본 실습과 네 답안 흐름은 모형 없이도 수행할 수 있습니다.

E3에서는 M11.05의 이진 임계값·오류 비용 모형과 M12.02·M14.03/.06의 핀홀 투영·시각 차이 모형을 추가했습니다. 합성 기록과 단순 가정을 사용하며 실제 모델 학습·센서 보정·작업 성공을 검증하는 도구는 아닙니다. 조작은 답안·진도·완료를 자동 변경하지 않습니다.
