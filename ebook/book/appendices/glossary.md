# 부록 B. 용어집

| 용어 | 설명 |
|---|---|
| Action Chunk | 한 번의 추론으로 예측하는 연속된 미래 행동 묶음 |
| Articulation | 관절로 연결된 강체 집합을 물리 엔진에서 표현하는 구조 |
| CCD | Continuous Collision Detection. 빠르게 움직이는 물체의 프레임 간 관통을 줄이는 충돌 검출 방식 |
| DDS | Data Distribution Service. ROS 2 통신의 기반이 되는 데이터 중심 미들웨어 표준 |
| Digital Twin | 실물 시스템의 상태와 동작을 대응시키는 가상 모델 |
| DLS | Damped Least Squares. 특이점 부근의 역기구학 수치 불안정을 줄이는 감쇠 최소제곱법 |
| Domain Randomization | 시뮬레이션의 외형·물리 조건을 무작위화해 현실 변화에 대한 정책 강건성을 높이는 기법 |
| End Effector | 로봇팔 끝에서 물체 또는 환경과 상호작용하는 도구나 그 기준 프레임 |
| Extrinsic | 카메라와 기준 좌표계 사이의 회전과 이동 관계 |
| FK | Forward Kinematics. 관절 상태에서 엔드이펙터 포즈를 계산하는 순기구학 |
| IK | Inverse Kinematics. 목표 엔드이펙터 포즈를 만족하는 관절 상태를 구하는 역기구학 |
| Intrinsic | 초점 거리, 주점 등 카메라 내부 투영 파라미터 |
| LoRA | Low-Rank Adaptation. 저랭크 행렬을 추가해 적은 학습 파라미터로 모델을 미세조정하는 방법 |
| OpenUSD | 장면의 계층, 속성, 관계와 합성을 표현하는 Universal Scene Description 생태계 |
| Policy | 관측과 목표를 받아 로봇 행동을 출력하는 의사결정 함수 또는 모델 |
| Prim | USD Stage 안의 기본 장면 객체 |
| QoS | Quality of Service. 신뢰성, 이력, 내구성 등 ROS 2 통신 정책 |
| Reality Gap | 시뮬레이션과 실제 환경의 관측·동역학 차이 |
| Sim2Real | 시뮬레이션에서 개발·학습한 시스템을 실제 장비로 이전하는 과정 |
| TF2 | ROS 2에서 시간에 따른 좌표 프레임 변환을 관리하는 라이브러리 |
| VLA | Vision-Language-Action. 시각 관측과 언어 지시에서 로봇 행동을 생성하는 모델 계열 |
