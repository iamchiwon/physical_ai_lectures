### 최종 프로젝트 평가 기준 {#chapter-6-project-rubric}

## 먼저 수행 범위를 고른다

S11 기본 캡스톤은 아래 세 가지 중 **하나**를 고르는 장비 없는 계산·기록 해석 과제다. 세 과제를 모두 수행하거나 실물 장비/GPU를 준비할 필요는 없다. 일반 코딩 경험을 전제로 언어 문법 입문을 요구하지 않는다. 실제 프로그램 실행을 추가했다면 계산·제공 기록·CPU 실행·시뮬레이터·실물 중 수행한 수준을 따로 적는다.

| 선택 | 제공 입력과 기본 활동 | 남길 산출물/핵심 판정 |
|---|---|---|
| A · [M32.01 모바일 배달](/study/unit-m32-01-a/) | 두 경로의 길이/폭·탑재 전후, 문 변경·점 장애물 시간식, 이상 정지 모형 | 목적지 모호성/물체·미션 계약, 폭0.7/0.9m의4/6m 경로·4s 교차/0.225m 정지 계산, 도착과 인계 미상 분리 |
| B · [M32.02 비전·집기/배치](/study/unit-m32-02-a/) | pinhole 픽셀/depth·가상장착, 관절 복원/변화율, 관측 나이·합성 성공 표 | camera/base 점·파지 pose 구분,0.4→0.39rad 제한/85ms 관측 거부, 파지/유지/배치·조건별80/50%·합성65% 구분 |
| C · [M32.03 이동 조작·양팔](/study/unit-m32-03-a/) | 평면 회전/이동·베이스 보상,1D 강체 파지점·시차/정적 하중 | TCP(0.9,0.4)m/로컬(0,+0.02)m 보상, 양팔 일치/불일치·시차6mm·각5N/1N·m 계산, 수락과 공동물체 유지 미상 분리 |

모든 입력/식·정상/변형과 개별 해설은 각 단원에 있다. 값은 교육용 가정이며 실제 주행/파지·허용치/안전 인증이 아니다. C의 제공 수치 활동에는 양팔 장비나 학습 정책이 필요 없다. 양팔 실제 정책/실행으로 확장할 때만 [M21.05](/study/unit-m21-05-a/)의 추가 선수와 해당 장치의 전제를 확인한다.

## 선택 뒤 공통으로 연결할 내용

1. [M32.05](/study/unit-m32-05-a/)의 요구ID·입출력/상태·단위/프레임/시각/버전 계약을 선택 과제에 적용한다. 원본→예상→주어진 결과/자기 계산→판정·미확인을 추적한다.
2. 같은 단원의 R1~R4/T1~T6 공통 표도 해석한다. 선택 과제에 공통 형식/근거 추적을 적용하는 연습이며 여섯 기록을 실제 장비의 실행 로그라고 부르지 않는다.
3. [M32.06](/study/unit-m32-06-a/)의 정상/거부·미상 사례와 3분 설명, 검토/수정·재검증 계획으로 마무리한다. 아래 기본 루브릭을 먼저 고정한다.

### 기본 계산·기록 과제의 평가

| 항목 | 비중 | 확인할 근거 |
|---|---:|---|
| 요구/인터페이스 |20|선택/범위·요구ID·입출력/상태·단위/시각/개정 |
| 방법/계산·설계 |25|선택 과제의 정상/변형 계산과 가정·오답/대안 |
| 증거/재현 |20|제공 원본/자기 계산/실제 실행 구분과 추적·환경/지문 |
| 실패/감독·미상 |20|경계/거부·누락·취소/결과·실패 분모·재검증 |
| 설명/한계·범위 |15|수행 범위·미시험·검토 방식과 다음 확인 |

각 항목은0~4점이며 총점은Σ(비중×점수/4)다. **총점70이상 + 모든 항목2이상 + 미해결 차단 결함 없음**을 모두 충족해야 기본 문서 과제 통과다. 합성 기록을 실물 성공으로 바꾸거나, 최종 결과 없는 기록을 완료로 보고하면 차단 결함이다. 자기검수/동료 읽기/독립 실행은 실제 수행한 방식으로 적는다. 이 통과는 장비 운전 승인·실물 성과/안전 인증과 별개다.

## 선택 실물 확장에만 적용하는 기존 장비 루브릭

아래는 실제 장비·정책 배포/물리 실험을 별도로 선택하고 필요한 감독/실행 근거를 갖춘 경우의 기존 평가다. 기본 종이 과제에 실물 E-stop·저속/nominal 운전·현장 통계 실적을 필수로 요구하지 않는다. 기본과 실물 루브릭의 총점을 합치거나 같은 수행 범위의 점수처럼 비교하지 않는다. 실물 확장을 하지 않았다면 ‘미실행’으로 기록하며 이 표를 채운 것으로 만들지 않는다.

총점 100점이다.

| 항목 | 배점 | 우수 기준 |
|---|---:|---|
| 과업 계약 | 10 | 성공/실패, timeout, reset, 조건을 사전 정의 |
| 안전 승격 | 20 | dry-run→저속→bounded→nominal 증거와 강등 조건 |
| 독립 안전 | 10 | E-stop/전원 차단, latched fault, 수동 재승인 |
| Reality Gap 진단 | 15 | 지연·기하·마찰·백래시 중 3개 이상 정량 분석 |
| 정책 배포 | 10 | 버전/해시, action chunk, filter, 주기 계약 |
| 실험 설계 | 15 | 조건별 반복, 순서 무작위화, 누락 없는 episode |
| 통계 보고 | 10 | 성공률 + Wilson CI + latency p50/p95/p99 |
| 재현성과 포트폴리오 | 10 | 코드·설정·실패 사례·라이선스·한계 공개 |

다음 중 하나라도 있으면 안전 승격 항목은 0점이다.

- workspace/joint limit 없이 실물 실행
- `PoseStamped.frame_id`를 무시하거나 좌표 변환 없이 `base_link`로 재표기
- stale target 또는 유효하지 않은 quaternion을 실행 경로에서 허용
- E-stop 뒤 자동 NOMINAL 복귀
- timeout 뒤 마지막 명령 무기한 유지
- 실패 episode 삭제 또는 성공 기준 사후 변경
- 자연어 명령으로 안전 제한 해제 가능
