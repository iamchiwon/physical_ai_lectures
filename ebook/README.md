# Ebook workspace

`Physical AI 로봇 제어 실무` 교재와 이북 산출물을 관리하는 독립 작업 영역입니다.

```text
book/       기존 여섯 장 응용 교재, 실습, 예제 코드, 이미지
curriculum/ 통합 과정의 새 상세 교재(E1·E2 및 E3 M10~M12·M14 기초)
output/     PDF, EPUB, HTML 최종 산출물
reviews/    장별·통합 검수 기록
shared/     이북용 CSS와 작성 템플릿
tools/      Pandoc 기반 빌드 스크립트
tmp/        빌드·검수 임시 자료
```

저장소 루트에서 다음과 같이 빌드합니다.

```bash
./ebook/tools/build_book.sh
```

빌드는 `doc/v2/inventory/e1-reviews.json`·`e2-reviews.json`·`e3-reviews.json`의 현재 원고 지문과 일치한 상세 본문·실습·문제·해설을 먼저 결합하고, 기존 여섯 장 응용 교재를 이어 붙입니다. JSON 작성 메타데이터는 이북 본문에서 제외하고, 포함된 상세 단위 연결은 실제 책 내부 앵커로 변환합니다. 원고가 승인 후 바뀌면 재검수 없이 출판하지 않습니다. Node.js와 루트 npm 의존성이 필요합니다.

새 상세 본문은 [`curriculum/`](curriculum/)에서, 웹에서는 `교재 본문` 목차의 상세 교재 영역에서 읽을 수 있습니다. 원고·웹 빌드와 PDF/EPUB 산출물 생성은 별도 단계입니다.

빌드 스크립트는 스크립트 위치를 기준으로 `ebook/` 루트를 찾으므로 현재 작업 디렉터리와 무관하게 동작합니다.

### 이북의 웹 연결

포함된 상세 단위와 같은 책에 포함된 기존 상세 본문은 실제 책 앵커가 있을 때 내부 링크로 연결합니다. 책 범위 밖의 요약·전체 목차·향후 단위는 웹 주소로 연결합니다. 기본 웹 주소는 프로젝트의 Pages 주소이며, 다른 도메인을 사용하면 `BOOK_WEB_BASE_URL`을 실제 학습 사이트의 절대 HTTP(S) 주소로 지정해 빌드하세요. 웹 연결은 해당 사이트의 배포된 콘텐츠를 따릅니다. 코드 예제 안의 경로 문자열은 링크 변환 대상이 아닙니다.

**출판 지시(2026-11-03):** 모든 작업·내용 검수 뒤 사용자가 별도 요청하기 전에는 위 PDF/EPUB 빌드 명령을 실행하지 않습니다. E3 작업은 원고·웹·검수와 출판 입력 코드의 확장만 수행합니다.
