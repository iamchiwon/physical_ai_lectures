# P4 · 정책·트윈·관제 평가 기본 실행 계약

## 학습 범위와 환경

S10의 M20.06/M21.06·M25.06·M27.06·M30.05/.06·M34.01~03을 연결한다. 일반 코딩 가능자를 대상으로 Python3.12.11 표준 라이브러리만 사용한다. 기본은 CPU의 작은 1차원 행동 복제(BC)와 합성 폐루프/관제 기록이다. GPU·ROS·실제3D엔진·접촉/충돌·실물 전이/운영 권한/안전 실증은 포함하지 않는다. 언어/문법 입문은 설명하지 않는다.

지도 x축의 목표0까지의 오차 x(m)를 입력받아 속도 u(m/s)를 내는 affine정책 u=a*x+b를 시연으로 적합한다. 단일점·무잡음·정확상태·이산정속의 합성 모형이며 실제 정책/동역학 성능으로 확대하지 않는다. 트윈은 이 작은 상태전이 모형의 범위에서만 쓴다. M34.02의 실제3D장면 구현을 대체하지 않는다.

## 학습/선택/잠근 시험

- 시연은 train의session-t1/t2, validation의session-v1, test의session-e1로분리한다. 한session이둘이상분할에나타나면입력오류로중단한다. 행ID도유일하며모든분할의점수/분모를보존한다.
- train4행으로절편포함최소제곱affine를적합하고zero기준과validation2행MSE로비교한다. 동점은zero를선택한다. 잠근test2행은선택후한번평가하며학습/모델선택에쓰지않는다. 분할명만붙인동일세션누수를허용하지않는다.
- 현재시연은u=-0.5*x로affine a=-0.5,b=0,validation/test MSE0이며zero의validation0.015625/test0.16이다. 단위는MSE(m/s)^2. 실제제공데이터와수치대조한다. 이것만으로성공률을정의하지않는다.

## 실행/관제 계약

- r1/bootA,ClockA,map-v7/model-v3/cal-c2,frame map,m·m/s를고정한다. 표시용변환은map→map항등이며관측/변환stamp가같아야한다. 회전·기구학·3D 물리를계산하지않는다.
- 관측now는1000+500*tick ms,admission은now+10ms다. 관측은0≤admission−stamp≤200ms(포함),명령은0≤admission−issued≤50ms(포함)여야한다. heartbeat는now시각으로별도표시하며관측을새롭게만들지않는다. 다른clock/대상/세대/버전·단위/프레임·변환시각불일치/미래/누락은INVALID_STOP·새명령없음이다.
- 입출력형식은엄격히검사한다. bool을숫자로받지않고유한수·정수시각/스텝·알려진키/식별자·고유scenario/tick을검사한다. 전체파일계약이틀리면실험을시작하지않고출력파일도만들지않는다. 개별관측불량은실험실패로기록해전체분모에남긴다.
- u는±0.5m/s로제한한다. 합성상태는x_next=x+0.5s*gain*u이며nominal gain1,조건변화gain0이다. 최대8스텝,초기x1m,|x|≤0.15m를신선한모형관측에서확인하면SIMULATED_SUCCEEDED다. 실제도착과구별한다. 제한/관문과범위는교육용이며운전기준이아니다.
- 모든명령은request/epoch/관측/버전ID를연결한다. 이실험은신뢰된합성자료와고정허가가정이다. 실제권한검사/멱등서버/네트워크취소를구현한것이아니다.

## 6개 고정 사례와 실패 분모

| 사례 | 입력 변화 | 판정 기준 |
|---|---|---|
|nominal |변화없음 |7명령뒤x=0.13348388671875m,가상성공 |
|shifted-dynamics |gain0 |8명령뒤x1m,한계도달실패 |
|stale |tick2 관측201ms전 |admission나이211ms,INVALID_STOP·2명령만 |
|wrong-version |tick2 map-v8 |INVALID_STOP·2명령만 |
|missing-observation |tick2 관측없음 |INVALID_STOP·2명령만 |
|rollback |tick2 bundle-B/schema변경 |새실행거부·이전bundle-A/새epoch로 되돌리되재개보류,2명령·x0.5625유지 |

가상성공1/6이며무효3·롤백보류1·조건변화실패1을분모에서빼지않는다. 동일사례의zero정책비교는nominal gain1에서도x1m로성공하지않는다. 롤백은코드/정책선택의복구이며물리상태를초기x1로되돌리지않는다. 자동재개하지않고새관측/정확한범위의새확인등의운영절차를다음검증으로남긴다.
